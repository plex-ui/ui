### Overview

<ComponentPreview language="vue" details={<>
  <p>A checkbox is checked, unchecked or indeterminate. Pass <code>checked="indeterminate"</code>, or <code>default-checked="indeterminate"</code>, for a partly selected state: a "select all" box whose items are only partly checked, as in <a href="#group-with-select-all">Group with select all</a>.</p>
  <p><code>solid</code> (default) fills the box; <code>ghost</code> renders only the checkmark, in the text color, without a border or background, for subtle inline selections or task lists. <code>pill</code> rounds the box (<code>border-radius: full</code>): the solid fill, and on a ghost box its hover tint and focus ring.</p>
  <p>Use <code>description</code> (or the <code>description</code> slot) for a second line under the label. It sits outside the label, so the checkbox keeps the label as its name and gets the description through <code>aria-describedby</code>. By default the box is on the left of its label; <code>orientation="right"</code> places it after the label. Both act only next to a label, so they are offered only with one. Without a <code>label</code> the checkbox is a standalone control: pass <code>aria-label</code> to name it.</p>
  <p><code>disabled</code> keeps the checked and indeterminate states.</p>
  <p>On a phone with <code>touch.css</code> a solid checkbox is the 22px selection circle of iOS with or without <code>pill</code>, so the phone view has no <code>pill</code> setting. A ghost checkbox is the checkmark of an iOS list row.</p>
</>} code={overview} previewMinHeight={200}>

Other attributes and listeners land on the checkbox `<button>`. Built on [Reka UI Checkbox](https://reka-ui.com/docs/components/checkbox). Inside a `<form>`, a hidden native checkbox mirrors the state so the value is submitted and a form reset restores the initial state.

## Styling

Checkbox reads these component tokens. Override them at any scope to restyle it:

- `--checkbox-indicator-size`: indicator size (default `var(--radio-group-indicator-size)`)
- `--checkbox-ghost-check-color`: checkmark color for the ghost variant (default `var(--gray-900)`)
- `--checkbox-checkmark-color`: checkmark color on a solid box (default `var(--gray-0)`)
- `--checkbox-check-icon-size`: size of the Check and Minus icons on a solid box (default the indicator size)
- `--checkbox-ghost-icon-size`: size of the Check and Minus icons for the ghost variant (default the indicator size; 26px in the touch stylesheet)
- `--checkbox-label-gap`: label gap (default `var(--radio-group-item-gap)`)
- `--checkbox-label-line-height`: label line height (default `var(--radio-group-item-line-height)`)
- `--input-border-color-invalid`: border color invalid (default `var(--color-border-danger-outline)`)
