## API

### RollingNumber

<PropsTable data={[
  { prop: "value", type: "number", description: "The number shown; a new value rolls each changed digit to it" },
  { prop: "locales", type: "string | string[]", default: '"en-US"', description: "The locale the number is written in; fixed rather than the browser's, so the server writes it as the browser does. Its own digits roll, such as Arabic-Indic" },
  { prop: "format", type: "Intl.NumberFormatOptions", description: "How it is written: a currency, a percent, fraction digits, grouping" },
  { prop: "class", type: "string", description: "Applied to the root span; set the size and weight here" },
]} />

Other attributes fall through to the root `<span>`. The written number is in a visually hidden span; the reels are `aria-hidden`.

## Styling

- `--rolling-number-duration`: how long a digit rolls (defaults to `600ms`)
- `--rolling-number-ease`: its easing (defaults to `--cubic-move`)
