## API

**Dialog** (root)

<PropsTable data={[
  { prop: "open / v-model:open", type: "boolean", description: "Controlled open state; uncontrolled when omitted" },
  { prop: "@update:open", type: "(open: boolean) => void", description: "Fires when the dialog opens or closes" },
]} />

**DialogContent**

<PropsTable data={[
  { prop: "width", type: "number | string", default: "480", description: "Panel width" },
  { prop: "show-close", type: "boolean", default: "true", description: "Show close button in top-right corner" },
  { prop: "class", type: "string", description: "Additional CSS class on the panel" },
  { prop: "placement", type: '"center" | "top" | "bottom" | "start" | "end" | "fullscreen"', default: '"center"', description: "Where the panel sits: centered, near the top, a bottom sheet, a side panel, or the whole screen" },
  { prop: "mobile-placement", type: '"center" | "bottom" | "fullscreen"', description: "Placement at 640px and below; defaults to placement" },
  { prop: "@open-auto-focus", type: "(event: Event) => void", description: "Called when focus moves into the dialog on open; call event.preventDefault() to place it yourself, for example on the panel instead of the first field" },
  { prop: "@close-auto-focus", type: "(event: Event) => void", description: "Called when focus returns on close; call event.preventDefault() to keep it elsewhere" },
]} />

**DialogTrigger**: opens the dialog; renders its child element (Reka's `as-child`).

**DialogHeader**: wrapper for title and description.

**DialogTitle**: accessible heading for the dialog.

**DialogDescription**: supporting text under the title.

**DialogBody**: the scrolling part between the header and the footer. With it, only the body scrolls. Accepts `class`.

**DialogFooter**: footer area for action buttons. At 640px and below, actions stack at full width with a 44px height and fully rounded corners.

**DialogClose**: closes the dialog when its child is activated.

## Styling

Dialog reads the shared semantic color, typography and spacing tokens listed in [Design tokens](/docs/foundations/design-tokens), so it follows theme changes made there. Override these Dialog tokens at any scope:

- `--dialog-close-background`: close button background (default `transparent`)
- `--dialog-close-background-hover`: close button background on hover

- `--dialog-mobile-close-size`: visible close-button circle (default `--control-size-md`, 32px)
- `--dialog-mobile-close-icon-size`: close SVG box (default `--control-icon-size-2xl`, 24px; the glyph occupies about 12px)
- `--dialog-mobile-close-background`: mobile close button fill (default secondary soft)
- `--dialog-mobile-radius`: mobile panel corner radius (default `--radius-4xl`, 24px)
- `--dialog-mobile-action-size`: mobile footer height and close-button touch target (default `--control-size-2xl`, 44px)
- `--dialog-mobile-action-radius`: mobile footer button radius (default `--radius-full`)
- `--dialog-mobile-action-font-size`: mobile footer button text size (default `--control-font-size-lg`)
