### Migration from SegmentedControl

`Tabs` replaces and extends `SegmentedControl`. As in the React package, the old import still works as an alias:

```vue
<script setup lang="ts">
import { ref } from "vue"
// Old (still works)
import { SegmentedControl, SegmentedControlOption } from "@plexui/vue/components/SegmentedControl"
// New (recommended)
import { Tabs, TabsTab } from "@plexui/vue/components/Tabs"

const mode = ref("a")
</script>

<template>
  <SegmentedControl v-model:value="mode" aria-label="Mode">
    <SegmentedControlOption value="a">A</SegmentedControlOption>
  </SegmentedControl>

  <Tabs v-model:value="mode" aria-label="Mode">
    <TabsTab value="a">A</TabsTab>
  </Tabs>
</template>
```

`TabsTab` and `TabsOption` are the same component, and so are `SegmentedControlOption` and `SegmentedControlTab`. The `SegmentedControl` alias defaults to `variant="segmented"`.
