## Styling

Alert reads these component tokens. Override them at any scope to restyle it:

- `--alert-border-radius`: border radius (default `var(--radius-xl)`)
- `--alert-font-size`: font size (default `var(--font-text-sm-size)`)
- `--alert-gap`: gap (default `spacing(3)`)
- `--alert-gutter`: gutter (default `spacing(4)`)
- `--alert-line-height`: line height (default `var(--font-text-sm-line-height)`)
- `--alert-title-font-weight`: title font weight (default `var(--font-weight-semibold)`)
