## Examples

Tooltips provide supplementary information on hover or keyboard focus. Touch-only users need visible helper text or a tap-triggered [Popover](/vue/components/popover). These examples use pointer and keyboard interactions, so they do not have a separate Phone preview. For copying, [Copy Tooltip](/vue/components/copy-tooltip) confirms the action after a successful tap.

  <p>Any element can be the trigger: <code>trigger</code> shows text, a button and an icon button.   <p>A disabled button can tell why in its tooltip on hover (a disabled button is no tab stop): pass the reason as <code>content</code> while it is disabled. To show a tooltip only under a condition, pass <code>null</code> otherwise.</p>

The tooltip content is the `role="tooltip"` element, and the trigger points at it with `aria-describedby`. Other attributes and listeners, such as `@click` and `@pointerdown`, go to the trigger element. `TooltipTriggerDecorator` turns text into an accessible trigger with the decorator style and a tab stop (`focusable`, default `true`).

## Styling

Tooltip has no component tokens of its own. It reads the shared semantic color, typography and spacing tokens listed in [Design tokens](/docs/foundations/design-tokens), so it follows theme changes made there.
