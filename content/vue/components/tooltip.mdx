### Overview

<ComponentPreview phonePresentation="none" language="vue" details={<>
  <p>Tooltips provide supplementary information on hover or keyboard focus. Touch-only users need visible helper text or a tap-triggered <a href="/vue/components/popover">Popover</a>. ## API

### Tooltip

<PropsTable data={[
  { prop: "default slot", type: "VNode", description: "The trigger: a single element. Wrap plain text in TooltipTriggerDecorator" },
  { prop: "content", type: "string | number | VNode | null", description: "Tooltip content, or the #content slot (null = no tooltip)" },
  { prop: "compact", type: "boolean", default: "false", description: "Short 1-3 word tooltips, inverse styling" },

  { prop: "align-offset", type: "number", default: "0", description: "Alignment offset" },
  { prop: "gutter-size", type: '"sm" | "md" | "lg"', default: '"md"', description: "Content padding" },
  { prop: "content-class-name", type: "string", description: "Class for tooltip content" },
  { prop: "force-open", type: "boolean", description: "Force open or closed" },
  { prop: "prevent-unintentional-click-to-close", type: "boolean", default: "false", description: "Keeps the tooltip open when the trigger is clicked right after it opened" },
  { prop: "content slot", type: "VNode[]", description: "Rich tooltip content; takes precedence over content" },
]} />

The tooltip content is the `role="tooltip"` element, and the trigger points at it with `aria-describedby`. Other attributes and listeners, such as `@click` and `@pointerdown`, go to the trigger element. `TooltipTriggerDecorator` turns text into an accessible trigger with the decorator style and a tab stop (`focusable`, default `true`).

## Styling

Tooltip and Copy Tooltip have no component tokens of their own. It reads the shared semantic color, typography and spacing tokens listed in [Design tokens](/docs/foundations/design-tokens), so it follows theme changes made there.
