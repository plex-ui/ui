### Overview

<ComponentPreview language="vue" details={<>Dashboard-ready stats cards with trends, icons, and progress bars. Use <code>size="sm"</code> for compact analytics rows with denser spacing and smaller typography; it pairs well with <code>tooltip</code>, a string that adds an info icon next to the label. The trend sits under the value with its label, or right-aligned in the header row (<code>trend-position</code>), as plain text or in a badge (<code>trend-variant</code>). ## Styling

Stats Card reads these component tokens. Override them at any scope to restyle it:

- `--stats-card-accent-width`: accent width (default `4px`)
- `--stats-card-background`: background (default `var(--color-surface)`)
- `--stats-card-border-color`: border color (default `var(--color-border)`)
- `--stats-card-description-color`: description color (default `var(--color-text-tertiary)`)
- `--stats-card-description-font-size`: description font size (default `var(--font-text-sm-size)`)
- `--stats-card-icon-color`: icon color (default `var(--color-text-primary)`)
- `--stats-card-icon-size`: icon size (default `16px`)
- `--stats-card-icon-wrapper-background`: icon wrapper background (default `var(--color-background-primary-soft-alpha)`)
- `--stats-card-icon-wrapper-radius`: icon wrapper radius (default `var(--radius-md)`)
- `--stats-card-icon-wrapper-size`: icon wrapper size (default `32px`)
- `--stats-card-info-icon-size`: info icon size (default `16px`)
- `--stats-card-label-color`: label color (default `var(--color-text-secondary)`)
- `--stats-card-label-font-size`: label font size (default `var(--font-text-sm-size)`)
- `--stats-card-padding`: padding (default `spacing(5)`)
- `--stats-card-progress-background`: progress background (default `light-dark(var(--alpha-08), var(--alpha-12))`)
- `--stats-card-progress-fill`: progress fill (default `var(--color-background-primary-solid)`)
- `--stats-card-progress-height`: progress height (default `4px`)
- `--stats-card-progress-radius`: progress radius (default `var(--radius-full)`)
- `--stats-card-radius`: radius (default `var(--radius-xl)`)
- `--stats-card-sm-description-font-size`: sm description font size (default `var(--font-text-xs-size)`)
- `--stats-card-sm-icon-size`: sm icon size (default `14px`)
- `--stats-card-sm-icon-wrapper-radius`: sm icon wrapper radius (default `var(--radius-sm)`)
- `--stats-card-sm-icon-wrapper-size`: sm icon wrapper size (default `28px`)
- `--stats-card-sm-info-icon-size`: sm info icon size (default `14px`)
- `--stats-card-sm-label-font-size`: sm label font size (default `var(--font-text-xs-size)`)
- `--stats-card-sm-padding-block`: sm padding block (default `spacing(3)`)
- `--stats-card-sm-padding-inline`: sm padding inline (default `spacing(4)`)
- `--stats-card-sm-trend-font-size`: sm trend font size (default `var(--font-text-xs-size)`)
- `--stats-card-sm-value-font-size`: sm value font size (default `var(--font-heading-md-size)`)
- `--stats-card-trend-font-size`: trend font size (default `var(--font-text-sm-size)`)
- `--stats-card-trend-font-weight`: trend font weight (default `var(--font-weight-semibold)`)
- `--stats-card-trend-negative-color`: trend negative color (default `var(--color-text-danger-soft)`)
- `--stats-card-trend-neutral-color`: trend neutral color (default `var(--color-text-tertiary)`)
- `--stats-card-trend-positive-color`: trend positive color (default `var(--color-text-success-soft)`)
- `--stats-card-value-color`: value color (default `var(--color-text)`)
- `--stats-card-value-font-size`: value font size (default `var(--font-heading-xl-size)`)
- `--stats-card-value-font-weight`: value font weight (default `var(--font-weight-semibold)`)
