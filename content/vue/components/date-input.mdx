<UsageBlock>{`import { DateInput } from "@plexui/vue/components/DateInput";`}</UsageBlock>

On Phone, put a date input in a row of a `FieldGroup`, as the [Input](/vue/components/input) examples and the [Forms: Settings](/vue/components/settings-forms) do. The row is its frame and sets its height, insets and type, so the Phone previews show rows without the `variant`, `size`, `pill` and `invalid` controls (a row shows its error as [Validation](#validation) does). To pick a date rather than type it, use the compact date of a [Date Picker](/vue/components/date-picker) in the row.

## API

<PropsTable data={[
  { prop: "value / v-model:value", type: "DateTime | null", description: "Selected date (Luxon DateTime). The field shows its date and time in its own zone, and a typed date is made in that zone (Luxon's default zone without a value)" },
  { prop: "@update:value", type: "(date: DateTime | null) => void", description: "Emitted when a complete valid date is entered or the field is cleared" },
  { prop: "@change", type: "(date: DateTime | null) => void", description: "Same payload as update:value, named after React's onChange" },
  { prop: "mode", type: "MaskitoDateMode", default: '"dd/mm/yyyy"', description: "Date format mode: dd/mm/yyyy, mm/dd/yyyy, yyyy/mm/dd, etc." },
  { prop: "separator", type: "string", default: '"."', description: "Character between date parts" },
  { prop: "time-mode", type: "MaskitoTimeMode", description: "Enable time input: HH:MM, HH:MM:SS, etc." },
  { prop: "date-time-separator", type: "string", default: '", "', description: "Separator between date and time parts" },
  { prop: "time-step", type: "number", default: "0", description: "Arrow-key increment step for time segments" },
  { prop: "min", type: "DateTime", description: "Earliest allowed date" },
  { prop: "max", type: "DateTime", description: "Latest allowed date" },
  { prop: "clearable", type: "boolean", default: "false", description: "Show clear button when input has a value" },
  { prop: "size", type: "ControlSize", default: '"md"', description: "Input size (3xs to 3xl)" },
  { prop: "variant", type: '"outline" | "soft"', default: '"outline"', description: "Visual style" },
  { prop: "pill", type: "boolean", default: "false", description: "Fully rounded corners" },
  { prop: "disabled", type: "boolean", default: "false", description: "Disable input" },
  { prop: "invalid", type: "boolean", default: "false", description: "Mark as invalid" },
  { prop: "placeholder", type: "string", description: "Generated from the format if not set" },
]} />

Other attributes, listeners and the `startAdornment` / `endAdornment` slots go to the underlying [Input](/vue/components/input). The mask is [Maskito](https://maskito.dev) (`@maskito/vue`), with the same options as the React component.

## Styling

Date Input reads these component tokens. Override them at any scope to restyle it:

- `--input-border-color-invalid`: border color invalid (default `var(--color-border-danger-outline)`)
- `--input-gap-lg`: gap lg (default `10px`)
- `--input-gap-md`: gap md (default `8px`)
- `--input-gap-sm`: gap sm (default `6px`)
- `--input-gap-xs`: gap xs (default `4px`)
- `--input-outline-border-color`: outline border color (default `var(--color-border-primary-outline)`)
- `--input-outline-border-color-focus`: outline border color focus (default `var(--alpha-50)`)
- `--input-outline-border-color-hover`: outline border color hover (default `light-dark(var(--alpha-25), var(--alpha-30))`)
- `--input-placeholder-text-color`: placeholder text color (default `var(--color-text-tertiary)`)
- `--input-soft-background-color`: soft background color (default `var(--color-background-primary-soft-alpha)`)
- `--input-soft-border-color-focus`: soft border color focus (default `var(--alpha-20)`)
- `--input-text-color`: text color (default `var(--color-text)`)
