  { prop: "show-pagination", type: "boolean", default: "true", description: "Whether to show pagination controls. They hide on their own when every row fits on one page" },
  { prop: "class", type: "string", description: "Class applied to outermost wrapper" },
  { prop: "emptyMessage slot", type: "VNode[]", description: "Rich content shown when no rows" },

  { prop: "@update:global-filter", type: "(value: string) => void", description: "Emitted with the next filter when the table changes it; powers v-model:global-filter" },

`@row-click` is a function prop rather than an event, because its presence makes the rows interactive; `:on-row-click` works the same. Column groups (a column definition with `columns`) render a header that spans its columns.

## Styling

Table reads these component tokens. Override them at any scope to restyle it:

- `--table-border-color`: border color (default `var(--color-border)`)
- `--table-caption-color`: caption color (default `var(--color-text-tertiary)`)
- `--table-caption-font-size`: caption font size (default `var(--font-text-sm-size)`)
- `--table-cell-color`: cell color (default `var(--color-text)`)
- `--table-cell-font-size`: cell font size (default `var(--font-text-sm-size)`)
- `--table-cell-line-height`: cell line height (default `var(--font-text-sm-line-height)`)
- `--table-cell-padding`: cell padding (default `spacing(3) spacing(4)`)
- `--table-footer-background`: footer background (default `transparent`)
- `--table-footer-font-weight`: footer font weight (default `var(--font-weight-medium)`)
- `--table-header-background`: header background (default `transparent`)
- `--table-header-color`: header color (default `var(--color-text-secondary)`)
- `--table-header-font-weight`: header font weight (default `var(--font-weight-medium)`)
- `--table-row-hover-background`: row hover background (default `light-dark(var(--alpha-02), var(--alpha-04))`)
