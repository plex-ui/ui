## Examples

### Overview

<ComponentPreview className={phoneRowsStyles.PhoneRowsPreview} language="vue" details={<>
  <p>Field wraps a form control with a label, a description and an error message, and links them: the label's <code>for</code>, <code>aria-describedby</code> and <code>aria-invalid</code> reach the control. <code>required</code> adds an asterisk after the label; it is visual only, so give the control its own <code>required</code> for form validation. The <code>layout</code> control puts the label in its four places:</p>
  <ul>
    <li><strong>above</strong>: the default, <code>orientation="vertical"</code>.</li>
    <li><strong>columns</strong>: <code>orientation="horizontal"</code>, every value starting at one column.</li>
    <li><strong>end</strong>: <code>row</code>, one line of a <code>FieldGroup</code> with the value at its end. A framed field is a pill there and takes <code>--field-row-control-width</code>, as its width cannot follow what is typed; <code>:pill="false"</code> on the control keeps the rounded box.</li>
    <li><strong>hidden</strong>: <code>hide-label</code>. The label still names the control for screen readers; the placeholder shows what to type, and a description moves under the field.</li>
  </ul>
  <p>On Phone a field is always a cell of a <code>FieldGroup</code> on the grouped background, as in an iOS form, in the same four places: the label above its value (<code>row orientation="vertical"</code>), values in one column (<code>FieldGroup columns</code>), the value at the end of the row, or the placeholder alone (<code>row hide-label</code>), its value starting at the row's edge. The row is the field's frame, so a framed or soft field loses its frame. The error stands inside the cell, under the value. The words that explain a field go in the group's <code>footer</code> slot, and a required field says so in its placeholder, as iOS account forms do. A disabled field dims its label with its value. A one-time code is the exception: <code>OTPInput</code> keeps its own digit cells on the screen, outside a group, as in <a href="/vue/components/form-examples#verify-email">Verify email</a>.</p>

## Styling

Field reads these component tokens. Override them at any scope to restyle it:

- `--field-error-color`: error color (default `var(--color-text-danger-outline)`)
- `--field-error-font-size`: error font size (default `0.75rem`)
- `--field-error-gap`: error gap (default `spacing(2)`)
- `--field-error-icon-size`: error icon size (default `1rem`)
- `--field-error-line-height`: error line height (default `var(--font-text-xs-line-height)`)
- `--field-error-margin-bottom`: error margin bottom (default `spacing(3)`)
- `--field-error-margin-top`: error margin top (default `0.5rem`)
- `--field-error-padding-inline`: error padding inline (default `0`)
- `--field-horizontal-control-width`: horizontal control width (default `240px`)
- `--field-horizontal-control-flex`: flex of the horizontal control (default `0 0 auto`; `0 1 auto` on a phone with `touch.css`, so the control narrows instead of overflowing)
- `--field-horizontal-label-width`: horizontal label width (default `120px`)
- `--field-label-font-weight`: label font weight (default `var(--font-weight-medium)`)
- `--field-row-above-color`: colour of a label above its value (default `var(--color-text-tertiary)`)
- `--field-row-above-font-size`: size of a label above its value (default `0.8125rem`)
- `--field-row-above-font-weight`: weight of a label above its value (default `var(--font-weight-medium)`)
- `--field-row-above-gap`: space under a label above its value (default `4px`)
- `--field-row-above-line-height`: line height of a label above its value (default `1.125rem`)
- `--field-row-above-padding-block`: padding of a row with a label above its value (default `10px`)
- `--field-row-action-font-size`: text size of the action button (default `var(--font-text-sm-size)`)
- `--field-row-action-font-weight`: text weight of the action button (default `var(--font-weight-medium)`)
- `--field-row-action-size`: height of the action button (default `2rem`)
- `--field-row-control-width`: width of a framed number in a row (default `160px`)
- `--field-row-description-font-size`: description size on a row (default `var(--font-text-sm-size)`)
- `--field-row-description-line-height`: description line height on a row (default `var(--font-text-sm-line-height)`)
- `--field-row-gap`: space between label and control (default `24px`, `16px` on a `fill` row)
- `--field-row-label-font-size`: label size on a row (default `var(--font-text-sm-size)`)
- `--field-row-label-font-weight`: label weight on a row (default `var(--font-weight-medium)`)
- `--field-row-label-line-height`: label line height on a row (default `var(--font-text-sm-line-height)`)
- `--field-row-label-width`: label column of a `fill` row (default `80px`)
- `--field-row-list-label-offset`: moves the label to the middle of a list's first line (default `6px`)
- `--field-row-list-padding-block`: padding of a `fill` row with an `action` (default `10px`)
- `--field-row-list-row-gap`: space above a list on its own line (default `8px`)
- `--field-row-min-height`: row height (default `52px`)
- `--field-row-padding-block`: row padding (default `10px`)
- `--field-row-padding-inline`: row padding (default `16px`)
- `--field-row-row-gap`: space above an error (default `2px`)
- `--field-row-text-display`: `contents` runs the description under the control (default `flex`)
- `--field-row-text-padding-block`: row padding with a description or an error (default `10px`)
- `--field-row-text-width`: width of a framed text field in a row (default `240px`)

FieldGroup reads these:

- `--field-group-background`: block background (default `transparent`)
- `--field-group-border-width`: block border (default `1px`)
- `--field-group-description-font-size`: description size (default `var(--font-text-sm-size)`; 15px on a phone)
- `--field-group-description-line-height`: description line height (default `var(--font-text-sm-line-height)`; 20px on a phone)
- `--field-group-footer-font-size`: footer size (default the description size; 13px on a phone)
- `--field-group-footer-line-height`: footer line height (default the description line height; 16px on a phone)
- `--field-group-footer-padding`: footer padding (default `8px 0 0`)
- `--field-group-footer-paragraph-gap`: space between footer paragraphs (default `spacing(2)`; 16px on a phone)
- `--field-group-header-min-height`: header height (default `spacing(8)`)
- `--field-group-header-padding-bottom`: space under the header (default `spacing(2)`)
- `--field-group-radius`: block radius (default `1rem`)
- `--field-group-title-color`: title color (default `var(--color-text)`)
- `--field-group-title-font-size`: title size (default `var(--font-text-md-size)`)
- `--field-group-title-font-weight`: title weight (default `var(--font-weight-medium)`)
- `--field-group-title-letter-spacing`: title tracking (default `normal`)
- `--field-group-title-line-height`: title line height (default `var(--font-text-md-line-height)`)
- `--field-group-title-padding-inline`: title inset (default `0`)
