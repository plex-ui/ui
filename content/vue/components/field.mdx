### Slot props pattern

Field's default slot receives `{ id, "aria-describedby", "aria-invalid" }` (plus `opticallyAlign` when set). A slot that reads these props renders its content as it is, so you bind them where they belong, like React's render prop. A slot that does not read them gets its single root element wired by Field.

```vue
<Field label="Email" error-message="Email is required" v-slot="fieldProps">
  <Input v-bind="fieldProps" placeholder="Enter email..." />
</Field>
```
