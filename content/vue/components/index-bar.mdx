An index bar takes people through a long list that is sorted by its titles, such as countries or contacts, as the iOS section index does: a letter for each section down the trailing edge, and a press or a drag on a letter shows its section. Give a list one only when it is long and its sections are its letters. A desktop list has no index, so the bar renders under 768px only.

## Examples

The example shows the phone view.

## API

### IndexBar

<PropsTable data={[
  { prop: "items", type: "string[]", description: "The titles of the sections, in order: usually letters, such as A to Z and #" },
  { prop: "id", type: "string", description: "The id of the index bar" },
  { prop: "aria-label", type: "string", default: '"Section index"', description: "Name of the index bar" },
  { prop: "aria-controls", type: "string", description: "The id of the list the index scrolls" },

**Events**: `select` with the title and the index of the section to show, on a press, on each new letter while dragging and from the keys (React `onSelect`); `focus` and `blur`.

The bar is one stop for the Tab key: a vertical slider named Section index, read as the letter of the current section, as the iOS section index is one adjustable element for VoiceOver. Down and Up, or Right and Left, move one section; Home and End go to the first and the last; Enter or Space shows the current section again. The letters themselves are hidden from assistive technology. While a pointer presses the bar, it has `data-pressed`. Classes and other attributes go to the strip of the index bar.

## Styling

IndexBar reads these component tokens. Override them at any scope to restyle it:

- `--index-bar-width`, `--index-bar-inset-inline-end`: the column of letters and its space from the trailing edge (default `16px`, `2px`)
- `--index-bar-font-size`, `--index-bar-line-height`, `--index-bar-font-weight`: the letters and the space from one to the next (default `11px`, `15px`, medium)
- `--index-bar-color`: the letters (default `var(--color-text-info)`)
- `--index-bar-target-width`: how far in from the edge a press reaches the bar (default `30px`)
- `--index-bar-content-inset-inline-end`: how far from the trailing edge a `Page` ends its rows beside the bar (default `20px`)
