## API

### Kbd

<PropsTable data={[
  { prop: "size", type: '"xs" | "sm" | "md"', default: '"sm"', description: "Height and text size: 16px, 20px or 24px" },
  { prop: "variant", type: '"soft" | "outline"', default: '"soft"', description: "soft fills the key, outline draws its edge; both mix the text color" },
  { prop: "class", type: "string", description: "Applied to the kbd element" },
  { prop: "default slot", type: "VNode[]", description: "The key" },
]} />

Other `<kbd>` attributes (`title`, `aria-label`, ...) fall through to it.

### KbdGroup

A row of keys pressed together (React's `Kbd.Group`). Renders a `<span>`; attributes fall through to it.

## Styling

Kbd reads these component tokens. Override them at any scope to restyle it:

- `--kbd-background`: fill (defaults to the text color at 10%)
- `--kbd-border-color`: edge (transparent for `soft`, the text color at 24% for `outline`)
- `--kbd-color`: text color (defaults to `inherit`)
- `--kbd-radius`: corner radius (defaults to `--radius-xs`)
