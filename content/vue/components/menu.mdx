## API

**Note:** Menu prevents `Tab` from advancing focus. For generic popover content use [Popover](/vue/components/popover) instead.

**Menu** (root)

<PropsTable data={[
  { prop: "force-open", type: "boolean", description: "Keep menu open (controlled)" },
  { prop: "modal", type: "boolean", default: "false", description: "Whether menu is modal (focus trap)" },
  { prop: "@open", type: "() => void", description: "Emitted when menu opens" },
  { prop: "@close", type: "() => void", description: "Emitted when menu closes" },
]} />

**MenuTrigger**: renders its child (e.g. a Button) as the element that toggles the menu. Other attributes and listeners reach the child.

<PropsTable data={[
  { prop: "disabled", type: "boolean", default: "false", description: "Prevent the menu from opening" },
]} />

**MenuContent**

<PropsTable data={[
  { prop: "width", type: 'number | "auto"', default: '"auto"', description: "Panel width (numbers are pixels)" },
  { prop: "min-width", type: 'number | "auto"', default: "300", description: "Minimum panel width" },
  { prop: "max-height", type: "number", description: "Maximum panel height, in pixels" },
  { prop: "side", type: '"top" | "right" | "bottom" | "left"', default: '"bottom"', description: "Preferred placement" },
  { prop: "side-offset", type: "number", default: "5", description: "Distance from the trigger, in pixels" },
  { prop: "align", type: '"start" | "center" | "end"', default: '"center"', description: "Alignment relative to trigger" },
  { prop: "align-offset", type: "number", default: "-5", description: "Offset from the start or end alignment, in pixels" },
  { prop: "layout", type: '"vertical" | "horizontal"', default: '"vertical"', description: "Layout direction. Use horizontal for icon toolbars" },
  { prop: "size", type: '"sm" | "md" | "lg"', default: '"md"', description: "Size of horizontal menu items (icon size + padding)" },
  { prop: "@close-auto-focus", type: "(event: Event) => void", description: "Emitted before focus returns to the trigger; call event.preventDefault() to keep it from moving there" },
]} />

**MenuItem**: list item. Listen to `@select` or `@click` for actions; without either the item is non-interactive content.

<PropsTable data={[
  { prop: "description", type: "string", description: "Second line under the label (or the description slot). The label turns semibold on its own" },
  { prop: "disabled", type: "boolean", default: "false", description: "Disable the item" },
  { prop: "danger", type: "boolean", default: "false", description: "Destructive action: the item is drawn in the danger color" },
  { prop: "@select", type: "(event: Event) => void", description: "Called when the item is selected; call event.preventDefault() to keep the menu open" },
  { prop: "@click", type: "(event: MouseEvent) => void", description: "Called when the item is clicked; also makes the item interactive" },
]} />

**MenuLink**: item that navigates. Internal paths render the link component from `PlexUIProvider` (for example vue-router's `RouterLink`); absolute `http(s)` URLs open in a new tab. Pass `href` or `to`, `disabled` (a disabled link does not navigate), `danger`, `as` and link attributes.

**MenuSeparator**: divider between items. No props.

**MenuGroup**: groups related items. Wraps `MenuItem`, `MenuLink`, or `MenuLabel`. No specific props.

**MenuLabel**: non-interactive label for a group. Accepts `class`.

**MenuSub** / **MenuSubTrigger** / **MenuSubContent**: submenu wrapper (with `force-open`, `@open` and `@close`), trigger (with `disabled`), and content panel (with `width`, `min-width`, `max-height`, `side-offset` and `align-offset`).

**MenuCheckboxItem**

<PropsTable data={[
  { prop: "checked / v-model:checked", type: 'boolean | "indeterminate"', default: "false", description: "Checked state" },
  { prop: "@checked-change", type: "(checked: boolean) => void", description: "Emitted with update:checked when the checkbox toggles" },
  { prop: "@select", type: "(event: Event) => void", description: "Call event.preventDefault() to keep the menu open" },
  { prop: "indicator-position", type: '"start" | "end"', default: '"end"', description: "Checkbox position" },
  { prop: "indicator-variant", type: '"solid" | "ghost"', default: '"solid"', description: "Indicator style" },
  { prop: "disabled", type: "boolean", default: "false", description: "Disable the item" },
]} />

**MenuRadioGroup** / **MenuRadioItem**: radio group with `v-model:value` (plus `@change`) and `indicator-position`; MenuRadioItem takes `value`, `disabled` and `@select`.

**MenuItemActions** / **MenuItemAction**: MenuItemActions wraps hover actions; MenuItemAction emits `@click` and closes the menu.

## Styling

Menu reads these component tokens. Override them at any scope to restyle it:

- `--menu-checkbox-indicator-size`: checkbox indicator size (default `var(--font-text-lg-size)`)
- `--menu-font-size`: font size (default `var(--font-text-sm-size)`)
- `--menu-gutter`: gutter (default `spacing(1.5)`)
- `--menu-item-background-color`: item background color (default `light-dark(var(--alpha-08), var(--alpha-10))`)
- `--menu-item-gap`: item gap (default `spacing(1.5)`)
- `--menu-item-padding`: item padding (default `spacing(1.5) spacing(2)`)
- `--menu-line-height`: line height (default `var(--font-text-sm-line-height)`)
- `--menu-radio-indicator-hole-size`: radio indicator hole size (default `var(--font-text-3xs-size)`)
- `--menu-radio-indicator-size`: radio indicator size (default `var(--font-text-lg-size)`)
- `--menu-radius`: radius (default `var(--radius-xl)`)
- `--menu-separator-background-color`: separator background color (default `var(--color-border)`)
- `--menu-separator-gutter`: separator gutter (default `var(--menu-gutter) calc(-1 * var(--menu-gutter))`)
- `--radio-group-indicator-background-color`: indicator background color (default `var(--color-background-primary-solid)`)
- `--radio-group-indicator-border-color`: indicator border color (default `var(--color-border-primary-outline)`)
- `--radio-group-indicator-border-color-hover`: indicator border color hover (default `var(--alpha-25)`)
- `--radio-group-indicator-hole-background-color`: indicator hole background color (default `var(--color-text-primary-solid)`)
