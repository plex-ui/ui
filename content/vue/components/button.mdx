## NavigationButton

`NavigationButton` supplies a Back, Close, or Confirm glyph inside the public Button. The caller owns navigation, dismissal, and form submission. Page toolbars and Dialog header actions retain its role-specific glyph sizing and 44px Phone target.

```vue
import { NavigationButton } from '@plexui/vue/components/Button';

<NavigationButton action="back" aria-label="Back to albums" @click="goBack" />
<NavigationButton action="close" @click="cancel" />
<NavigationButton action="confirm" type="submit" form="album" aria-label="Save album" />
```

`action` is required: `"back" | "close" | "confirm"`. Accessible names default to Back, Close, and Confirm; override `aria-label` for the destination or operation. Other Button and native button props remain available, including `type`, `form`, disabled/loading state, event handlers, and refs. The component owns its glyph, `pill`, and `uniform` shape, so it does not accept children or an icon-size override.

Back and Close default to secondary soft buttons with the mobile glass material. Confirm defaults to primary solid; an explicit `color` or `variant` still overrides it. Use the existing [shared application accent](/docs/foundations/colors#shared-application-accent) recipe to set the primary palette once in application CSS after the stylesheet imports. Semantic `info` remains available for informational states.

Phone geometry uses `--navigation-button-size`, `--navigation-button-back-icon-size`, `--navigation-button-close-icon-size`, and `--navigation-button-confirm-icon-size`. Desktop retains Button sizing. Unrelated toolbar buttons keep their existing icon sizes.

## API

For neutral `soft` or `ghost` buttons, `mobileMaterial="glass"` applies the mobile toolbar surface below 768px with `touch.css`. Its label is the Liquid Glass text button's of the iOS 27 kit: Medium, 17px from `md` up (`--button-glass-font-weight`, `--button-glass-font-size`). Page toolbar icon buttons use it automatically. Use `mobileMaterial="flat"` to keep the original variant in a toolbar. Desktop appearance is unchanged.

Props mirror the React Button. In Vue, pass classes with `class` (React's `className`) and listen with `@click`.

## Styling

Button reads these component tokens. Override them at any scope to restyle it:

- `--button-font-weight`: font weight (default `var(--font-weight-medium)`)
- `--button-gap-lg`: gap lg (default `6px`)
- `--button-gap-md`: gap md (default `4px`)
- `--button-gap-sm`: gap sm (default `3px`)
- `--button-outline-background`: fill of the outline variant (default `transparent`)
