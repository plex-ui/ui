### Overview

<ComponentPreview className={emptyMessageStyles.PhoneScreenPreview} language="vue" details={<>
  <p>An empty message is made of parts, each optional: an icon, a title, a description and an action row. It needs a title or a description, so this preview offers <code>description</code> with a title; the description takes text or nodes, such as a search term in <code>font-semibold</code>. <code>color</code> on <code>EmptyMessageIcon</code> and on <code>EmptyMessageTitle</code> shows the intent of the message, such as <code>danger</code> on both for an error (a missing permission) or <code>warning</code> on the icon for a notice (a feature in beta); the description keeps its own color.</p>
  <p><code>fill</code> sizes the message to its parent: <code>static</code> takes the full width and height, <code>absolute</code> covers a positioned parent, and <code>none</code> applies no sizing, for a container that sets the height (a list with no results). Use <code>size="sm"</code> for an empty panel, card section or list: a smaller title, tighter spacing, no minimum width and a small icon badge; in a message of the default size the icon takes its own <code>size</code>. <code>align="start"</code> left-aligns the message, for an empty state under a section heading: a single line such as "No tags added" reads with the heading above it.</p>
  <p>The action row takes buttons, or a <code>TextLink</code> with <code>class="text-sm"</code> on the row. On a phone a message of the default size that fills the screen takes the shape of the iOS empty state: its buttons stand at the bottom across the width, one under the other, and its text is centred in the space above them; a link stays under the text.</p>

## Styling

Empty Message uses optional `--empty-message-*` tokens for its content spacing, typography and action sizes. It reads the shared semantic color, typography and spacing tokens listed in [Design tokens](/docs/foundations/design-tokens), so it follows theme changes made there.
