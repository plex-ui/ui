Compose with `AccordionItem`, `AccordionTrigger`, and `AccordionContent`. Built on Reka UI Accordion, with the same keyboard navigation, focus management, and WAI-ARIA semantics as the React version.

On a phone an item reads as an iOS 27.2 DisclosureGroup in an inset grouped list: a 52px row with its title at 17/22 regular and a chevron in the label color that points to the end and turns down when the item opens. The chevron is 21px and ends 1px past the title's margin, where iOS draws it. The content is a row under the title, 17/22 in the label color, 20px in from it, with a separator above it across the row; under an open item the separator starts where the content does, as under the last row a group holds.

## API

### Accordion

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `type` | `"single" \| "multiple"` | | Required. Whether one item or many can be open at a time |
| `v-model:value` / `value` | `string \| string[]` | | Controlled open item(s), named like the React prop |
| `default-value` | `string \| string[]` | | Uncontrolled initial open item(s) |
| `collapsible` | `boolean` | `false` | When `type="single"`, allow closing the open item |
| `disabled` | `boolean` | `false` | Disable every item |
| `dir` | `"ltr" \| "rtl"` | `"ltr"` | Reading direction |
| `orientation` | `"horizontal" \| "vertical"` | `"vertical"` | Layout axis |
| `class` | `string` | | Applied to the root `<div>` |
| `@update:value` | `(value: string \| string[]) => void` | | Fires when the open item(s) change; closing the open item of a single accordion reports `""` |

### AccordionItem

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `value` | `string` | | Required. Unique identifier used by `value` / `default-value` |
| `disabled` | `boolean` | `false` | Disable this item |
| `class` | `string` | | Applied to the item wrapper |

### AccordionTrigger

Renders a `<button>` inside an `<h3>` header, with a chevron that rotates when the item opens. The default slot is the label; `class`, other attributes, and listeners such as `@click` go to the `<button>`.

### AccordionContent

Renders the collapsible panel; the default slot is its content. It sets `--radix-accordion-content-height` (the same variable as React, so the shared CSS animates both) to interpolate the open/close animation from `0` to the measured content height. `force-mount` keeps a closed panel mounted and visible for custom animations.

## Styling

Colors, spacing, and transitions are controlled by component tokens:

- `--accordion-item-divider-color`: border between items (defaults to `--color-border`)
- `--accordion-item-divider-width`: divider thickness (defaults to `1px`)
- `--accordion-item-disabled-opacity`: disabled item opacity (defaults to `0.5`)
- `--accordion-trigger-color`: trigger text color
- `--accordion-trigger-font-size` / `--accordion-trigger-font-weight` / `--accordion-trigger-line-height`: trigger typography
- `--accordion-trigger-padding-block`: trigger vertical padding
- `--accordion-trigger-gap`: space between label and chevron
- `--accordion-trigger-focus-ring-color`: focus ring color
- `--accordion-icon-color` / `--accordion-icon-size`: chevron color and size (on a phone `--color-text` and `21px`)
- `--accordion-icon-margin-inline-end`: how far the chevron reaches past the end of the trigger (defaults to `0px`; `-5.33px` on a phone)
- `--accordion-content-color` / `--accordion-content-font-size` / `--accordion-content-line-height`: content typography
- `--accordion-content-padding-bottom`: space between content text and the next divider
- `--accordion-content-padding-top` / `--accordion-content-padding-inline-start`: space above the content and before it (default `0px`; `14.33px` and `20px` on a phone)
- `--accordion-content-divider-width`: the separator between a trigger and its content (defaults to `0px`; `1px` on a phone)
- `--accordion-transition-duration` / `--accordion-transition-ease`: open/close animation

Override at any scope to tune the look:

```css
.my-faq {
  --accordion-trigger-font-size: var(--font-text-base-size);
  --accordion-item-divider-color: var(--color-border-strong);
}
```
