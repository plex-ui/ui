Other attributes and listeners land on the switch `<button>`. Built on [Reka UI Switch](https://reka-ui.com/docs/components/switch). Inside a `<form>`, a hidden native checkbox mirrors the state so the value is submitted with the form.

## Styling

Set `--switch-accent-color` once in your application's theme stylesheet for every `color="accent"` switch. The [accent recipe](/docs/foundations/colors#primary-actions-and-checked-controls) connects this token to primary actions and other form controls. The default `color="primary"` is unchanged.

The Overview includes all four states:

| State | Track and thumb | Interaction |
| --- | --- | --- |
| Enabled, off | Neutral track; thumb at the start | Can toggle |
| Enabled, on | Accent track; thumb at the end | Can toggle |
| Disabled, off | Neutral disabled track; thumb at the start without a shadow | Cannot toggle |
| Disabled, on | Muted accent track; thumb at the end without a shadow | Cannot toggle |

On a phone the switch takes the measures of a native iOS 27.2 switch: a 63 × 28px track with a 37 × 24px thumb 2px in from its end, and an off track in the tertiary label color. The thumb casts no shadow, as the native one, a disabled switch keeps its enabled colors at half opacity, and while it is held the thumb turns into a clear lens of glass over the track.

Switch reads these component tokens. Override them at any scope to restyle it:

- `--field-label-font-weight`: label font weight (default `var(--font-weight-medium)`)
- `--switch-label-gap`: label gap (default `spacing(2)`)
- `--switch-thumb-color`: thumb color (default `light-dark(var(--gray-0), var(--gray-1000))`)
- `--switch-thumb-color-disabled`: thumb color disabled (default `light-dark(var(--gray-0), var(--gray-800))`)
- `--switch-thumb-offset`: thumb offset (default `3px`)
- `--switch-thumb-shadow`: thumb shadow (default `0 1px 2px rgb(0 0 0 / 20%)`; on a phone `none`)
- `--switch-thumb-size`: thumb size
- `--switch-accent-color`: checked track color when `color="accent"` (default `light-dark(#34c759, #30d158)`)
- `--switch-track-color`: track color (default `light-dark(var(--gray-150), var(--gray-400))`; on a phone with `touch.css` the tertiary label `--mobile-label-tertiary`, falling back to `--alpha-25`: the native off track)
- `--switch-track-color-checked`: track color checked (default `light-dark(var(--gray-900), var(--blue-400))`)
- `--switch-track-color-checked-disabled`: track color checked disabled (default `light-dark(var(--gray-300), var(--blue-700))`; a phone dims the enabled colors instead)
- `--switch-track-color-disabled`: track color disabled (default `light-dark(var(--gray-100), var(--gray-300))`; a phone dims the enabled colors instead)
- `--switch-track-color-hover`: track color hover (default `light-dark(var(--gray-200), var(--gray-450))`; on a phone `--alpha-30`)
- `--switch-track-height`: track height (default `19px`)
- `--switch-track-width`: track width (default `32px`)
