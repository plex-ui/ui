## Styling

Set `--switch-accent-color` once in your application's theme stylesheet for every `color="accent"` switch. The [shared application accent recipe](/docs/foundations/colors#shared-application-accent) connects this token to primary actions and other form controls. The default `color="primary"` is unchanged.

The Overview includes all four states:

| State | Track and thumb | Interaction |
| --- | --- | --- |
| Enabled, off | Neutral track; thumb at the start | Can toggle |
| Enabled, on | Accent track; thumb at the end | Can toggle |
| Disabled, off | Neutral disabled track; thumb at the start without a shadow | Cannot toggle |
| Disabled, on | Muted accent track; thumb at the end without a shadow | Cannot toggle |

Switch reads these component tokens. Override them at any scope to restyle it:

- `--field-label-font-weight`: label font weight (default `var(--font-weight-medium)`)
- `--switch-label-gap`: label gap (default `spacing(2)`)
- `--switch-thumb-color`: thumb color (default `light-dark(var(--gray-0), var(--gray-1000))`)
- `--switch-thumb-color-disabled`: thumb color disabled (default `light-dark(var(--gray-0), var(--gray-800))`)
- `--switch-thumb-offset`: thumb offset (default `3px`)
- `--switch-thumb-shadow`: thumb shadow (default `0 1px 2px rgb(0 0 0 / 20%)`)
- `--switch-thumb-size`: thumb size
- `--switch-accent-color`: checked track color when `color="accent"` (default `light-dark(#34c759, #30d158)`)
- `--switch-track-color`: track color (default `light-dark(var(--gray-150), var(--gray-400))`; on a phone with `touch.css` `--alpha-25`, the native off track)
- `--switch-track-color-checked`: track color checked (default `light-dark(var(--gray-900), var(--blue-400))`)
- `--switch-track-color-checked-disabled`: track color checked disabled (default `light-dark(var(--gray-300), var(--blue-700))`)
- `--switch-track-color-disabled`: track color disabled (default `light-dark(var(--gray-100), var(--gray-300))`; on a phone `--alpha-15`)
- `--switch-track-color-hover`: track color hover (default `light-dark(var(--gray-200), var(--gray-450))`; on a phone `--alpha-30`)
- `--switch-track-height`: track height (default `19px`)
- `--switch-track-width`: track width (default `32px`)
