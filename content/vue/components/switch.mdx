## Styling

Switch reads these component tokens. Override them at any scope to restyle it:

- `--field-label-font-weight`: label font weight (default `var(--font-weight-medium)`)
- `--switch-label-gap`: label gap (default `spacing(2)`)
- `--switch-thumb-color`: thumb color (default `light-dark(var(--gray-0), var(--gray-1000))`)
- `--switch-thumb-color-disabled`: thumb color disabled (default `light-dark(var(--gray-0), var(--gray-800))`)
- `--switch-thumb-offset`: thumb offset (default `3px`)
- `--switch-thumb-shadow`: thumb shadow (default `0 1px 2px rgb(0 0 0 / 20%)`)
- `--switch-thumb-size`: thumb size
- `--switch-track-color`: track color (default `light-dark(var(--gray-150), var(--gray-400))`)
- `--switch-track-color-checked`: track color checked (default `light-dark(var(--gray-900), var(--blue-400))`)
- `--switch-track-color-checked-disabled`: track color checked disabled (default `light-dark(var(--gray-300), var(--blue-700))`)
- `--switch-track-color-disabled`: track color disabled (default `light-dark(var(--gray-100), var(--gray-300))`)
- `--switch-track-color-hover`: track color hover (default `light-dark(var(--gray-200), var(--gray-450))`)
- `--switch-track-height`: track height (default `19px`)
- `--switch-track-width`: track width (default `32px`)
