<UsageBlock>{`import { Input, InputAdornmentButton } from "@plexui/vue/components/Input";`}</UsageBlock>

On Phone, put an input in a row of a `FieldGroup`, as the [Form Examples](/vue/components/form-examples) do. The row is its frame and sets its height, insets and type, so the Phone previews show rows without the `size`, `gutter-size`, `pill` and `variant` controls.

### Optical alignment

Use `optically-align` with either `"start"` or `"end"` to offset the gutter, aligning the input text with surrounding content. Works with `Field`: pass `optically-align` on the Field and it forwards to the child control automatically. On Phone, a row starts its label and its text at the row's inset, so there is nothing to offset.

<ComponentPreview className={phoneRowsStyles.PhoneRowsPreview} language="vue" code={withPhone(opticalAlign, opticalAlignPhone, "the help is the group's footer.")}>

    template={opticalAlign}

    ]}
  />
</ComponentPreview>

Input shares the unified 9-step size scale with Button, Select, SelectControl, and SegmentedControl: set the same `size` on adjacent controls and they'll align perfectly. On a phone with `touch.css`, `sm` to `xl` are all 44px.

## Styling

Input reads these component tokens. Override them at any scope to restyle it:

- `--input-border-color-invalid`: border color invalid (default `var(--color-border-danger-outline)`)
- `--input-gap-lg`: gap lg (default `10px`)
- `--input-gap-md`: gap md (default `8px`)
- `--input-gap-sm`: gap sm (default `6px`)
- `--input-gap-xs`: gap xs (default `4px`)
- `--input-outline-border-color`: outline border color (default `var(--color-border-primary-outline)`)
- `--input-outline-border-color-focus`: outline border color focus (default `var(--alpha-50)`)
- `--input-outline-border-color-hover`: outline border color hover (default `light-dark(var(--alpha-25), var(--alpha-30))`)
- `--input-placeholder-text-color`: placeholder text color (default `var(--color-text-tertiary)`)
- `--input-soft-background-color`: soft background color (default `var(--color-background-primary-soft-alpha)`)
- `--input-soft-border-color-focus`: soft border color focus (default `var(--alpha-20)`)
- `--input-text-color`: text color (default `var(--color-text)`)
