On Phone, put an input in a row of a `FieldGroup`, as the [Settings Forms](/vue/components/settings-forms) do. The row is its frame and sets its height, insets and type, so the Phone previews show rows without the `size`, `gutter-size`, `pill` and `variant` controls.

### Overview

<ComponentPreview className={phoneRowsStyles.PhoneRowsPreview} language="vue" details={<>
  <p>Use <code>variant</code> to stylize the input. <code>ghost</code> has no border and no fill, for a field its container already frames, such as the search line at the top of a dialog; it still turns red when <code>invalid</code>. <code>size</code> sets the control <code>height</code> and gives a <code>gutter-size</code> (the horizontal padding) and a <code>font-size</code>, each of which can be overridden; Input shares the 9-step size scale with Button, Select, SelectControl and SegmentedControl, so adjacent controls of one <code>size</code> line up. <code>pill</code> rounds it fully. Bind the text with <code>v-model:value</code>.</p>
  <p>The <code>startAdornment</code> slot puts content before the value, such as a prefix or a search icon, and the <code>endAdornment</code> slot after it, such as a character counter. <code>gutter-size</code> sets the space at the edges (a negative margin on the adornment, such as <code>-ml-2</code>, fine-tunes it), and <code>gap</code> on the container the space between the adornment and the value. Listening to <code>@clear</code> shows a built-in clear button while the input has a value and is not disabled or read-only (bind <code>:on-clear</code> to show it under a condition); clicking it keeps focus in the input. <code>optically-align</code> (<code>"start"</code> or <code>"end"</code>) offsets the gutter so the text lines up with the content around it, here the label; on a <code>Field</code> it is forwarded to its control.</p>
  <p><code>auto-select</code> selects all the text, useful with copy actions; it acts when toggled and leaves the selection free to change. Autofill extensions are prevented by default; <code>allow-autofill-extensions</code> lets them in, and a <code>name</code> or <code>type="password"</code> turns it on by default. <code>read-only</code> keeps the value and hides the clear button. <code>disabled</code> greys the input out and blocks interaction. <code>invalid</code> marks it invalid, with <code>[data-invalid]</code> on the container; you decide how the state is removed (<code>@focus</code>, <code>@update:value</code>, a submit handler).</p>
  <p>On Phone the row is the frame and sets the height, insets and type, so the input takes no <code>variant</code>, <code>size</code>, <code>gutter-size</code>, <code>pill</code> or <code>optically-align</code>; with <code>touch.css</code> the <code>3xs</code> to <code>xl</code> sizes are all 44px. The value stands at the end of the row, at one column for the whole group with <code>FieldGroup columns</code>, or under the label with <code>orientation="vertical"</code>, where it is <code>ghost</code>. A start adornment is a prefix of the value and trailing <code>text-secondary</code> text takes the row's accessory color; the clear button is the filled circle of an iOS text field, shown only while the value is being edited, and a long value stops 6px before it. An error is the row's <code>error-message</code> under it. Browser autofill extensions are a desktop matter: on iOS autofill comes from the system above the keyboard. An Input in a <a href="/vue/components/toolbar#overview">Toolbar</a> takes the bar's search field, and one with <code>type="search"</code> at the top of the content is <a href="/vue/components/toolbar#search-in-the-content">the same glass field</a> under a large title.</p>

Plex UI also provides a `FieldError` component (`@plexui/vue/components/FieldError`) that pairs well with invalid inputs. ## Styling

Input reads these component tokens. Override them at any scope to restyle it:

- `--input-border-color-invalid`: border color invalid (default `var(--color-border-danger-outline)`)
- `--input-gap-lg`: gap lg (default `10px`)
- `--input-gap-md`: gap md (default `8px`)
- `--input-gap-sm`: gap sm (default `6px`)
- `--input-gap-xs`: gap xs (default `4px`)
- `--input-outline-border-color`: outline border color (default `var(--color-border-primary-outline)`)
- `--input-outline-border-color-focus`: outline border color focus (default `var(--alpha-50)`)
- `--input-outline-border-color-hover`: outline border color hover (default `light-dark(var(--alpha-25), var(--alpha-30))`)
