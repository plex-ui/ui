## Styling

Breadcrumb reads these component tokens. Override them at any scope to restyle it:

- `--breadcrumb-font-size`: text size (`--font-text-sm-size`, or `--font-text-xs-size` at `sm`)
- `--breadcrumb-line-height`: line height
- `--breadcrumb-gap`: space around separators (`spacing(1)`, or `spacing(0.5)` at `sm`)

Links use the secondary text color and turn to the text color on hover; the current page uses the text color; separators use the tertiary color.
