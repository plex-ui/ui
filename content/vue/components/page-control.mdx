A page control shows the position of the current page in an ordered list of peer pages, such as a carousel or onboarding, and moves between them. Center it below the pages. More than about ten dots are hard to count at a glance; for longer lists, prefer a grid. It follows the iOS 26 kit Page control on every screen: 8px dots 8px apart in a 24px capsule, with a 44px target on a phone.

## API

<PropsTable data={[
  { prop: "count", type: "number", description: "Number of pages" },
  { prop: "value", type: "number", description: "Controlled index of the current page, from 0; bind with v-model:value" },
  { prop: "default-value", type: "number", default: "0", description: "Initial page (uncontrolled)" },
  { prop: "background", type: '"automatic" | "prominent" | "minimal"', default: '"automatic"', description: "When the capsule behind the dots shows; minimal also turns off scrubbing" },
  { prop: "value-text", type: "(index: number, count: number) => string", default: "Page 2 of 5", description: "Text assistive technology reads for the current page" },
  { prop: "aria-label", type: "string", default: '"Pages"', description: "Name of the page control, when no visible label names it" },
  { prop: "aria-labelledby", type: "string", description: "The id of the visible label of the page control" },
  { prop: "aria-controls", type: "string", description: "The id of the element that shows the pages" },
  { prop: "id", type: "string", description: "The id of the page control" },
]} />

**Events**: `update:value` with the index of the next page; `change` with the index and `{ scrubbing }`, true while a drag scrubs; `focus` and `blur`.

The page control is a slider whose value is the page, read as Page 2 of 5, as VoiceOver reads the native control as adjustable. With the keyboard, Left and Right (mirrored in a right-to-left layout) or Up and Down move one page, Home and End go to the first and last page. The dots are presentation only.

## Styling

PageControl reads these component tokens. Override them at any scope to restyle it:

- `--page-control-height`, `--page-control-padding-inline`: the capsule (default `24px`, `12px`)
- `--page-control-gap`: space between dots (default `8px`)
- `--page-control-dot-size`, `--page-control-dot-size-small`, `--page-control-dot-size-smaller`: the full dot and the two shrinking ones (default `8px`, `6px`, `4px`)
- `--page-control-dot-color`, `--page-control-dot-color-current`: the dots (default `var(--alpha-30)`, `var(--color-text)`; the other dots in the tertiary label, `--mobile-label-tertiary`, on a phone with `touch.css`)
- `--page-control-background`: the capsule fill with `automatic` and `prominent` (default `var(--alpha-08)`)
- `--page-control-target-size`: height of the touch target (`44px` at 767px and below)
- `--page-control-transition-duration`: how fast dots change (default `200ms`, none with reduced motion)
