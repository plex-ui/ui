### Overview

<ComponentPreview phonePresentation="none" language="vue" details={<>An avatar shows one of four things. Without other props it shows the first letter of <code>name</code>. With <code>image-url</code>, an absolute URL, it shows the photo with a soft fade once it loads, and the initial if it fails. With <code>Icon</code>, an icon component such as <code>Robot</code> from <code>@plexui/vue/components/Icon</code>, it shows the icon; <code>name</code> is not shown, and only names the avatar when it is a button. With <code>overflow-count</code> it shows the count, formatted and scaled to fit. <code>size</code> sets the width and height in pixels, and the initial, icon and count scale with it. <code>color</code> and <code>variant</code> style every avatar except a loaded photo, which covers them. Avatars are fully rounded by default; a Tailwind rounding class in <code>class</code> overrides that. Listening to <code>@click</code> (or <code>@pointerdown</code>) makes the avatar a <code>button</code> with interaction styles and its <code>name</code> as the accessible name.</>} code={overview} previewMinHeight={228}>

## Styling

Avatar reads these component tokens. Override them at any scope to restyle it:

- `--avatar-font-size-scaling`: font size scaling (default `0.5`)
- `--avatar-group-cutout-color`: cutout color (default `var(--color-surface)`)
- `--avatar-group-cutout-width`: cutout width (default `3px`)
- `--avatar-group-spacing`: spacing (default `-8px`)
- `--avatar-image-border-color`: image border color (default `light-dark(var(--alpha-04), var(--alpha-15))`)
- `--avatar-overflow-font-size-scaling-one`: overflow font size scaling one (default `0.45`)
- `--avatar-overflow-font-size-scaling-three`: overflow font size scaling three (default `0.3`)
- `--avatar-overflow-font-size-scaling-two`: overflow font size scaling two (default `0.37`)
- `--avatar-radius`: radius (default `var(--radius-full)`)
- `--avatar-size`: size (default `28px`)
