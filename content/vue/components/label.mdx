For stacked form fields, prefer [`Field`](/vue/components/field): it bundles label, description, and error handling. Reach for a standalone `Label` when you pair it directly with a checkbox, switch, or any control where Field's layout is overkill.

## API

### Label

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `for` | `string` | | `id` of the associated control. Clicks on the label focus or activate the control. |
| `class` | `string` | | Applied to the root `<label>` element |
| default slot | `VNode[]` | | Label content |

Built on [Reka UI Label](https://reka-ui.com/docs/components/label), which prevents text selection on double-click and forwards clicks to the associated control. All other `<label>` attributes are forwarded.

## Styling

Component tokens:

- `--label-color`: text color (defaults to `--color-text`)
- `--label-font-size`: text size (defaults to `--font-text-sm-size`)
- `--label-font-weight`: weight (defaults to `--font-weight-medium`)
- `--label-line-height`: line height (defaults to `1`)
