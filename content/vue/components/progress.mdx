## API

### Progress

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `value` | `number \| null` | `null` | Current progress between `0` and `max`. Pass `null` for indeterminate. |
| `max` | `number` | `100` | Maximum progress value |
| `segments` | `ProgressSegment[]` | | Parts of one bar side by side: `{ value, color?, label? }`, `color` one of `primary`, `secondary`, `success`, `warning`, `caution`, `danger`, `info`, `discovery`. Takes the place of `value`. |
| `get-value-label` | `(value: number, max: number) => string` | | Accessible value text (`aria-valuetext`). Defaults to the rounded percentage, e.g. `"67%"`. |
| `class` | `string` | | Applied to the root `<div>` |

Built on [Reka UI Progress](https://reka-ui.com/docs/components/progress). Other attributes are forwarded to the root `<div>`.

## Styling

Component tokens:

- `--progress-height`: track height (defaults to `4px`)
- `--progress-track-color`: track background (defaults to `--color-background-secondary-soft`)
- `--progress-indicator-color`: fill color (defaults to `--color-text`)
- `--progress-radius`: corner radius (defaults to `--radius-full`)
- `--progress-indeterminate-duration`: sweep duration (defaults to `1.5s`)
- `--progress-segment-gap`: the track between the parts of a segmented bar (defaults to `2px`)
- `--progress-segment-color`: a part's color (set by its `color`, from the solid background of that color)

Override at any scope to change the bar's look without subclassing.
