## Phone

Under 768px the header is one row of 44px over the page. It floats: at rest nothing shows, and content scrolled under it turns it to glass with a hairline. The content keeps its place through `--page-top`, the top inset and the bar together, also for anything else that has to start below the bar, such as a banner.

Keep the row to a title and one group of actions. The bar has no room for a second row, so anything set under `PageBar`, such as a search field, belongs at the top of `PageContent` on a phone. `useBreakpoint("md")` tells which one to render. The first column of the bar stays free for the menu button of a sidebar.

Use it inside `SidebarInset` for a whole app, see the [app sidebar](/vue/components/sidebar#app).

## API

### Page

<PropsTable data={[
  { prop: "width", type: '"full" | "wide" | "column"', default: '"full"', description: "Column that header and content share: edge to edge, 1280px or 768px, centred" },
  { prop: "class", type: "string", description: "Class of the root element" },
]} />

All other attributes fall through to the root.

### PageHeader

<PropsTable data={[
  { prop: "divider", type: "boolean", default: "true", description: "Shows the line, and the glass on a phone, once the content has scrolled under the header" },
  { prop: "class", type: "string", description: "Class of the band" },
]} />

The default slot stands in the shared column. All other attributes fall through to the band.

### PageContent

<PropsTable data={[
  { prop: "fill", type: "boolean", default: "false", description: "The content fills the page and scrolls inside itself, from 768px up" },
  { prop: "class", type: "string", description: "Class of the element that scrolls" },
]} />

The default slot stands in the shared column. All other attributes, listeners included, fall through to the element that scrolls. Its template ref is the component: read the element from `$el`.

### PageFooter

Actions stay below the scrolling `PageContent`. The footer shares the page column and includes at least 16px of bottom padding, or the device's bottom safe area when larger. Give `Page` a bounded height, such as `100dvh`, to keep the footer at the bottom of the screen. Native div attributes are forwarded to the footer.

### Parts

| Part | Element | Purpose |
|------|---------|---------|
| `PageBar` | `<div>` | Row of the title and the actions |
| `PageHeading` | `<div>` | Title with what stands beside it |
| `PageTitle` | `<h1>` | Page heading |
| `PageSubtitle` | `<p>` | Status of the page |
| `PageActions` | `<div>` | Buttons on the trailing side of the bar |

## Styling

Page reads these component tokens. Override them at any scope to restyle it:

- `--page-background`: background (default `var(--color-surface)`)
- `--page-bar-gap`: gap between title and actions (default `24px`)
- `--page-bar-height`: bar height (default `36px`)
- `--page-bar-height-phone`: bar height on a phone (default `44px`)
- `--page-bar-line`: hairline of the glass bar (default `light-dark(rgb(0 0 0 / 10%), var(--color-border))`)
- `--page-bar-veil`: fill of the glass bar (default `light-dark(rgb(255 255 255 / 72%), rgb(0 0 0 / 60%))`)
- `--page-content-padding-bottom`: bottom of the content (default `48px`)
- `--page-content-padding-top`: top of the content on a phone (default `16px`)
- `--page-gutter`: side gutter on a phone (default `16px`)
- `--page-gutter-wide`: side gutter and top of the content from 768px up (default `24px`)
- `--page-header-padding-bottom`: gap between the bar and the line (default `12px`)
- `--page-header-padding-top`: top of the header (default `12px`)
- `--page-title-font-size`: title font size (default `20px`)
- `--page-title-line-height`: title line height (default `26px`)
- `--page-width`: width of the column, any value
- `--page-width-column`: `column` width (default `768px`)
- `--page-width-wide`: `wide` width (default `1280px`)

### Footer spacing

`Page.Footer` stays below the scrolling content. Set `--page-footer-gutter` when its primary action needs a larger horizontal inset than the fields. `--page-footer-padding-bottom` controls the space below it, including the safe area.

```css
.mobile-form {
  --page-footer-gutter: 24px;
  --page-footer-padding-bottom: max(24px, env(safe-area-inset-bottom, 0px));
}
```
