## API

### NavigationRow

<PropsTable data={[
  { prop: "label", type: "string | number", description: "The name of the row, where a row's label starts (or the `label` slot)" },
  { prop: "value", type: "string | number | null", description: "The current value, at the end of the row in the secondary label color (or the `value` slot). `0` shows; `null`, `undefined` and `\"\"` do not" },
  { prop: "description", type: "string | number", description: "A line under the label; the row grows from 52px to hold it (or the `description` slot, where a `<br />` starts a second line)" },
  { prop: "to", type: "string | object", description: "A router target: with it the row is a link, through the `linkComponent` of `PlexUIProvider`" },
  { prop: "href", type: "string", description: "Where the row goes, as a plain link" },
  { prop: "as", type: "Component | \"a\"", description: "The link component, such as a router's link" },
  { prop: "external", type: "boolean", description: "Treats the link as one out of the app (a new tab)" },
  { prop: "disabled", type: "boolean", default: "false", description: "The row can't be pressed. A disabled link renders as a disabled button, so it never navigates" },
  { prop: "disclosure", type: "boolean", default: "true", description: "The chevron at the end. `false` drops it, for a row that opens a record rather than a page of choices (the Contacts list of iOS); the row is still one press" },
  { prop: "valuePlacement", type: "\"end\" | \"below\" | \"auto\"", default: "\"end\"", description: "Where the value stands: at the end of the row, under the label at the full width, or `auto`: at the end while it fits beside the label on one line, otherwise under it" },
]} />

**Slots**: `label`, `value`, `description`, in place of their props; `leading`, what leads the row (an `Avatar` or a picture) in a column before the label, on the label's first line (a taller avatar starts at its top), the line above the row starting after it.

**Events**: `click`, when the row is pressed.

**Exposed**: `element`, the pressable (the button, or the element of the link), and `focus()`.

Every other attribute (an `id`, a `class`, listeners, ARIA and data attributes) goes to the pressable. The row says nothing of what it opens: a row that opens a dialog in place of a page sets `aria-haspopup="dialog"` and `aria-expanded` itself. The name the row reads with is its label, description and value in that order.

## Styling

NavigationRow reads the row tokens of [FieldGroup](/vue/components/field#fieldgroup) (`--field-row-min-height`, `--field-row-padding-inline`, `--field-row-label-*`, `--field-row-description-*`, `--field-row-gap`, `--field-row-disclosure-gap`) and five of its own. Override them at any scope to restyle it:

- `--navigation-row-label-color`: the label (default the text color)
- `--navigation-row-value-color`: the value (default the secondary label color; the text color with `columns`)
- `--navigation-row-disclosure-color`: the chevron (default the tertiary label color)
- `--navigation-row-leading-size`: the column of `leading`, its own size (default `40px`, an avatar; `28px` for a symbol)
- `--navigation-row-leading-gap`: from `leading` to the text (default `12px`)
