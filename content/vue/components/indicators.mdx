### Overview

A `style` attribute replaces the size, stroke and color variables these props set. All other `<span>` (LoadingIndicator) or `<div>` (CircularProgress, LoadingDots) attributes are forwarded.

## Styling

The indicators read these CSS custom properties, each with a fallback. Set them at any scope to restyle the indicators inside it:

- `--indicator-size`: `LoadingIndicator` size (defaults to `1em`, or `20px` with the touch stylesheet, also inside a field)
- `--indicator-stroke`: ring stroke width (defaults to `2px`) or mobile spoke width (defaults to the iOS 27 kit proportion of the size: 2/14 up to 16px, 4/30 to 27px, 5/35 from 28px)
- `--indicator-color`: `LoadingIndicator` color (defaults to `currentcolor`)
- `--indicator-rotate-duration`: time of one `LoadingIndicator` turn (defaults to `0.8s`)
- `--circular-progress-size`: `CircularProgress` diameter (defaults to `28px`)
- `--circular-progress-stroke`: `CircularProgress` stroke width (defaults to `2px`)
- `--circular-progress-track-color`: `CircularProgress` base track (defaults to a light green)
- `--circular-progress-track-active-color`: `CircularProgress` progress stroke (defaults to `--green-500`)

`LoadingDots` takes the current text color.
