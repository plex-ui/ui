## Reference

<PropsTable data={[
  { prop: "variant", type: '"outline" | "soft"', default: '"outline"', description: "Visual style of the editor" },
  { prop: "disabled", type: "boolean", default: "false", description: "Disable the editor" },
  { prop: "invalid", type: "boolean", default: "false", description: "Mark as invalid" },
  { prop: "placeholder", type: "string", description: "Placeholder text when empty" },
  { prop: "value / v-model:value", type: "string", description: "Controlled markdown value; `update:value` fires on every change" },
  { prop: "default-value", type: "string", description: "Initial markdown for uncontrolled mode" },
  { prop: "@change", type: "(markdown: string) => void", description: "Called on content change" },
  { prop: "#toolbarEnd", type: "slot", description: "Content rendered at the end of the toolbar" },
  { prop: "rows", type: "number", default: "1", description: "Minimum visible rows" },
]} />

`class` applies to the container. `id`, `aria-describedby` and `aria-invalid` go to the editable element. Like the React component, `update:value` and `change` also fire once when the editor is created and whenever `disabled` changes.
