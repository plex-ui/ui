title: Design Tokens
description: Plex UI design tokens reference. Every color, radius, typography, shadow, and motion variable exposed as CSS custom properties and Tailwind classes
---

Plex UI ships a set of CSS custom properties (design tokens) that drive all visual styling: colors, typography, radii, shadows, and motion. Use these tokens in your own components to stay consistent with the system. Each token below is a custom property of the same name (for example `--color-text-secondary`, `--radius-md`, `--shadow-200`) that you can reference in Tailwind classes or plain CSS. The `--breakpoint-*` values are defined by the opt-in `@plexui/ui/styles/variables-tailwind-theme.css` import ([Installation](/docs/installation#using-the-full-plex-scale-in-your-tailwind-utilities-opt-in)).
