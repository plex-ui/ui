---
title: Foundations
description: Design tokens, color palettes, and typography that underpin every Plex UI component
---

The visual language of Plex UI is built on three foundational layers. Every component, demo, and example in these docs sits on top of them.

- **[Design tokens](/docs/foundations/design-tokens)**: the CSS custom properties (`--color-*`, `--font-*`, `--radius-*`, `--shadow-*`, `--transition-*`, `--cubic-*`) that drive all visual styling. Use these in your own components to stay consistent with the system without hardcoding values.
- **[Colors](/docs/foundations/colors)**: primitive color palettes exposed as CSS variables, designed to work seamlessly with light and dark modes. Reference the semantic tokens (`text-primary`, `bg-surface`, etc.) instead of raw palette values.
- **[Typography](/docs/foundations/typography)**: the heading and text scale (`heading-5xl` to `text-3xs`) with size, weight, line-height, and tracking baked in. Exposed to Tailwind as `text-*` and `heading-*` utilities.

Plex UI components consume these foundations directly, so anything you build alongside the system inherits the same visual rhythm by reusing the same tokens.
