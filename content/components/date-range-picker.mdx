### Limits

<ComponentPreview details={<>Use <code>min</code> and <code>max</code> to limit the selectable range. Use <code>maxRangeDays</code> to limit the range length.     pill

### Shortcuts

<ComponentPreview details={<>Use the <code>shortcuts</code> array to provide quick date range options. When a shortcut is selected, its label is shown in the trigger. Each shortcut has a <code>label</code> and a <code>getDateRange()</code> function. A shortcut whose range falls outside <code>min</code> and <code>max</code>, or is longer than <code>maxRangeDays</code>, is disabled.</>} code={`const dayShortcuts: DateRangeShortcut[] = [
  {
    label: "Today",
    getDateRange: () => {
      const today = DateTime.local()
      return [today.startOf("day"), today.endOf("day")]
    },
  },
  {
    label: "Yesterday",
    getDateRange: () => {
      const yesterday = DateTime.local().minus({ days: 1 })
      return [yesterday.startOf("day"), yesterday.endOf("day")]
    },
  },
  {
    label: "Last 7 days",
    getDateRange: () => {
      const today = DateTime.local().endOf("day")
      return [today.minus({ days: 6 }).startOf("day"), today]
    },
  },
  {
    label: "Last 30 days",
    getDateRange: () => {
      const today = DateTime.local().endOf("day")
      return [today.minus({ days: 29 }).startOf("day"), today]
    },
  },
]
const [value, setValue] = useState<DateRange | null>(null)

<div style={{ width: "fit-content" }}>
  <DateRangePicker
    size="lg"
    pill
    clearable
    value={value}
    onChange={setValue}
    shortcuts={dayShortcuts}
  />
</div>`} previewMinHeight={168}>
  <DateRangePickerShortcutsDemo />
</ComponentPreview>

## API

In the calendars, the arrow keys move focus by a day or a week, Home and End move it to the Sunday or Saturday of the week, and Page Up and Page Down move it by a month (January 31 goes to the last day of February). Focus moves across the visible months, and a day past them turns the calendars by a month first. Focus stays put when the day it would move to is disabled: outside `min` and `max`, or past `maxRangeDays` while a range is being picked. Enter and Space pick the focused day.

## Styling

Date Range Picker reads these component tokens. Override them at any scope to restyle it:

- `--input-border-color-invalid`: border color invalid (default `var(--color-border-danger-outline)`)
- `--input-outline-border-color`: outline border color (default `var(--color-border-primary-outline)`)
- `--input-outline-border-color-hover`: outline border color hover (default `light-dark(var(--alpha-25), var(--alpha-30))`)
- `--input-placeholder-text-color`: placeholder text color (default `var(--color-text-tertiary)`)
- `--input-text-color`: text color (default `var(--color-text)`)
- `--select-control-font-weight`: font weight (default `var(--font-weight-normal)`)
