On Phone, a select control is the value of a row in a `FieldGroup`, as the [Settings Forms](/components/settings-forms) do: the value and its up-down chevrons sit at the row's end, like an iOS pop-up button. The row sets the control's height, insets, type and colors, so the Phone previews show rows without the `size`, `pill`, `variant`, `StartIcon`, `dropdownIconType`, `block` and `opticallyAlign` controls.

The same module exports `DropdownIcon` for custom menu triggers. Its `iconType` accepts `"dropdown"` or `"chevronDown"`; the indicator keeps its proportions inside a Button.

## API

Use `SelectControl` with any floating UI (e.g. `Menu`, `Popover`). The control renders the trigger; you provide the dropdown content. `children` is the control's content. Other props land on the control's `<span role="button">`; `onKeyDown` receives only the keys the control does not handle itself. To decide when the control opens (or to keep it closed), pass `onInteract` and control the dropdown's `open` state yourself: the wrapping trigger then no longer opens on its own.

## Styling

Select Control reads these component tokens. Override them at any scope to restyle it:

- `--input-border-color-invalid`: border color invalid (default `var(--color-border-danger-outline)`)
- `--input-outline-border-color`: outline border color (default `var(--color-border-primary-outline)`)
- `--input-outline-border-color-hover`: outline border color hover (default `light-dark(var(--alpha-25), var(--alpha-30))`)
- `--input-placeholder-text-color`: placeholder text color (default `var(--color-text-tertiary)`)
- `--input-text-color`: text color (default `var(--color-text)`)
- `--select-control-font-weight`: font weight (default `var(--font-weight-normal)`)
