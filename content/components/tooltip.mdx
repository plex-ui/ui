## Examples

Tooltips provide supplementary information on hover or keyboard focus. Touch-only users need visible helper text or a tap-triggered [Popover](/components/popover). The Overview uses pointer and keyboard interactions, so it has no separate Phone preview. For copying, [Copy Tooltip](#copy-tooltip) confirms the action after a successful tap.

## API

### Tooltip

<PropsTable data={[
  { prop: "children", type: "ReactElement", description: "The trigger: a single element. Wrap plain text in Tooltip.TriggerDecorator" },

  { prop: "sideOffset", type: "number", default: "5", description: "Distance from trigger" },

  { prop: "alignOffset", type: "number", default: "0", description: "Alignment offset" },
  { prop: "gutterSize", type: '"sm" | "md" | "lg"', default: '"md"', description: "Content padding" },
  { prop: "contentClassName", type: "string", description: "Class for tooltip content" },
  { prop: "forceOpen", type: "boolean", description: "Force open or closed" },
  { prop: "preventUnintentionalClickToClose", type: "true", description: "Keeps the tooltip open when the trigger is clicked right after it opened" },
]} />

The tooltip content is the `role="tooltip"` element, and the trigger points at it with `aria-describedby`. Other props, such as `onClick` and `onPointerDown`, go to the trigger element. `Tooltip.TriggerDecorator` turns text into an accessible trigger with the decorator style and a tab stop (`focusable`, default `true`).

## Styling

Tooltip and Copy Tooltip have no component tokens of their own. It reads the shared semantic color, typography and spacing tokens listed in [Design tokens](/docs/foundations/design-tokens), so it follows theme changes made there.
