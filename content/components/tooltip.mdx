## Examples

Tooltips provide supplementary information on hover or keyboard focus. Touch-only users need visible helper text or a tap-triggered [Popover](/components/popover). These examples use pointer and keyboard interactions, so they do not have a separate Phone preview. For copying, [Copy Tooltip](/components/copy-tooltip) confirms the action after a successful tap.

The tooltip content is the `role="tooltip"` element, and the trigger points at it with `aria-describedby`. Other props, such as `onClick` and `onPointerDown`, go to the trigger element. `Tooltip.TriggerDecorator` turns text into an accessible trigger with the decorator style and a tab stop (`focusable`, default `true`).

## Styling

Tooltip has no component tokens of its own. It reads the shared semantic color, typography and spacing tokens listed in [Design tokens](/docs/foundations/design-tokens), so it follows theme changes made there.
