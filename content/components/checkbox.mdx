On Phone, a single checkbox stays next to its label, while a list of options goes in the rows of a `FieldGroup`: each `Field row` names an option and ends with the checkbox, as in an iOS settings list.

### Overview

<ComponentPreview details={<>
  <p>A checkbox is checked, unchecked or indeterminate. Pass <code>checked="indeterminate"</code>, or <code>defaultChecked="indeterminate"</code>, for a partly selected state: a "select all" box whose items are only partly checked, as in <a href="#group-with-select-all">Group with select all</a>.</p>
  <p><code>solid</code> (default) fills the box; <code>ghost</code> renders only the checkmark, in the text color, without a border or background, for subtle inline selections or task lists. <code>pill</code> rounds the box (<code>border-radius: full</code>): the solid fill, and on a ghost box its hover tint and focus ring.</p>
  <p>Use <code>description</code> for a second line under the label. It sits outside the label, so the checkbox keeps the label as its name and gets the description through <code>aria-describedby</code>. By default the box is on the left of its label; <code>orientation="right"</code> places it after the label. Both act only next to a label, so they are offered only with one. Without a <code>label</code> the checkbox is a standalone control: pass <code>aria-label</code> to name it.</p>
  <p><code>disabled</code> keeps the checked and indeterminate states.</p>
  <p>On a phone with <code>touch.css</code> a solid checkbox is the 22px selection circle of iOS with or without <code>pill</code>, so the phone view has no <code>pill</code> setting. A ghost checkbox is the checkmark of an iOS list row.</p>
</>} code={`const [variant, setVariant] = useState("solid")
const [pill, setPill] = useState(false)
const [label, setLabel] = useState(true)
const [description, setDescription] = useState(false) // with a label
const [orientation, setOrientation] = useState("left") // with a label
const [disabled, setDisabled] = useState(false)

const options = [
  { label: "Share usage data", description: "Help improve the product with anonymous usage reports.", defaultChecked: true },
  { label: "Enable notifications", description: "You can enable or disable notifications at any time from settings.", defaultChecked: false },
  { label: "Sync all folders", description: "Some of its folders are synced.", defaultChecked: "indeterminate" },
]

<div className={label ? (description ? "flex flex-col gap-4 max-w-sm" : "flex flex-col gap-3") : "flex gap-4"}>
  {options.map((option) => (
    <Checkbox
      key={option.label}
      variant={variant}
      pill={pill}
      disabled={disabled}
      defaultChecked={option.defaultChecked}
      {...(label
        ? { label: option.label, description: description ? option.description : undefined, orientation }
        : { "aria-label": option.label })}
    />
  ))}
</div>`} previewMinHeight={200}>

</ComponentPreview>

### Group with select all

<ComponentPreview details={<>Combine a parent checkbox with child checkboxes to create a "select all" pattern. The parent shows an <code>indeterminate</code> state when only some children are checked. Each child is controlled by its item in <code>items</code>.</>} code={`const [items, setItems] = useState([
  { id: "read", label: "Read", checked: true },
  { id: "write", label: "Write", checked: false },
  { id: "execute", label: "Execute", checked: false },
])

const allChecked = items.every((i) => i.checked)
const noneChecked = items.every((i) => !i.checked)
const parentChecked = allChecked ? true : noneChecked ? false : "indeterminate"

<div className="flex flex-col gap-3">
  <Checkbox
    label="Permissions"
    checked={parentChecked}
    onCheckedChange={() => {
      const next = !allChecked
      setItems((prev) => prev.map((i) => ({ ...i, checked: next })))
    }}
  />
  <div className="flex flex-col gap-3 pl-6">
    {items.map((item) => (
      <Checkbox
        key={item.id}
        label={item.label}
        checked={item.checked}
        onCheckedChange={(next) => {
          setItems((prev) => prev.map((i) => (i.id === item.id ? { ...i, checked: Boolean(next) } : i)))
        }}
      />
    ))}
  </div>
</div>`} previewMinHeight={240}>
  <CheckboxGroupDemo />
</ComponentPreview>

### With Field

<ComponentPreview className={phoneRowsStyles.PhoneRowsPreview} details={<>Wrap checkboxes in a <code>Field</code> component for form layout with label, description, and error message support. A single control passed as the child gets <code>aria-describedby</code> and <code>aria-invalid</code> automatically; the render-prop form receives them as arguments, so spread them onto the control that should carry them. const errorId = useId()

  description="Please review and accept the terms before continuing."

>
  {() => (
    <div className="flex flex-col gap-3 mt-1">
      <Checkbox
        label="I agree to the Terms of Service"
        checked={agreed}
        onCheckedChange={(next) => setAgreed(Boolean(next))}
      />
      <Checkbox label="I agree to the Privacy Policy" />
    </div>
  )}

    <Checkbox
      checked={agreed}
      onCheckedChange={(next) => setAgreed(Boolean(next))}

      aria-describedby={showError ? errorId : undefined}

## Styling

Checkbox reads these component tokens. Override them at any scope to restyle it:

- `--checkbox-indicator-size`: indicator size (default `var(--radio-group-indicator-size)`)
- `--checkbox-ghost-check-color`: checkmark color for the ghost variant (default `var(--gray-900)`)
- `--checkbox-checkmark-color`: checkmark color on a solid box (default `var(--gray-0)`)
- `--checkbox-check-icon-size`: size of the Check and Minus icons on a solid box (default the indicator size)
- `--checkbox-ghost-icon-size`: size of the Check and Minus icons for the ghost variant (default the indicator size; 26px in the touch stylesheet)
- `--checkbox-label-gap`: label gap (default `var(--radio-group-item-gap)`)
- `--checkbox-label-line-height`: label line height (default `var(--radio-group-item-line-height)`)
- `--input-border-color-invalid`: border color invalid (default `var(--color-border-danger-outline)`)
