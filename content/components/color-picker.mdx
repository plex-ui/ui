### ColorPicker

<PropsTable data={[
  { prop: "value", type: "string", description: "The controlled color, `#rrggbb` or `#rrggbbaa`" },
  { prop: "defaultValue", type: "string", default: "\"#000000\"", description: "The color when it is initially rendered" },
  { prop: "onChange", type: "(value: string) => void", description: "Called with the next color: `#rrggbb`, or `#rrggbbaa` when it is not opaque" },
  { prop: "supportsAlpha", type: "boolean", default: "true", description: "Shows the Opacity slider" },
  { prop: "mode", type: "\"grid\" | \"spectrum\" | \"sliders\"", description: "The controlled way to choose a color" },
  { prop: "defaultMode", type: "\"grid\" | \"spectrum\" | \"sliders\"", default: "\"grid\"", description: "The way to choose a color when it is initially rendered" },
  { prop: "onModeChange", type: "(mode) => void", description: "Called when another way is chosen" },
  { prop: "swatches", type: "string[]", description: "The controlled saved colors" },
  { prop: "defaultSwatches", type: "string[]", default: "[]", description: "The saved colors when it is initially rendered" },
  { prop: "onSwatchesChange", type: "(swatches: string[]) => void", description: "Called after Add saves the current color or Delete removes one" },
  { prop: "aria-label", type: "string", default: "\"Colors\"", description: "Accessible name of the picker" },
]} />

The well is a button, described by its color. In the picker, Grid and the saved colors are radio groups: the arrow keys move and choose, Home and End go to the ends of a row in Grid and to the first and last saved color. Spectrum is a slider: Up and Down change the hue, Left and Right the lightness, by 1%, or 10% with Shift or Page Up and Page Down. The Opacity and channel sliders are sliders, and their fields take a typed value on Enter or when they lose focus.

## Styling

ColorPicker and ColorWell read these component tokens. Override them at any scope to restyle them:

- `--color-picker-width`: the picker's column (default `264px`, the full width of the sheet on a phone)
- `--color-picker-body-radius`: the corner of the grid and the spectrum (default `var(--radius-xl)`, `18px` on a phone)
- `--color-picker-selection-color`: the ring of the selected cell, swatch, knob and loupe (default `#fff`)
- `--color-picker-edge-color`: the hairline inside the edge of the grid, spectrum, tracks and colors, and round the knobs and loupe, so white reads on white (default `light-dark(var(--alpha-10), var(--alpha-15))`)
- `--color-picker-label-color`: the Opacity and channel labels (default `var(--color-text)`, `var(--mobile-label-secondary)` on a phone, where they are 13px caps)
- `--color-picker-track-height` and `--color-picker-knob-size`: the sliders (default `28px` and `24px`, `34px` and `34px` on a phone)
- `--color-picker-checker`: the picker's checkerboard under a clear color, on the tracks, the current color and the saved colors (default black and white squares; on a phone light gray squares over the surface)
- `--color-picker-field-background`: the fields (default `var(--color-background-secondary-soft-alpha)`, `var(--mobile-surface-elevated-grouped-secondary)` on a phone)
- `--color-picker-add-background` and `--color-picker-add-color`: the Add button (default the field background and the text color; `#d9d9d9` and `#4a4a4a` on a phone, in both themes)
- `--color-picker-separator-color`: the line over the saved colors (default `var(--color-border)`, `light-dark(var(--alpha-20), var(--alpha-15))` on a phone)
- `--color-picker-swatch-size`: a saved color (default `24px`, `30px` on a phone)
- `--color-well-size-sm` and `--color-well-size-lg`: the well (default `28px` and `36px`)
- `--color-well-rainbow`: the ring of the well (the kit's angular gradient)
