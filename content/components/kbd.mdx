## API

### Kbd

<PropsTable data={[
  { prop: "size", type: '"xs" | "sm" | "md"', default: '"sm"', description: "Height and text size: 16px, 20px or 24px" },
  { prop: "variant", type: '"soft" | "outline"', default: '"soft"', description: "soft fills the key, outline draws its edge; both mix the text color" },
  { prop: "className", type: "string", description: "Applied to the kbd element" },
]} />

Other `<kbd>` attributes (`title`, `aria-label`, ...) are forwarded.

### Kbd.Group

A row of keys pressed together. Renders a `<span>` and forwards its attributes.

### Kbd.Modifier

<PropsTable data={[
  { prop: "name", type: '"mod" | "ctrl" | "alt" | "shift"', default: '"mod"', description: "The modifier: mod is ⌘ on an Apple keyboard and Ctrl on another" },
  { prop: "platform", type: '"apple" | "other"', description: "The keyboard to print for; by default the browser's (Apple on the server)" },
  { prop: "size", type: '"xs" | "sm" | "md"', default: '"sm"', description: "As Kbd" },
  { prop: "variant", type: '"soft" | "outline"', default: '"soft"', description: "As Kbd" },
]} />

Renders a `<kbd>`; a symbol carries its name for a screen reader. `isApplePlatform()` and `KBD_MODIFIERS` are exported for a shortcut written elsewhere, such as in `aria-keyshortcuts`.

## Styling

Kbd reads these component tokens. Override them at any scope to restyle it:

- `--kbd-background`: fill (defaults to the text color at 10%)
- `--kbd-border-color`: edge (transparent for `soft`, the text color at 24% for `outline`)
- `--kbd-color`: text color (defaults to `inherit`)
- `--kbd-radius`: corner radius (defaults to `--radius-xs`)
