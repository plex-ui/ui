A navigation row leads into what it holds, as a row of iOS Settings does: General › Language shows the language in use and opens the list to change it. Use it for a setting whose choices or details need a page of their own; for a choice made in place, use a [Select](/components/select) in a [Field](/components/field) row, and for a row that does something at once, an action row (a ghost `Button` with `block` in a `data-row`).

## API

### NavigationRow

<PropsTable data={[
  { prop: "label", type: "ReactNode", description: "The name of the row, where a row's label starts" },
  { prop: "value", type: "ReactNode", description: "The current value, at the end of the row in the secondary label color. `0` shows; `null`, `undefined`, `false` and `\"\"` do not" },
  { prop: "description", type: "ReactNode", description: "A line under the label; the row grows from 52px to hold it" },
  { prop: "href", type: "string", description: "Where the row goes: with it the row is a link, through the `linkComponent` of `PlexUIProvider`" },
  { prop: "as", type: "PlexUI.LinkComponent", description: "The link component for `href`, such as a router's link" },
  { prop: "target, rel, download", type: "string", description: "Attributes of the link, with `href`" },
  { prop: "external", type: "boolean", description: "Treats `href` as a link out of the app (a new tab)" },
  { prop: "disabled", type: "boolean", default: "false", description: "The row can't be pressed. A disabled link renders as a disabled button, so it never navigates" },
  { prop: "onClick", type: "(event: MouseEvent) => void", description: "Called when the row is pressed" },
  { prop: "ref", type: "Ref<HTMLButtonElement | HTMLAnchorElement>", description: "The pressable of the row: the button, or the element of the link" },
  { prop: "className", type: "string", description: "CSS classes applied to the pressable" },
]} />

Every other attribute (an `id`, events, ARIA and data attributes) goes to the pressable too. The row says nothing of what it opens: a row that opens a dialog in place of a page sets `aria-haspopup="dialog"` and `aria-expanded` itself. The name the row reads with is its label, description and value in that order.

## Styling

NavigationRow reads the row tokens of [FieldGroup](/components/field#fieldgroup) (`--field-row-min-height`, `--field-row-padding-inline`, `--field-row-label-*`, `--field-row-description-*`, `--field-row-gap`, `--field-row-disclosure-gap`) and three of its own. Override them at any scope to restyle it:

- `--navigation-row-label-color`: the label (default the text color)
- `--navigation-row-value-color`: the value (default the secondary label color; the text color with `columns`)
- `--navigation-row-disclosure-color`: the chevron (default the tertiary label color)
