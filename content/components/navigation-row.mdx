Every other attribute (an `id`, events, ARIA and data attributes) goes to the pressable too. The row says nothing of what it opens: a row that opens a dialog in place of a page sets `aria-haspopup="dialog"` and `aria-expanded` itself. The name the row reads with is its label, description and value in that order.

## Styling

NavigationRow reads the row tokens of [FieldGroup](/components/field#fieldgroup) (`--field-row-min-height`, `--field-row-padding-inline`, `--field-row-label-*`, `--field-row-description-*`, `--field-row-gap`, `--field-row-disclosure-gap`) and five of its own. Override them at any scope to restyle it:

- `--navigation-row-label-color`: the label (default the text color)
- `--navigation-row-value-color`: the value (default the secondary label color; the text color with `columns`)
- `--navigation-row-disclosure-color`: the chevron (default the tertiary label color)
- `--navigation-row-leading-size`: the column of `leading`, its own size (default `40px`, an avatar; `28px` for a symbol)
- `--navigation-row-leading-gap`: from `leading` to the text (default `12px`)
