## File Card

Standalone file card component. Wrap with `FileCardGroup` for the bordered container. Omit `onRemove` to hide the delete button.

### Read-only

<ComponentPreview code={`<div className="w-[360px]">
  <FileCardGroup>
    <FileCard file={file} />
  </FileCardGroup>
</div>`}>
  <FileCardDemo />
</ComponentPreview>

### With remove

<ComponentPreview code={`const [file, setFile] = useState<File | null>(initialFile)

{file ? (
  <div className="w-[360px]">
    <FileCardGroup>
      <FileCard file={file} onRemove={() => setFile(null)} />
    </FileCardGroup>
  </div>
) : (
  <div className="w-[360px] text-center text-sm text-tertiary">File removed</div>
)}`}>
  <FileCardWithRemoveDemo />
</ComponentPreview>

### Multiple files

<ComponentPreview code={`const [files, setFiles] = useState<File[]>(initialFiles)

<div className="w-[360px]">
  <FileCardGroup>
    {files.map((file, index) => (
      <FileCard
        key={\`\${file.name}-\${file.size}\`}
        file={file}
        onRemove={() => setFiles((prev) => prev.filter((_, i) => i !== index))}
      />
    ))}
  </FileCardGroup>
</div>`}>
  <FileCardListDemo />
</ComponentPreview>

### Read-only list

## Styling

File Upload reads these component tokens. Override them at any scope to restyle it:

- `--field-error-margin-top`: error margin top (default `0.5rem`)
- `--file-upload-area-border-radius`: area border radius (default `var(--radius-xl)`)
- `--file-upload-area-min-height`: area min height (default `10rem`)
- `--file-upload-gutter`: gutter (default `var(--floating-input-gutter)`)
- `--file-upload-list-gap`: list gap (default `0.5rem`)
- `--floating-input-background`: background (default `var(--color-surface)`)
- `--floating-input-border-color`: border color
- `--floating-input-border-color-hover`: border color hover
- `--floating-input-border-color-invalid`: border color invalid (default `var(--color-border-danger-outline)`)
- `--floating-input-transition-duration`: transition duration (default `80ms`)
- `--input-text-color`: text color (default `var(--color-text)`)
