<UsageBlock>{`import { FloatingLabelInput } from "@plexui/ui/components/FloatingLabelInput";`}</UsageBlock>

On Phone a label does not float: iOS has no floating label. Each field is a cell of a `FieldGroup` on the grouped background, and its placeholder names it: an [Input](/components/input), a [Textarea](/components/textarea) or a [Select](/components/select) in a `Field row hideLabel`, as the [Settings Forms](/components/settings-forms) do. The label stays for screen readers, a description goes in the group's footer, and an error stands inside the cell. The Phone previews show those cells; where the label rests and the shape of the field are desktop settings, and the Label inside example has no Phone view.

### Text fields

### FloatingLabelSelect

The trigger of a `Select` or `Menu`, or a field of your own. Its children are the selected value.

## Styling

Float Input reads these component tokens. Override them at any scope to restyle it:

- `--field-error-color`: error color (default `var(--color-text-danger-outline)`)
- `--field-error-font-size`: error font size (default `0.75rem`)
- `--field-error-line-height`: error line height (default `var(--font-text-xs-line-height)`)
- `--field-error-margin-top`: error margin top (default `0.5rem`)
- `--floating-input-background`: background (default `var(--color-surface)`)
- `--floating-input-border-color`: border color
- `--floating-input-border-color-focus`: border color focus (default `var(--alpha-50)`)
- `--floating-input-border-color-hover`: border color hover
- `--floating-input-border-color-invalid`: border color invalid (default `var(--color-border-danger-outline)`)
- `--floating-input-border-radius`: border radius (default `var(--radius-full)`)
- `--floating-input-box-gutter`: gutter of the rounded box (default `var(--control-gutter-lg)`)
- `--floating-input-box-radius`: radius of the rounded box (default `var(--control-radius-xl)`)
- `--floating-input-font-size`: value and resting label size (default `1rem`)
- `--floating-input-gutter`: gutter (default `1.25rem`)
- `--floating-input-height`: height (default `3.25rem`)
- `--floating-input-inside-height`: height with the label inside (default `3.5rem`)
- `--floating-input-inside-label-color`: label color with the label inside (default `var(--color-text-secondary)`)
- `--floating-input-inside-label-scale`: label scale with the label inside (default `0.75`)
- `--floating-input-inside-label-shift`: how far the label rises inside the box (default `-0.75rem`)
- `--floating-input-inside-line-height`: line step of the textarea, and the distance from the label to the value (default `1.25rem`)
- `--floating-input-inside-value-shift`: how far the value drops under the label (default `1rem`)
- `--floating-input-label-color`: label color (default `var(--color-text-tertiary)`)
- `--floating-input-label-color-focus`: label color focus (default `var(--color-text)`)
- `--floating-input-label-color-invalid`: label color invalid (default `var(--color-text-danger-outline)`)
- `--floating-input-label-scale`: label scale (default `0.88`)
- `--floating-input-transition-duration`: transition duration (default `80ms`)
