A rolling number turns each changed digit to its new value, as the wheels of an odometer do, so a total or a count that changes in front of the reader shows the change. Use it where a number moves while it is watched, such as a total as items are added; a number that only loads once needs none.

## API

### RollingNumber

<PropsTable data={[
  { prop: "value", type: "number", description: "The number shown; a new value rolls each changed digit to it" },
  { prop: "locales", type: "Intl.LocalesArgument", default: '"en-US"', description: "The locale the number is written in; fixed rather than the browser's, so the server writes it as the browser does. Its own digits roll, such as Arabic-Indic" },
  { prop: "format", type: "Intl.NumberFormatOptions", description: "How it is written: a currency, a percent, fraction digits, grouping" },
  { prop: "className", type: "string", description: "Applied to the root span; set the size and weight here" },
]} />

Other `<span>` attributes are forwarded to the root. The written number is in a visually hidden span; the reels are `aria-hidden`.

## Styling

- `--rolling-number-duration`: how long a digit rolls (defaults to `600ms`)
- `--rolling-number-ease`: its easing (defaults to `--cubic-move`)
