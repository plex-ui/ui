### Icons

<ComponentPreview details={<>

  <p>For icon-only buttons, there are two common approaches:</p>

  <p><strong>Tighter gutters</strong>: applying a smaller <code>gutterSize</code> than <code>size</code> can create well-sized, but not exactly square, icon buttons.</p>

## Styling

Button reads these component tokens. Override them at any scope to restyle it:

- `--button-font-weight`: font weight (default `var(--font-weight-medium)`)
- `--button-gap-lg`: gap lg (default `6px`)
- `--button-gap-md`: gap md (default `4px`)
- `--button-gap-sm`: gap sm (default `3px`)
