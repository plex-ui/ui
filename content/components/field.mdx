### Render prop pattern

For controls that need explicit prop wiring, pass a function as `children`. The function receives `{ id, "aria-describedby", "aria-invalid" }` which you spread onto the control.

```tsx
<Field label="Email" errorMessage="Email is required">
  {(fieldProps) => <Input {...fieldProps} placeholder="Enter email..." />}
</Field>
```

## Styling

Field reads these component tokens. Override them at any scope to restyle it:

- `--field-error-color`: error color (default `var(--color-text-danger-outline)`)
- `--field-error-font-size`: error font size (default `0.75rem`)
- `--field-error-gap`: error gap (default `spacing(2)`)
- `--field-error-icon-size`: error icon size (default `1rem`)
- `--field-error-line-height`: error line height (default `var(--font-text-xs-line-height)`)
- `--field-error-margin-bottom`: error margin bottom (default `spacing(3)`)
- `--field-error-margin-top`: error margin top (default `0.5rem`)
- `--field-error-padding-inline`: error padding inline (default `0`)
- `--field-horizontal-control-width`: horizontal control width (default `240px`)
- `--field-horizontal-control-flex`: flex of the horizontal control (default `0 0 auto`; `0 1 auto` on a phone with `touch.css`, so the control narrows instead of overflowing)
- `--field-horizontal-label-width`: horizontal label width (default `120px`)
- `--field-label-font-weight`: label font weight (default `var(--font-weight-medium)`)
- `--field-row-above-color`: colour of a label above its value (default `var(--color-text-tertiary)`)
- `--field-row-above-font-size`: size of a label above its value (default `0.8125rem`)
- `--field-row-above-font-weight`: weight of a label above its value (default `var(--font-weight-medium)`)
- `--field-row-above-gap`: space under a label above its value (default `4px`)
- `--field-row-above-line-height`: line height of a label above its value (default `1.125rem`)
- `--field-row-above-padding-block`: padding of a row with a label above its value (default `10px`)
- `--field-row-action-font-size`: text size of the action button (default `var(--font-text-sm-size)`)
- `--field-row-action-font-weight`: text weight of the action button (default `var(--font-weight-medium)`)
- `--field-row-action-size`: height of the action button (default `2rem`)
- `--field-row-control-width`: width of a framed number in a row (default `160px`)
- `--field-row-description-font-size`: description size on a row (default `var(--font-text-sm-size)`)
- `--field-row-description-line-height`: description line height on a row (default `var(--font-text-sm-line-height)`)
- `--field-row-gap`: space between label and control (default `24px`, `16px` on a `fill` row)
- `--field-row-label-font-size`: label size on a row (default `var(--font-text-sm-size)`)
- `--field-row-label-font-weight`: label weight on a row (default `var(--font-weight-medium)`)
- `--field-row-label-line-height`: label line height on a row (default `var(--font-text-sm-line-height)`)
- `--field-row-label-width`: label column of a `fill` row (default `80px`)
- `--field-row-list-label-offset`: moves the label to the middle of a list's first line (default `6px`)
- `--field-row-list-padding-block`: padding of a `fill` row with an `action` (default `10px`)
- `--field-row-list-row-gap`: space above a list on its own line (default `8px`)
- `--field-row-min-height`: row height (default `52px`)
- `--field-row-padding-block`: row padding (default `10px`)
- `--field-row-padding-inline`: row padding (default `16px`)
- `--field-row-row-gap`: space above an error (default `2px`)
- `--field-row-text-display`: `contents` runs the description under the control (default `flex`)
- `--field-row-text-padding-block`: row padding with a description or an error (default `10px`)
- `--field-row-text-width`: width of a framed text field in a row (default `240px`)

- `--field-group-description-line-height`: description line height (default `var(--font-text-xs-line-height)`)
- `--field-group-radius`: block radius (default `1rem`)
