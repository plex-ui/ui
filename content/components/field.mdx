## Examples

### Overview

<ComponentPreview className={phoneRowsStyles.PhoneRowsPreview} details={<>
  <p>Field wraps a form control with a label, a description and an error message, and links them: the label's <code>htmlFor</code>, <code>aria-describedby</code> and <code>aria-invalid</code> reach the control. <code>required</code> adds an asterisk after the label; it is visual only, so give the control its own <code>required</code> for form validation. The <code>layout</code> control puts the label in its four places:</p>
  <ul>
    <li><strong>above</strong>: the default, <code>orientation="vertical"</code>.</li>
    <li><strong>columns</strong>: <code>orientation="horizontal"</code>, every value starting at one column.</li>
    <li><strong>end</strong>: <code>row</code>, one line of a <code>FieldGroup</code> with the value at its end. A framed field is a pill there and takes <code>--field-row-control-width</code>, as its width cannot follow what is typed; <code>pill={'{false}'}</code> on the control keeps the rounded box.</li>
    <li><strong>hidden</strong>: <code>hideLabel</code>. The label still names the control for screen readers; the placeholder shows what to type, and a description moves under the field.</li>
  </ul>
  <p>On Phone a field is always a cell of a <code>FieldGroup</code> on the grouped background, as in an iOS form, in the same four places: the label above its value (<code>row orientation="vertical"</code>), values in one column (<code>FieldGroup columns</code>), the value at the end of the row, or the placeholder alone (<code>row hideLabel</code>), its value starting at the row's edge. The row is the field's frame, so a framed or soft field loses its frame. The error stands inside the cell, under the value. The words that explain a field go in the group's <code>footer</code>, and a required field says so in its placeholder, as iOS account forms do. A disabled field dims its label with its value. A one-time code is the exception: <code>OTPInput</code> keeps its own digit cells on the screen, outside a group, as in <a href="/components/auth-forms#verify-email">Verify email</a>.</p>
</>} code={`// Desktop
<Field label="Name" required>
  <Input placeholder="Jane Appleseed" />
</Field>
<Field
  label="Email"
  required
  description="We'll never share your email with anyone else."
  errorMessage="Enter a valid email address."
>
  <Input type="email" defaultValue="jane@example" />
</Field>

// Phone: a cell of a FieldGroup; the words that explain it go in the footer.
<FieldGroup footer="We'll never share your email with anyone else.">
  <Field row label="Name" orientation="vertical">
    <Input placeholder="Required" />
  </Field>
  <Field row label="Email" orientation="vertical" errorMessage="Enter a valid email address.">
    <Input type="email" defaultValue="jane@example" />
  </Field>
</FieldGroup>

// columns: <FieldGroup columns> with rows; end: rows; hidden: placeholder only
<Field row hideLabel label="Name">
  <Input placeholder="Name" />
</Field>`} previewMinHeight={168}>
  <FieldOverviewDemo />
</ComponentPreview>

### Group

<ComponentPreview className={phoneRowsStyles.PhoneRowsPreview} details={<>

### Other controls

<ComponentPreview className={phoneRowsStyles.PhoneRowsPreview} details={<>
  <p>Field works with any form control. A native one, such as a <code>Textarea</code>, is named by the label's <code>htmlFor</code>. A <code>Select</code> or <code>DatePicker</code> trigger is not a native form control, so Field points its <code>aria-labelledby</code> at the label, and the trigger adds its value: a screen reader hears "Role, Editor". A child with a name of its own (<code>aria-label</code>, <code>aria-labelledby</code> or <code>label</code>) keeps it.</p>
  <p>On Phone a Select or a date is the value at the end of its row, and a long text stands under its label. A group of checkboxes, radios or switches is a row per choice: see <a href="/components/checkbox#with-field">Checkbox</a>, <a href="/components/radio-group">Radio Group</a> and <a href="/components/switch">Switch</a>.</p>
</>} code={`// Desktop
<Field label="Role" description="What this person can change.">
  <Select value={role} onChange={(option) => setRole(option.value)} options={roles} />
</Field>
<Field label="Starts">
  <DatePicker placeholder="Select date" value={start} onChange={setStart} />
</Field>
<Field label="Notes">
  <Textarea placeholder="Anything the team should know" rows={3} />
</Field>

// Phone
<FieldGroup>
  <Field row label="Role">

  </Field>

    <DatePicker triggerDateFormat="MMM d, yyyy" triggerShowIcon={false} placeholder="Select date" value={start} onChange={setStart} />
  </Field>
  <Field row label="Notes" orientation="vertical">
    <Textarea placeholder="Anything the team should know" rows={3} autoResize />
  </Field>
</FieldGroup>`} previewMinHeight={168}>

</ComponentPreview>

### Several controls

<ComponentPreview phonePresentation="none" details={<>For more than one control, or a control that needs its props placed by hand, pass a function as <code>children</code>. ## Styling

Field reads these component tokens. Override them at any scope to restyle it:

- `--field-error-color`: error color (default `var(--color-text-danger-outline)`)
- `--field-error-font-size`: error font size (default `0.75rem`)
- `--field-error-gap`: error gap (default `spacing(2)`)
- `--field-error-icon-size`: error icon size (default `1rem`)
- `--field-error-line-height`: error line height (default `var(--font-text-xs-line-height)`)
- `--field-error-margin-bottom`: error margin bottom (default `spacing(3)`)
- `--field-error-margin-top`: error margin top (default `0.5rem`)
- `--field-error-padding-inline`: error padding inline (default `0`)
- `--field-horizontal-control-width`: horizontal control width (default `240px`)
- `--field-horizontal-control-flex`: flex of the horizontal control (default `0 0 auto`; `0 1 auto` on a phone with `touch.css`, so the control narrows instead of overflowing)
- `--field-horizontal-label-width`: horizontal label width (default `120px`)
- `--field-label-font-weight`: label font weight (default `var(--font-weight-medium)`)
- `--field-row-above-color`: colour of a label above its value (default `var(--color-text-tertiary)`)
- `--field-row-popup-value-color`: colour of the value of a Select at the end of a row on a phone (default the secondary label, as the pop-ups of Reminders and Calendar; `var(--color-text)` gives the primary label of the Files View Options sheet)
- `--field-row-above-font-size`: size of a label above its value (default `0.8125rem`)
- `--field-row-above-font-weight`: weight of a label above its value (default `var(--font-weight-medium)`)
- `--field-row-above-gap`: space under a label above its value (default `4px`)
- `--field-row-above-line-height`: line height of a label above its value (default `1.125rem`)
- `--field-row-above-padding-block`: padding of a row with a label above its value (default `10px`)
- `--field-row-action-font-size`: text size of the action button (default `var(--font-text-sm-size)`)
- `--field-row-action-font-weight`: text weight of the action button (default `var(--font-weight-medium)`)
- `--field-row-action-size`: height of the action button (default `2rem`)
- `--field-row-control-width`: width of a framed number in a row (default `160px`)
- `--field-row-description-font-size`: description size on a row (default `var(--font-text-sm-size)`)
- `--field-row-description-line-height`: description line height on a row (default `var(--font-text-sm-line-height)`)
- `--field-row-gap`: space between label and control (default `24px`, `16px` on a `fill` row)
- `--field-row-label-font-size`: label size on a row (default `var(--font-text-sm-size)`)
- `--field-row-label-font-weight`: label weight on a row (default `var(--font-weight-medium)`)
- `--field-row-label-line-height`: label line height on a row (default `var(--font-text-sm-line-height)`)
- `--field-row-label-width`: label column of a `fill` row (default `80px`)
- `--field-row-list-label-offset`: moves the label to the middle of a list's first line (default `6px`)
- `--field-row-list-padding-block`: padding of a `fill` row with an `action` (default `10px`)
- `--field-row-list-row-gap`: space above a list on its own line (default `8px`)
- `--field-row-min-height`: row height (default `52px`)
- `--field-row-padding-block`: row padding (default `10px`)
- `--list-row-inset`: how far a row's content stands inside its group, on every width (`16px`; on a phone `20px`, where an iOS cell's text starts). Your own rows in a group take it, or the Tailwind utility `px-list-inset`, to line up with the kit's; the edge of a screen or a sheet is `--page-gutter` (`px-layout-margin`). It is set on the root, where the kit's rows, the lines between them and a group's title and footer take it: to change them all, override it on `:root`. `--mobile-list-inset` stays as its alias
- `--field-row-padding-inline`: row padding (default `--list-row-inset`)
- `--field-row-row-gap`: space above an error (default `2px`)
- `--field-row-text-display`: `contents` runs the description under the control (default `flex`)
- `--field-row-text-padding-block`: row padding with a description or an error (default `10px`)
- `--field-row-text-width`: width of a framed text field in a row (default `240px`)

FieldGroup reads these:

- `--field-group-background`: block background (default `transparent`)
- `--field-group-border-width`: block border (default `1px`)
- `--field-group-description-font-size`: description size (default `var(--font-text-sm-size)`; 15px on a phone)
- `--field-group-description-line-height`: description line height (default `var(--font-text-sm-line-height)`; 20px on a phone)
- `--field-group-footer-font-size`: footer size (default the description size; 13px on a phone)
- `--field-group-footer-line-height`: footer line height (default the description line height; 16px on a phone)
- `--field-group-footer-padding`: footer padding (default `8px 0 0`; `8px 20px 6px` on a phone)
- `--field-group-footer-paragraph-gap`: space between footer paragraphs (default `spacing(2)`; 16px on a phone)
- `--field-group-header-min-height`: header height (default `spacing(8)`)
- `--field-group-header-padding-bottom`: space under the header (default `spacing(2)`)
- `--field-group-radius`: block radius (default `1rem`)
- `--field-group-separator-inset`: on a phone, how far the line between rows stands from both ends of the row (`--list-row-inset`, 20px, where the row's text starts)
- `--field-group-separator-inset-start`: where the line starts (default `--field-group-separator-inset`). Set it on a row that leads with an icon to start the line after the icon, where its text starts, or on the group for every row
- `--field-group-separator-inset-end`: where the line ends (default `--field-group-separator-inset`)
- `--field-group-title-color`: title color (default `var(--color-text)`)
- `--field-group-title-font-size`: title size (default `var(--font-text-md-size)`)
- `--field-group-title-font-weight`: title weight (default `var(--font-weight-medium)`)
- `--field-group-title-letter-spacing`: title tracking (default `normal`)
- `--field-group-title-line-height`: title line height (default `var(--font-text-md-line-height)`)
- `--field-group-title-padding-inline`: title inset (default `0`; 20px on a phone)
