## API

External links render an `<a>` with `target="_blank"` (unless you pass `target`) and `rel="noopener noreferrer"`. Without `href` or `to`, `TextLink` renders a `<span role="button">`; with an `onClick` it takes Tab and runs on Enter or Space. Other anchor attributes are forwarded.

### Configure your Router

Wrap your app in `PlexUIProvider` and pass your router's Link component. You can also pass the Link component to the `as` prop on `TextLink` for component-level override.

```tsx
import { PlexUIProvider } from "@plexui/ui/components/PlexUIProvider"
import { Link } from "react-router"

export function App() {
  return (
    <PlexUIProvider linkComponent={Link}>
      ...
    </PlexUIProvider>
  )
}

<TextLink to={{ pathname: "/help" }} prefetch="intent">Get Help</TextLink>
```

```tsx
import Link from "next/link"

<TextLink as={Link} href="/dashboard">View Dashboard</TextLink>
```

## Styling

Text Link reads these component tokens. Override them at any scope to restyle it:

- `--link-font-weight`: font weight (default `inherit`)
- `--link-gap`: gap (default `spacing(0.5)`)
- `--link-primary-text-color`: primary text color (default `light-dark(var(--blue-500), var(--blue-300))`)
- `--link-primary-text-color-hover`: primary text color hover (default `light-dark(var(--blue-600), var(--blue-400))`)
- `--link-radius`: radius (default `var(--radius-sm)`)
- `--link-underline-decoration-offset`: underline decoration offset (default `0.1em`)
