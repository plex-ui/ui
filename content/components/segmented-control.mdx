### Overview

<ComponentPreview className={phoneRowsStyles.PhoneRowsPreview} details={<>SegmentedControl provides two visual variants: <code>segmented</code> (default) with a sliding background highlight, and <code>underline</code> with an animated line indicator under the active tab and no background container. <code>flush</code> makes the underline indicator match the text width exactly, with gap between tabs instead of padding, and <code>block</code> stretches the tabs evenly across the container. <code>orientation="vertical"</code> stacks the tabs: the thumb slides up and down, and the underline becomes a line on the left side, for sidebar-style navigation. Both variants take the full 9-step <code>size</code> scale of Button, Input, Select and SelectControl, which sets the height, font size, icon size and spacing of the tabs. <code>icon</code> on a tab puts an icon before its label, sized to the <code>size</code>; leave out the label for icon-only tabs of a horizontal control and give each an <code>aria-label</code>. Vertical tabs keep their labels, so the example offers no icon only there: they are a list, a sidebar or on a phone an inset grouped list, and a list row always has a title. <code>badge</code> takes a number or an object with <code>content</code>, <code>color</code>, <code>variant</code> and <code>pill</code>, shown after the label inside the control; a count names what it counts, so it sits on a labelled tab and icon-only tabs carry none. <code>disabled</code> affects the whole group, which on a phone shows at half opacity when horizontal, as a disabled iOS segmented control does; <code>monthDisabled</code> disables only Month, whose label in a horizontal control on a phone takes the disabled label of iOS, 20% of the label color, while its row in a vertical one shows at half opacity. Arrow-key navigation skips disabled tabs without resetting the selected value.<br /><br />On a phone horizontal tabs of either variant are the iOS 27 segmented control, filling the row of a phone screen, in its two sizes. The default <code>md</code> and larger are the large control of iOS 27 apps, as Calendar and Reminders draw it and SwiftUI draws a segmented Picker in a toolbar: a 48px glass capsule, a 40px gray selection 4px inside it, 8px between segments, every label 15px Medium and primary. <code>sm</code> and smaller are the small one, the plain control of SwiftUI's Picker in content and of Safari's bookmarks: a 32px capsule of the tertiary fill, a white selection 2px inside it, labels 13px, Semibold when selected. <code>mobileMaterial</code> switches the look, as for Button: <code>flat</code> makes the large one plain, 49px as SwiftUI's <code>.controlSize(.large)</code>, and <code>glass</code> puts the small one under the Liquid Glass of <code>.glassEffect()</code>. Inside a phone Toolbar every control is the large glass one. The phone example puts the control in a top bar between Close and Confirm, as a sheet's toolbar holds a segmented Picker in iOS 27.2 and Calendar its new event, in a bottom bar, or above the content, as Safari's bookmarks do, over a day that scrolls under the glass of the bars; <code>placement</code> picks one. Vertical tabs of either variant are an inset grouped list, as iOS lists a choice: 52px rows with the 17px label and a checkmark on the selected row instead of the thumb. A segment with an icon and a label shows the icon alone, at the 20px symbol size, as UISegmentedControl draws an action with a title and an image; the label stays the segment&apos;s accessible name, since iOS segments carry a title or a symbol, not both. They carry no badges either: on a phone write a count into the label instead, or leave it out. Underline tabs draw the same segmented control on a phone and every control there is a capsule filling its row, so the phone view has no <code>variant</code>, <code>flush</code>, <code>block</code>, <code>pill</code> and <code>badge</code> controls, and its <code>size</code> offers <code>sm</code> and <code>md</code>.</>} code={overviewCode} codeValues={{ icon: "none", badge: false, badgePill: true }} codeExamples={[{ name: "Icons", values: { icon: "start" }, details: "An icon before each label, sized to the control's size." }, { name: "Icon only", values: { icon: "only" }, details: "Icons alone, each tab named by its aria-label." }, { name: "Badges", values: { badge: true }, details: "A count after each label: a number, or an object with content, color, variant and pill." }]} previewMinHeight={PREVIEW_MIN_HEIGHT.controlWithPanel}>

### Overflow

<ComponentPreview className={phoneRowsStyles.PhoneRowsPreview} details={<>When tabs overflow their container they scroll sideways, the default <code>overflow="scroll"</code>, and the active tab scrolls into view smoothly: constrain the container width and nothing else is needed. A phone scrolls them the same way inside the capsule, as Safari's tab groups and Telegram's chat folders do, and each segment then takes the width of its label. With <code>overflow="menu"</code> the tabs that do not fit stay out of the row and move into a menu at its end. ### Also exported as Tabs

The same component is exported as `Tabs`, with `Tabs.Tab` for an option, for code that names it so:

```tsx
import { Tabs } from "@plexui/ui/components/Tabs";
<Tabs.Tab value="a">A</Tabs.Tab>
```

`SegmentedControl.Option`, `SegmentedControl.Tab`, `Tabs.Option` and `Tabs.Tab` are one sub-component.

## Styling

SegmentedControl reads these component tokens. Override them at any scope to restyle it:

- `--badge-font-size-2xs`: font size 2xs (default `var(--font-text-xs-size)`)
- `--badge-font-size-lg`: font size lg (default `var(--font-text-sm-size)`)
- `--badge-font-size-md`: font size md (default `var(--font-text-sm-size)`)
- `--badge-font-size-sm`: font size sm (default `var(--font-text-xs-size)`)
- `--badge-font-size-xs`: font size xs (default `var(--font-text-xs-size)`)
- `--badge-font-weight-2xs`: font weight 2xs (default `var(--font-weight-semibold)`)
- `--badge-font-weight-lg`: font weight lg (default `var(--font-weight-semibold)`)
- `--badge-font-weight-md`: font weight md (default `var(--font-weight-semibold)`)
- `--badge-font-weight-sm`: font weight sm (default `var(--font-weight-semibold)`)
- `--badge-font-weight-xs`: font weight xs (default `var(--font-weight-semibold)`)
- `--badge-gutter-2xs`: gutter 2xs (default `0.1875rem`)
- `--badge-gutter-lg`: gutter lg (default `var(--control-gutter-xs)`)
- `--badge-gutter-md`: gutter md (default `var(--control-gutter-2xs)`)
- `--badge-gutter-sm`: gutter sm (default `calc(var(--control-gutter-2xs) - 1px)`)
- `--badge-gutter-xs`: gutter xs (default `0.25rem`)
- `--badge-radius-2xs`: radius 2xs (default `var(--radius-2xs)`)
- `--badge-radius-lg`: radius lg (default `var(--radius-sm)`)
- `--badge-radius-md`: radius md (default `var(--radius-xs)`)
- `--badge-radius-sm`: radius sm (default `var(--radius-xs)`)
- `--badge-radius-xs`: radius xs (default `var(--radius-2xs)`)
- `--badge-size-2xs`: size 2xs (default `1rem`)
- `--badge-size-lg`: size lg (default `var(--control-size-2xs)`)
- `--badge-size-md`: size md (default `var(--control-size-3xs)`)
- `--badge-size-sm`: size sm (default `calc(var(--control-size-3xs) - 2px)`)
- `--badge-size-xs`: size xs (default `1.125rem`)
- `--badge-tracking-2xs`: tracking 2xs (default `var(--tracking-wide)`)
- `--badge-tracking-lg`: tracking lg (default `var(--tracking-normal)`)
- `--badge-tracking-md`: tracking md (default `var(--tracking-normal)`)
- `--badge-tracking-sm`: tracking sm (default `var(--tracking-wide)`)
- `--badge-tracking-xs`: tracking xs (default `var(--tracking-wide)`)
- `--button-gap-lg`: gap lg (default `6px`)
- `--button-gap-md`: gap md (default `4px`)
- `--button-gap-sm`: gap sm (default `3px`)
- `--segmented-control-background`: background (default `light-dark(var(--gray-100), var(--alpha-08))`)
- `--segmented-control-font-weight`: font weight (default `var(--font-weight-semibold)`)
- `--segmented-control-gap`: gap (default `2px`)
- `--segmented-control-gutter`: gutter (default `2px`)
- `--segmented-control-mobile-plain-background`: phone track in content, the tertiary fill (default `light-dark(var(--alpha-06), var(--alpha-12))`)
- `--segmented-control-mobile-plain-thumb-background`: phone thumb in content (default `light-dark(var(--gray-0), var(--alpha-25))`)
- `--segmented-control-mobile-thumb-background`: phone thumb background on the glass track in a Toolbar (default `light-dark(var(--alpha-08), var(--gray-200))`)
- `--segmented-control-symbol-size`: phone icon of an icon-only segment (default `20px` with `touch.css`, otherwise the icon size)
- `--segmented-control-option-highlight-background-color`: option highlight background color (default `light-dark( var(--gray-200), var(--gray-300) )`)
- `--segmented-control-option-highlight-gutter`: option highlight gutter (default `1px`)
- `--segmented-control-sheen`, `--segmented-control-shadow`, `--segmented-control-backdrop-filter`: the track's glass in a phone Toolbar, set by `touch.css` from the shared mobile glass (default `none`)
- `--segmented-control-thumb-background`: thumb background (default `light-dark(var(--gray-0), var(--alpha-12))`)
- `--segmented-control-thumb-outset`: how far the phone thumb reaches past its segment toward the capsule's ends (`4px` in a phone Toolbar with `touch.css`, default `0px`)
- `--segmented-control-thumb-shadow`: thumb shadow (default `0 1px 4px -1px rgb(0 0 0 / 20%)`)
- `--tabs-underline-border-color`: underline border color (default `var(--color-border)`)
- `--tabs-underline-indicator-color`: underline indicator color (default `var(--color-background-primary-solid)`)
- `--tabs-underline-indicator-height`: underline indicator height (default `2px`)
