On Phone, put an input in a row of a `FieldGroup`, as the [Form Examples](/components/form-examples) do. The row is its frame and sets its height, insets and type, so the Phone previews show rows without the `size`, `gutterSize`, `pill` and `variant` controls.

## Examples

Plex UI also provides a `FieldError` component (`@plexui/ui/components/FieldError`) that pairs well with invalid inputs. ### Optical alignment

Use `opticallyAlign` with either `"start"` or `"end"` to offset the gutter, aligning the input text with surrounding content. Works with `Field`: pass `opticallyAlign` on the Field and it forwards to the child control automatically. On Phone, a row starts its label and its text at the row's inset, so there is nothing to offset.

<ComponentPreview className={phoneRowsStyles.PhoneRowsPreview} code={`// Desktop
<Field label="Full name" opticallyAlign="start">
  <Input placeholder="Jane Doe" pill />
</Field>
<Field
  label="Email"
  description="We'll never share your email."
  errorMessage="Please enter a valid email address."
  required
  opticallyAlign="start"
>
  <Input placeholder="jane@example.com" pill />
</Field>
<Button className="mt-6" color="primary" variant="soft" pill>
  Submit
</Button>

// Phone: the help is the group's footer.
<FieldGroup footer="We'll never share your email.">
  <Field row label="Full name">
    <Input placeholder="Jane Doe" />
  </Field>
  <Field row label="Email" errorMessage="Please enter a valid email address.">
    <Input placeholder="jane@example.com" />
  </Field>
</FieldGroup>
<Button color="primary" size="3xl" pill block>Submit</Button>`}>
  <InputOpticalAlignDemo />
</ComponentPreview>

Input shares the unified 9-step size scale with Button, Select, SelectControl, and SegmentedControl. Set the same `size` on adjacent controls and they'll align perfectly. On a phone with `touch.css`, `3xs` to `xl` are all 44px: a `3xs`, `2xs` or `xs` field takes the height, 17px text and gutter of `sm`.

## Styling

Input reads these component tokens. Override them at any scope to restyle it:

- `--input-border-color-invalid`: border color invalid (default `var(--color-border-danger-outline)`)
- `--input-gap-lg`: gap lg (default `10px`)
- `--input-gap-md`: gap md (default `8px`)
- `--input-gap-sm`: gap sm (default `6px`)
- `--input-gap-xs`: gap xs (default `4px`)
- `--input-outline-border-color`: outline border color (default `var(--color-border-primary-outline)`)
- `--input-outline-border-color-focus`: outline border color focus (default `var(--alpha-50)`)
- `--input-outline-border-color-hover`: outline border color hover (default `light-dark(var(--alpha-25), var(--alpha-30))`)
- `--input-placeholder-text-color`: placeholder text color (default `var(--color-text-tertiary)`)
- `--input-soft-background-color`: soft background color (default `var(--color-background-primary-soft-alpha)`)
- `--input-soft-border-color-focus`: soft border color focus (default `var(--alpha-20)`)
- `--input-text-color`: text color (default `var(--color-text)`)
