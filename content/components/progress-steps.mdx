## API

**ProgressSteps** (root)

<PropsTable data={[
  { prop: "current", type: "number", description: "Current active step (1-based)" },
  { prop: "orientation", type: '"horizontal" | "vertical"', default: '"horizontal"', description: "Layout direction" },
  { prop: "size", type: '"sm" | "md" | "lg"', default: '"md"', description: "Step indicator size" },
  { prop: "color", type: '"default" | "success"', default: '"default"', description: "Color scheme for completed/active steps" },
  { prop: "connectorStyle", type: '"solid" | "dashed"', default: '"solid"', description: "Connector line style" },
  { prop: "variant", type: '"default" | "minimal"', default: '"default"', description: "\"minimal\" renders a compact bar (requires total)" },
  { prop: "total", type: "number", description: "Total steps for minimal variant" },
]} />

**ProgressSteps.Step**

<PropsTable data={[
  { prop: "icon", type: "ReactNode", description: "Custom icon instead of step number" },
]} />

**ProgressSteps.Title**: Wrapper for step title text. Applies appropriate styling based on step state.

**ProgressSteps.Description**: Wrapper for step description text. Applies appropriate styling based on step state.

## Styling

Progress Steps reads these component tokens. Override them at any scope to restyle it:

- `--progress-steps-connector-color`: connector color (default `var(--gray-100)`)
- `--progress-steps-connector-color-completed`: connector color completed (default `var(--gray-900)`)
- `--progress-steps-connector-dash-gap`: connector dash gap (default `4px`)
- `--progress-steps-connector-dash-length`: connector dash length (default `4px`)
- `--progress-steps-connector-width`: connector width (default `2px`)
- `--progress-steps-content-gap-lg`: content gap lg (default `spacing(4)`)
- `--progress-steps-content-gap-md`: content gap md (default `spacing(3)`)
- `--progress-steps-content-gap-sm`: content gap sm (default `spacing(2.5)`)
- `--progress-steps-description-color`: description color (default `var(--color-text-secondary)`)
- `--progress-steps-description-color-inactive`: description color inactive (default `var(--color-text-tertiary)`)
- `--progress-steps-font-size-lg`: font size lg (default `var(--font-text-md-size)`)
