## API

### Breadcrumb

<PropsTable data={[
  { prop: "size", type: '"sm" | "md"', default: '"md"', description: "Text size: sm above a compact header, md above a page title" },
  { prop: "separator", type: "ReactNode", default: "a small chevron", description: "What stands between two items" },
  { prop: "aria-label", type: "string", default: '"Breadcrumb"', description: "Name of the navigation landmark" },
  { prop: "className", type: "string", description: "Applied to the nav element" },
]} />

Other `<nav>` attributes are forwarded.

### Breadcrumb.Item

<PropsTable data={[
  { prop: "href", type: "string", description: "Link destination. Internal paths use the linkComponent of PlexUIProvider" },
  { prop: "to", type: "string", description: "Router destination, for link components that take to" },
  { prop: "current", type: "boolean", default: "false", description: "The current page: plain text marked aria-current=\"page\"" },
  { prop: "onClick", type: "(event: MouseEvent) => void", description: "Makes an item without a destination act as a button" },
  { prop: "className", type: "string", description: "Applied to the li element" },
]} />

## Styling

Breadcrumb reads these component tokens. Override them at any scope to restyle it:

- `--breadcrumb-font-size`: text size (`--font-text-sm-size`, or `--font-text-xs-size` at `sm`)
- `--breadcrumb-line-height`: line height
- `--breadcrumb-gap`: space around separators (`spacing(1)`, or `spacing(0.5)` at `sm`)

Links use the secondary text color and turn to the text color on hover; the current page uses the text color; separators use the tertiary color.
