## Styling

Empty Message reads the shared semantic colors and optional `--empty-message-*` tokens for its typography, content padding and actions. The touch stylesheet provides the full mobile state; `size="sm"` keeps the compact panel layout. See [Design tokens](/docs/foundations/design-tokens).
