## Responsive composition

These application-local helpers choose the layout from the viewport. Desktop collapse remains independent of the mobile drawer. On a phone the drawer is a grouped page with a large title and a close button, as the sidebar of an iPhone app is: each menu is a card of 52px rows, a group label heads its section, a row that leads to a page ends with a disclosure chevron, and an item with a submenu keeps its own chevron, which turns down as its items open under it. The page and hidden drawer are inert at the appropriate time, and focus returns to the menu button after closing. Keep navigation selection handlers on the row buttons; popup and disclosure buttons do not close the drawer.

Save the helpers in `responsive-sidebar.tsx` and the styles in `responsive-sidebar.module.css`:

```tsx
import { useEffect, useRef, type ReactNode } from 'react';
import { NavigationButton } from '@plexui/ui/components/Button';
import { Page } from '@plexui/ui/components/Page';
import {
  Sidebar,
  SidebarInset,
  SidebarMobile,
  SidebarMobileMenuButton,
  SidebarProvider,
  useSidebar,
  type SidebarProps,
  type SidebarProviderProps,
} from '@plexui/ui/components/Sidebar';
import { Toolbar } from '@plexui/ui/components/Toolbar';
import { useBreakpoint } from '@plexui/ui/hooks/useBreakpoints';
import s from './responsive-sidebar.module.css';
/** Leaf navigation closes the drawer; disclosure and popup buttons keep it open. */
export function isSidebarNavigationSelection(target: EventTarget | null) {
  if (!(target instanceof Element)) return false;
  const button = target.closest('[data-active]');
  return Boolean(button && !button.hasAttribute('aria-haspopup') &&
    !button.hasAttribute('aria-expanded') && !button.closest('li')?.querySelector(':scope > ul'));
}

export function ResponsiveSidebarProvider({ className, open, variant, ...props }: SidebarProviderProps) {
  const wide = useBreakpoint('md');
  return <SidebarProvider {...props} className={[s.Frame, className].filter(Boolean).join(' ')} open={wide ? open : true} variant={wide ? variant : 'sidebar'} />;
}

/** Reuses one navigation tree in the desktop rail and the mobile drawer. */
export function ResponsiveSidebar({ children, ...props }: SidebarProps) {
  const { isMobile, openMobile, setOpenMobile } = useSidebar();
  const closeRef = useRef<HTMLButtonElement>(null);
  useEffect(() => {
    if (!isMobile || !openMobile) return;
    const trigger = document.activeElement;
    closeRef.current?.focus();
    return () => { if (trigger instanceof HTMLElement && trigger.isConnected) trigger.focus(); };
  }, [isMobile, openMobile]);
  if (!isMobile) return <Sidebar {...props}>{children}</Sidebar>;
  return (
    <SidebarMobile contained className={s.Drawer} inert={!openMobile} role="navigation" aria-label="Main navigation">
      <Page surface="grouped">
        <Toolbar titleStyle="large">
          <Toolbar.Title>Navigation</Toolbar.Title>
          <Toolbar.Trailing>
            <NavigationButton action="close" aria-label="Close menu" ref={closeRef} onClick={() => setOpenMobile(false)} />
          </Toolbar.Trailing>
        </Toolbar>
        <Page.Content className={s.NavigationContent} onClick={(event) => {
          if (!event.defaultPrevented && isSidebarNavigationSelection(event.target)) setOpenMobile(false);
        }}>
          {children}
        </Page.Content>
      </Page>
    </SidebarMobile>
  );
}

export function SidebarDemoPage({ title, children }: { title: ReactNode; children: ReactNode }) {
  const { isMobile, openMobile } = useSidebar();
  return (
    <SidebarInset className={s.Inset} inert={isMobile && openMobile}>
      {isMobile ? (
        <Page>
          <Page.Header>
            <Page.Bar>
              <Page.Leading><SidebarMobileMenuButton /></Page.Leading>
              <Page.Title>{title}</Page.Title>
            </Page.Bar>
          </Page.Header>
          <Page.Content>{children}</Page.Content>
        </Page>
      ) : (
        <div className="p-6">
          <h1 className="text-2xl font-semibold mb-4">{title}</h1>
          {children}
        </div>
      )}
    </SidebarInset>
  );
}
```

## API

### Structure

A Sidebar is composed of the following parts:

- `SidebarProvider`: Handles collapsible state and provides context to all child components.
- `SidebarLayout`: Wrapper for sidebar and main content.
- `Sidebar`: The sidebar container.
- `SidebarHeader` / `SidebarFooter`: Sticky at the top and bottom of the sidebar.
- `SidebarContent`: Scrollable content area.
- `SidebarGroup`: Section within the content, with optional label.
- `SidebarMenu` / `SidebarMenuItem` / `SidebarMenuButton`: Navigation menu items.
- `SidebarMenuSub` / `SidebarMenuSubButton`: Nested submenu items.
- `SidebarInset`: Main content area next to the sidebar.
- `SidebarTrigger`: Toggle button for collapsing the sidebar.

Use `Cmd+B` (Mac) or `Ctrl+B` (Windows/Linux) to toggle the sidebar with keyboard.

### SidebarMenuBadge

Trailing content of a row: a `Badge`, or plain text such as a count, which reads as small secondary figures. A `Badge` sits as far from the row's edge as from its top and bottom, and its digits end where plain counts and the chevron end. When the sidebar collapses to icons, a `Badge` becomes a dot of its color at the top right of the row's icon, clear of the glyph; plain text fades with the label.

### SidebarTrigger

Collapse button. Renders nothing when `collapsible="none"`. The default icon is `Sidebar` in both states, and a tooltip can say what a press does; children replace it. An `onClick` runs before the toggle; call `event.preventDefault()` in it to cancel the toggle. `SidebarMobileMenuButton`, the mobile menu button (the PlexUI `SidebarMenuMobile` icon, which turns into `X` while the menu is open), handles `onClick` the same way.

### SidebarInput

A search field: `Input` with a search icon as its start adornment. It takes every `Input` prop.

### SidebarCard

Renders a promotional card in the sidebar footer for CTAs, upgrades, or announcements.

### useSidebar

Hook to access sidebar state and controls from any component within `SidebarProvider`.

- `state`: Current state: `"expanded"` or `"collapsed"`
- `open` / `setOpen`: Desktop sidebar open state
- `openMobile` / `setOpenMobile`: Mobile menu open state
- `isMobile`: Whether the viewport is mobile
- `collapsible`: Current collapsible mode
- `toggleSidebar`: Toggle function for both desktop and mobile

## Styling

Sidebar reads these component tokens. Override them at any scope to restyle it. `SidebarProvider` sets the three width tokens on its own element, so change those through its `style` (or on an element inside it):

- `--sidebar-accent`: accent (default `light-dark(var(--alpha-08), var(--alpha-12))`)
- `--sidebar-background`: background (default `none`)
- `--sidebar-border`: border (default `var(--color-border)`)
- `--sidebar-collapse-duration`: collapse duration (default `0.3s`)
- `--sidebar-footer-shadow`: footer shadow
- `--sidebar-foreground`: foreground (default `var(--color-text)`)
- `--sidebar-group-label-color`: group label color (default `var(--color-text-tertiary)`)
- `--sidebar-gutter`: gutter (default `12px`)
- `--sidebar-gutter-sm`: gutter sm (default `var(--control-gutter-2xs)`)
- `--sidebar-header-height`: header height (default `var(--control-size-3xl)`)
- `--sidebar-icon-margin`: icon margin (default `0 2px 0 4px`)
- `--sidebar-icon-size`: icon size (default `20px`)
- `--sidebar-icon-wrapper-size`: icon wrapper size (default `32px`)
- `--sidebar-inset-shadow`: inset shadow (default `none`)
- `--sidebar-menu-badge-dot-size`: size of the dot a `Badge` becomes above the icon in the collapsed rail (default `6px`)
- `--sidebar-menu-item-font-size`: menu item font size (default `14px`)
- `--sidebar-menu-item-height`: menu item height (default `38px`)
- `--sidebar-menu-item-height-desktop`: menu item height desktop (default `32px`)
- `--sidebar-menu-item-line-height`: menu item line height (default `20px`)
- `--sidebar-menu-item-margin`: menu item margin (default `0 0 2px`)
- `--sidebar-menu-item-margin-desktop`: menu item margin desktop (default `0 0 2px`)
- `--sidebar-menu-item-padding`: menu item padding (default `0`)
- `--sidebar-menu-item-radius`: menu item radius (default `8px`)
- `--sidebar-menu-item-trailing-padding`: where counts and the chevron end, from the row's right edge (default `12px`)

- `--sidebar-menu-text`: menu text (default `light-dark(var(--gray-750), var(--gray-850))`)

- `--sidebar-mobile-backdrop-color`: mobile backdrop color (default `light-dark(rgb(0 0 0 / 15%), rgb(0 0 0 / 35%))`)
