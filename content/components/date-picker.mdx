On Phone, put a date picker in a row of a `FieldGroup`, as the [Settings Forms](/components/settings-forms) do. In the row its trigger is the compact date of iOS: a capsule with the date that opens the calendar, 8px under it and, on a screen 392px wide or wider, 32px from its edge, as iOS 27.2 opens it; with a time format the date and the time are two capsules 8px apart, as Calendar shows an event's start. The row's capsule is its frame and sets its height, insets and type, and iOS opens the calendar under the row, so the Phone previews leave out the `variant`, `size`, `pill`, `block`, icon, date format and placement controls, and set `triggerShowIcon={false}` and the date as iOS writes it, `"MMM d, yyyy"`. To type a date instead, put a [Date Input](/components/date-input) in the row.

### Two fields

<ComponentPreview className={phoneRowsStyles.PhoneRowsPreview} details={<>Compose <code>DatePicker</code> and <code>Input</code> side by side for maximum flexibility in form layouts. Each field operates independently while sharing the same DateTime value. Here <code>handleTimeInput</code> masks the typed time as HH:MM and moves the date to a complete typed time, and a newly picked date takes the typed time.</>} code={`const [selectedDate, setSelectedDate] = useState<DateTime | null>(null)
const [time, setTime] = useState("10:30")

// Mask the typed time as HH:MM; a complete time moves the picked date's time
const handleTimeInput = (event: React.ChangeEvent<HTMLInputElement>) => {
  const raw = event.target.value.replace(/[^\\d:]/g, "")
  const digits = raw.replace(/:/g, "")
  let formatted = digits
  if (digits.length >= 3) {
    formatted = digits.slice(0, 2) + ":" + digits.slice(2, 4)
  } else if (digits.length === 2 && !raw.includes(":")) {
    formatted = digits + ":"
  }
  setTime(formatted.slice(0, 5))

  const parts = formatted.split(":")
  if (parts.length === 2 && parts[1].length === 2 && selectedDate) {
    const hour = Math.min(23, Number(parts[0]) || 0)
    const minute = Math.min(59, Number(parts[1]) || 0)
    setSelectedDate(selectedDate.set({ hour, minute }))
  }
}

// A picked date takes the typed time
const onDateChange = (next: DateTime | null) => {
  if (next && time) {
    const [hour, minute] = time.split(":").map(Number)
    setSelectedDate(next.set({ hour: hour || 0, minute: minute || 0 }))
  } else {
    setSelectedDate(next)
  }
}

// Desktop
<div style={{ display: "flex", gap: "8px", alignItems: "center" }}>
  <DatePicker
    id="date-picker-two-field-date"
    triggerDateFormat="MMM d, yyyy"
    size="lg"
    pill
    captionLayout="dropdown"
    triggerShowIcon={false}
    dropdownIconType="none"
    placeholder="Select date"
    value={selectedDate}
    onChange={onDateChange}
  />
  <Input
    id="date-picker-two-field-time"
    size="lg"
    pill
    value={time}
    onChange={handleTimeInput}
    placeholder="HH:MM"
    maxLength={5}
    style={{ width: "72px" }}
  />
</div>

// Phone: two rows, the compact date and the time typed at the row's end
<FieldGroup>
  <Field row label="Date">

      id="date-picker-two-field-date"
      triggerDateFormat="MMM d, yyyy"
      captionLayout="dropdown"

      placeholder="Select date"
      value={selectedDate}
      onChange={onDateChange}
    />

## API

Use `aria-labelledby` with the ID of a visible field label. The trigger includes that label and its current date or placeholder in its accessible name. `aria-label`, `aria-describedby` and `aria-invalid` also reach the trigger.

In the calendar, the arrow keys move focus by a day or a week, Home and End move it to the Sunday or Saturday of the week, and Page Up and Page Down move it by a month (January 31 goes to the last day of February). A day in another month turns the calendar to that month first. Focus stays put when the day it would move to is outside `min` and `max`. Enter and Space select the focused day.

## Styling

Date Picker reads these component tokens. Override them at any scope to restyle it:

- `--input-border-color-invalid`: border color invalid (default `var(--color-border-danger-outline)`)
- `--input-outline-border-color`: outline border color (default `var(--color-border-primary-outline)`)
- `--input-outline-border-color-hover`: outline border color hover (default `light-dark(var(--alpha-25), var(--alpha-30))`)
- `--input-placeholder-text-color`: placeholder text color (default `var(--color-text-tertiary)`)
- `--input-text-color`: text color (default `var(--color-text)`)
- `--select-control-font-weight`: font weight (default `var(--font-weight-normal)`)
