On Phone, put the options in the rows of a `FieldGroup` inside the `RadioGroup`: each `Field row` names an option, and its `RadioGroup.Item` without children is the checkmark at the end of the row, as in an iOS settings list. The group title names the choice. Direction, orientation, cards and the alignment check are desktop layouts, so those examples are desktop only.

## API

**RadioGroup** (root)

<PropsTable data={[
  { prop: "value", type: "string", description: "Controlled selected value" },
  { prop: "defaultValue", type: "string", description: "Initial selected value (uncontrolled)" },
  { prop: "onChange", type: "(value: string) => void", description: "Called when selected option changes" },
  { prop: "direction", type: '"col" | "row"', default: '"row"', description: "Item flow direction" },
  { prop: "disabled", type: "boolean", default: "false", description: "Disable the whole group" },
  { prop: "name", type: "string", description: "Name of the hidden radio inputs submitted with the owning form" },
  { prop: "required", type: "boolean", default: "false", description: "Marks the group and every hidden radio input as required" },
  { prop: "aria-label", type: "string", description: "Accessible group label" },
  { prop: "className", type: "string", description: "Extra classes on the group element" },
]} />

Other props, such as the `id`, `aria-describedby` and `aria-invalid` a `Field` passes, land on the group element.

**RadioGroup.Item**

<PropsTable data={[
  { prop: "value", type: "string", description: "Item value" },

  { prop: "block", type: "boolean", default: "false", description: "Stretch item to fill available width" },
  { prop: "orientation", type: '"left" | "right"', default: '"left"', description: "Position of the radio indicator relative to the label" },

  { prop: "className", type: "string", description: "Extra classes on the label element" },

Other props on `RadioGroup.Item` land on its wrapper `<div>`. The arrow keys move focus and check the focused option; Home and End move focus only (roving focus from Radix). Inside a `<form>`, hidden native radios mirror the selection so the value is submitted with the form.

## Styling

Radio Group reads these component tokens. Override them at any scope to restyle it:

- `--radio-group-col-gap`: col gap (default `spacing(2.5)`)
- `--radio-group-indicator-background-color`: indicator background color (default `var(--color-background-primary-solid)`)
- `--radio-group-indicator-border-color`: indicator border color (default `var(--color-border-primary-outline)`)
- `--radio-group-indicator-border-color-hover`: indicator border color hover (default `var(--alpha-25)`)
- `--radio-group-indicator-hole-background-color`: indicator hole background color (default `var(--color-text-primary-solid)`)
- `--radio-group-indicator-hole-size`: indicator hole size (default `0.375rem`)
- `--radio-group-indicator-size`: indicator size (default `var(--font-text-lg-size)`)
- `--radio-group-item-font-size`: item font size (default `var(--font-text-sm-size)`)
- `--radio-group-item-gap`: item gap (default `spacing(1.5)`)
- `--radio-group-item-line-height`: item line height (default `var(--font-text-sm-line-height)`)
- `--radio-group-row-gap`: row gap (default `spacing(5)`)
