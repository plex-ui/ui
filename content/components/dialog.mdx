<UsageBlock>{`import { Dialog } from "@plexui/ui/components/Dialog";`}</UsageBlock>

At 640px and below, `mobileVariant="alert"` presents a compact centered confirmation with inline actions and no close icon. Use `mobileVariant="sheet"` for forms and details: it opens at the bottom with a grabber, a leading Close button and a centered title. Both variants preserve the desktop appearance.

Alert actions wrap onto separate rows when their labels need more space. Set `<Dialog.Footer mobileLayout="stacked">` when the actions should always stack. Put long sheet content in `Dialog.Body` to keep the header and actions visible while the body scrolls.

## API

**Dialog** (root)

  { prop: "open", type: "boolean", description: "Controlled open state; uncontrolled when omitted" },

**Dialog.Content**

<PropsTable data={[
  { prop: "width", type: "number | string", default: "480", description: "Panel width. Mobile alert uses its compact width; a bottom sheet fills the viewport width" },
  { prop: "showClose", type: "boolean", default: "true", description: "Show the built-in close button. Mobile sheet places it at the leading edge; mobile alert hides it" },
  { prop: "pill", type: "boolean", default: "false", description: "Rounder panel and a round close button, for dialogs beside pill controls" },
  { prop: "className", type: "string", description: "Additional CSS class on the panel" },
  { prop: "placement", type: '"center" | "top" | "bottom" | "start" | "end" | "fullscreen"', default: '"center"', description: "Where the panel sits: centered, near the top, a bottom sheet, a side panel, or the whole screen" },
  { prop: "mobileVariant", type: '"alert" | "sheet"', description: "Mobile appearance at 640px and below. Alert is compact and centered; sheet defaults to the bottom. Omit for the standard appearance" },
  { prop: "mobilePlacement", type: '"center" | "bottom" | "fullscreen"', description: "Placement at 640px and below. Defaults to bottom for sheet, otherwise placement. Alert stays centered" },
  { prop: "onOpenAutoFocus", type: "(event: Event) => void", description: "Called when focus moves into the dialog on open; call event.preventDefault() to place it yourself, for example on the panel instead of the first field" },
  { prop: "onCloseAutoFocus", type: "(event: Event) => void", description: "Called when focus returns on close; call event.preventDefault() to keep it elsewhere" },
]} />

**Dialog.Trigger**: opens the dialog; renders its child element (Radix `asChild`).

**Dialog.Header**: wrapper for title, description and an optional header action.

**Dialog.HeaderAction**: positions one toolbar control beside Close on desktop and opposite Close in a mobile sheet. Place it inside Dialog.Header and label icon-only controls. Mobile alerts hide this slot.

**Dialog.Title**: accessible heading for the dialog.

**Dialog.Description**: supporting text under the title.

**Dialog.Body**: the scrolling part between the header and the footer. With it, only the body scrolls. Accepts `className`.

**Dialog.Footer**: footer area for action buttons. Mobile alert actions are 48px pills in a wrapping row by default. Mobile sheets use 50px pill actions, 24px side gutters and at least 24px below the actions, including the bottom safe area. Standard dialogs and sheets stack their mobile actions.

<PropsTable data={[
  { prop: "mobileLayout", type: '"inline" | "stacked"', description: "Action layout at 640px and below. Defaults to inline for alert, stacked otherwise. Inline actions wrap when they do not fit" },
]} />

**Dialog.Close**: closes the dialog when its child is activated.

## Styling

Dialog reads the shared semantic color, typography and spacing tokens listed in [Design tokens](/docs/foundations/design-tokens), so it follows theme changes made there. Override these Dialog tokens at any scope:

- `--dialog-close-background`: close button background (default `transparent`)
- `--dialog-close-background-hover`: close button background on hover

Standard mobile appearance uses these tokens:

- `--dialog-mobile-close-size`: visible close-button circle (default `--control-size-md`, 32px)
- `--dialog-mobile-close-icon-size`: close SVG box (default `--control-icon-size-2xl`, 24px; the glyph occupies about 12px)
- `--dialog-mobile-close-background`: mobile close button fill (default secondary soft)
- `--dialog-mobile-radius`: mobile panel corner radius (default `--radius-4xl`, 24px)
- `--dialog-mobile-action-size`: mobile footer height and close-button touch target (default `--control-size-2xl`, 44px)
- `--dialog-mobile-action-radius`: mobile footer button radius (default `--radius-full`)
- `--dialog-mobile-action-font-size`: mobile footer button text size (default `--control-font-size-lg`)

Alert and Sheet use these additional tokens:

- `--dialog-alert-width`: compact alert width (default `300px`, capped by the viewport)
- `--dialog-alert-radius`: alert corner radius (default `34px`)
- `--dialog-alert-padding`: alert outer padding (default `14px`)
- `--dialog-alert-action-height`: minimum Alert action height (default `48px`)
- `--dialog-sheet-action-height`: minimum Sheet action height (default `50px`)
- `--dialog-sheet-radius`: sheet top corner radius (default `38px`; fullscreen stays square)
- `--dialog-sheet-close-size`: sheet close-button circle and touch target (default `--control-size-2xl`, 44px)
- `--dialog-sheet-close-icon-size`: sheet close SVG box (default `34px`; the visible cross is about 17px)
- `--dialog-mobile-type-size`: Alert and Sheet heading, description and actions (default `17px`)
- `--dialog-mobile-type-leading`: Alert and Sheet heading, description and action line height (default `22px`)
