<UsageBlock>{`import { DateInput } from "@plexui/ui/components/DateInput";`}</UsageBlock>

On Phone, put a date input in a row of a `FieldGroup`, as the [Input](/components/input) examples and the [Settings Forms](/components/settings-forms) do. The row is its frame and sets its height, insets and type, so the Phone previews show rows without the `variant`, `size`, `pill` and `invalid` controls (a row shows its error as [Validation](#validation) does). To pick a date rather than type it, use the compact date of a [Date Picker](/components/date-picker) in the row.

## Styling

Date Input reads these component tokens. Override them at any scope to restyle it:

- `--input-border-color-invalid`: border color invalid (default `var(--color-border-danger-outline)`)
- `--input-gap-lg`: gap lg (default `10px`)
- `--input-gap-md`: gap md (default `8px`)
- `--input-gap-sm`: gap sm (default `6px`)
- `--input-gap-xs`: gap xs (default `4px`)
- `--input-outline-border-color`: outline border color (default `var(--color-border-primary-outline)`)
- `--input-outline-border-color-focus`: outline border color focus (default `var(--alpha-50)`)
- `--input-outline-border-color-hover`: outline border color hover (default `light-dark(var(--alpha-25), var(--alpha-30))`)
- `--input-placeholder-text-color`: placeholder text color (default `var(--color-text-tertiary)`)
- `--input-soft-background-color`: soft background color (default `var(--color-background-primary-soft-alpha)`)
- `--input-soft-border-color-focus`: soft border color focus (default `var(--alpha-20)`)
- `--input-text-color`: text color (default `var(--color-text)`)
