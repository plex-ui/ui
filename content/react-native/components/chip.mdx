export const overviewCode = `import { Chip, Input, List, ListItem, Menu, NavigationButton } from "@plexui/react-native"
import { Filter, SearchSm } from "@plexui/react-native/icons"

const FILTERS = [
  { value: "rated", label: "Top Rated" },
  { value: "open", label: "Open Now" },
]
const SORTS = [
  { value: "match", label: "Best Match" },
  { value: "distance", label: "Distance" },
  { value: "rating", label: "Ratings" },
]

const [appearance, setAppearance] = useState<"glass" | "tag">("glass") // iOS
const [on, setOn] = useState<string[]>([])
const [sortOpen, setSortOpen] = useState(false)
const [sort, setSort] = useState("match")
const sortLabel = SORTS.find((option) => option.value === sort).label
// A filter that is on moves to the start of the row, as in Maps
const filters = [...on.map((value) => FILTERS.find((filter) => filter.value === value)), ...FILTERS.filter((filter) => !on.includes(filter.value))]

<View style={{ flexDirection: "row", alignItems: "center", gap: 8, paddingHorizontal: 16 }}>
  <View style={{ flex: 1 }}>
    <Input variant="soft" pill inputMode="search" placeholder="Search Maps" startAdornment={<SearchSm />} value={query} onChangeText={setQuery} onClear={() => setQuery("")} />
  </View>
  <NavigationButton action="close" accessibilityLabel="Close search" />
</View>
<ScrollView horizontal showsHorizontalScrollIndicator={false} contentContainerStyle={{ gap: 8, paddingHorizontal: 16 }}>
  <Chip appearance={appearance} icon={<Filter />} accessibilityLabel="Filters" onPress={openFilters} />
  {filters.map((filter) => (
    <Chip
      key={filter.value}
      appearance={appearance}
      selected={on.includes(filter.value)}
      onSelectedChange={(next) => setOn((list) => (next ? [...list, filter.value] : list.filter((value) => value !== filter.value)))}
    >
      {filter.label}
    </Chip>
  ))}
  <Menu open={sortOpen} onOpenChange={setSortOpen}>
    <Menu.Trigger>
      <Chip appearance={appearance} menu expanded={sortOpen} accessibilityLabel={\`Sort by, \${sortLabel}\`}>
        {\`Sort by \${sortLabel}\`}
      </Chip>
    </Menu.Trigger>
    <Menu.Content aria-label="Sort by">
      {SORTS.map((option) => (
        <Menu.Item key={option.value} checked={option.value === sort} onSelect={() => setSort(option.value)}>
          {option.label}
        </Menu.Item>
      ))}
    </Menu.Content>
  </Menu>
</ScrollView>
<List>
  {places.map((place) => <ListItem key={place.name} label={place.name} description={place.details} />)}
</List>`

### Overview

<ComponentPreview details={<>
  <p>Chip's props follow the toggles of <code>@plexui/ui</code> (<code>selected</code>, <code>onSelectedChange</code>) and Badge's <code>onRemove</code>. iOS has no chip control, so a chip is drawn as the filter capsules of iOS 26 apps, measured on an iPhone in Maps: <code>appearance="tag"</code>, the default, a 40pt capsule of the gray fill (a tag cloud in a sheet, see Filters), or <code>glass</code>, a 44pt glass capsule (filters in a row over content, under a search); the label 17/22 Regular, and a selected chip filled in the app's accent (its tint) with a white label. On Android a chip is a 32dp capsule filled with the text color at 5%, its label 14sp Regular, pressed in the press color of a List row (black at 6%, white at 5% in dark mode); a selected filter chip fills in the Plex primary. On both, the chip stands in a 44pt (iOS) or 48dp (Android) touch target.</p>
  <p>Here a search for breakfast, as in Maps: under the search field a row of glass chips over the results, the filter button first, scrolling sideways when it is wider than the screen. Top Rated and Open Now are filter chips: a chip with <code>selected</code>, <code>defaultSelected</code> or <code>onSelectedChange</code> toggles on a press, and VoiceOver and TalkBack read it as a checkbox. Once on, a filter moves to the start of the row, as Maps moves it; that order is the app's. A chip with <code>onPress</code> alone is an action chip (Material's assist chip): it runs the action and keeps no state, as the filter button at the start of the row, a chip of an <code>icon</code> alone: with no label it is a circle as tall as the chip, named by <code>accessibilityLabel</code>.</p>
  <p>Sort by picks among options, so it opens a menu: <code>menu</code> puts a chevron after the label (iOS's small chevron down, Material's drop-down arrow) and tells a screen reader the chip opens a popup, <code>true</code> or <code>"menu"</code> a menu, <code>"listbox"</code> or <code>"dialog"</code> what else it opens; <code>expanded</code> says whether it is open. A menu chip is read as a button, not a checkbox, and <code>accessibilityLabel</code> names it with the chosen value. <code>trailingIcon</code> puts another symbol after the label in the chevron's place.</p>
  <p><code>icon</code> puts a symbol before the label (20pt on iOS, 18dp on Android). <code>disabled</code> dims a chip (on Android to half, its fill with it; on iOS the label of an off chip turns the disabled gray and a selected chip's accent fades to 40%) and takes no presses; a selected chip stays selected.</p>
</>} code={overviewCode} previewMinHeight={168}>

### Removable

<ComponentPreview details={<>Input chips are values the reader entered and can take back, here the recipients of a message. iOS has no chip with a cross: Apple's removable values are tokens (the search tokens of Mail, Photos and Files, the recipients of Mail and Messages), so <code>removeStyle="token"</code>, the default, draws none: a press selects the chip in the accent, a second press or Delete on a web keyboard removes it, choosing another token lets the first go, and VoiceOver reads it as selected and offers <code>removeLabel</code> as an action; leaving the chip lets the selection go. <code>removeStyle="button"</code> puts a cross after the label drawn as the field's clear button, xmark.circle.fill at 17pt in the tertiary label in a 44pt target. ## Platforms

| | iOS 26 | Android |
| --- | --- | --- |
| Native component | None: drawn as the filter capsules of iOS apps | Chip (assist, filter, input) |
| Look | A 40pt gray capsule (`tag`) or a 44pt glass one (`glass`), filled in the accent when selected | A 32dp capsule in a light gray fill, filled in the Plex primary when selected |
