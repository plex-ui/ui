import { CheckMd, Health } from "@plexui/react-native/icons"
import { ScrollView, View } from "react-native"

const [second, setSecond] = useState(true)
const [floating, setFloating] = useState(true)
const [background, setBackground] = useState("soft") // or "fade", with floating
const [form, setForm] = useState(null)
const row = (choice) => (
  <ListItem key={choice} label={choice} trailing={form === choice ? <CheckMd color={theme.colors.accent} /> : undefined} disclosure={false} onPress={() => setForm(choice)} />
)

<View style={{ flex: 1 }}>
  {/* Floating actions stand over the lists: the end keeps their room, so the last row scrolls clear of them */}
  <ScrollView contentContainerStyle={{ paddingHorizontal: 20, paddingTop: 72, paddingBottom: floating ? 160 : 24 }}>
    <View style={{ alignItems: "center", marginBottom: 24 }}>
      <Health size={64} color={theme.colors.accent} />
    </View>
    <Text variant="title2" weight="bold" style={{ marginHorizontal: 20, marginBottom: 8 }}>Choose the Medication Type</Text>
    <List surface="plain" header="Common Forms">{["Capsule", "Tablet", "Liquid", "Topical"].map(row)}</List>
    <List surface="plain" header="More Forms" style={{ marginTop: 16 }}>{["Cream", "Device", "Drops", "Foam", "Gel"].map(row)}</List>
  </ScrollView>
  <BottomActions floating={floating} background={background}>
    <Button color="primary" variant="solid" disabled={form === null} onPress={next}>Next</Button>
    {second && <Button color="secondary" onPress={skip}>Skip</Button>}
  </BottomActions>
</View>`

## Examples

### Overview

<ComponentPreview details={<>
  <p>BottomActions holds a screen's main action at its bottom: an onboarding's Continue, a setup step's Next, a form's Create account. The example is a step of a setup flow after the iOS 27 Health app's Choose the Medication Type: Next stays disabled until a form is chosen, and the lists run on under it. Use it for the one action that moves a person on from the screen, with at most a second, quieter one under it (Not now, Skip); actions of the content stay in the content. It is React Native only: the web has no bottom of a screen to stand at.</p>
  <p>On iOS the action is a capsule across the screen, 36pt from its sides and 52pt tall, its bottom just over the home indicator (2pt above the safe area), as iOS 26's own setup screens set it. On Android it is a full-width 48dp button, 16dp from the sides and 16dp above the gesture bar. Each Button inside is a block of the size <code>3xl</code> unless it sets its own <code>block</code> or <code>size</code>; a second action stands under the first, 8 apart. A second Button with no <code>variant</code> of its own takes the platform's: on iOS a glass capsule of the main one's size, as Apple's step-by-step sheets set Skip; on Android a ghost button.</p>
  <p><code>floating</code> lays the actions over the content, a scroll view under them, which then keeps their room at its end so its last line scrolls clear of them. Over the content the actions stand on a soft edge, as a bottom <a href="/react-native/components/toolbar">Toolbar</a> draws: on iOS the screen's color fading in over 27pt above them (with a light blur on the web), on Android the screen's color fading in. <code>background="fade"</code> lets the content run on under the actions, crisp, as TabBar's <code>fade</code>: from the top action's top the screen's color comes in over 60pt to 85% and holds to the screen's edge, with no blur (Android keeps its soft edge). <code>canvasColor</code> sets the color it fades into, a grouped screen's gray. Without it the actions take their own room at the end of the screen.</p>
