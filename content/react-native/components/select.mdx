export const overviewCode = `import { List, ListItem, Select } from "@plexui/react-native"

const CURRENCIES = [
  { label: "US dollar", value: "usd" },
  { label: "Euro", value: "eur" },
  { label: "British pound", value: "gbp" },
  { label: "Japanese yen", value: "jpy" },
  { label: "Swiss franc", value: "chf" },
  { label: "Canadian dollar", value: "cad" },
  { label: "Australian dollar", value: "aud" },
]

const [currency, setCurrency] = useState<string | null>(null)
const [disabled, setDisabled] = useState(false)

// The select is the value of a row: a ghost field as wide as its value
<List>
  <ListItem
    label="Currency"
    disabled={disabled}
    trailing={
      <Select
        aria-label="Currency"
        options={CURRENCIES}
        value={currency}
        onChange={(option) => setCurrency(option.value)}
        placeholder="None"
        variant="ghost"
        block={false}
        disabled={disabled}
      />
    }
  />
</List>`

const [role, setRole] = useState("editor")

### Overview

<ComponentPreview details={<>
  <p>On a phone, put a select in a row of a <code>List</code>, the grouped section of a settings form: the value and its indicator sit at the row's end, a <code>ghost</code> field with <code>block={"{false}"}</code>, and a press opens a menu of the options with a checkmark at the chosen one. On iOS it is the row's pop-up button, as on the web's phone: the value in the secondary gray (the placeholder lighter), the menu picker's small up and down chevrons after it, and the menu opening over it at its end; on Android the value alone in the accent (the placeholder in the hint's gray), and a press anywhere on the row opens a single-choice dialog in the middle of the screen: the setting's name as its title (<code>title</code>, else the <code>aria-label</code>), a 50dp row with a radio for each option, and Cancel (<code>cancelLabel</code>). Choosing a row picks it and closes the dialog; Cancel, a tap on the dim or Back closes it as it was. Outside a row the Android field keeps its dropdown arrow and opens the same dialog.</p>
  <p>Pass the chosen option's value as <code>value</code>, or <code>null</code> while nothing is chosen, when the field shows the <code>placeholder</code> in the placeholder color: None here, as an iOS pop-up button names an empty choice. <code>onChange</code> receives the option a person chooses. The field is drawn as an <a href="/react-native/components/input">Input</a> of the same <code>variant</code> and <code>size</code>; <code>pill</code> makes a capsule, and <code>block</code>, the default, fills the width, while <code>block={"{false}"}</code> makes the field as wide as its value, as at the end of a row. <code>invalid</code> draws the field in the error color.</p>
  <p><code>disabled</code> dims the field and takes no presses; a field disabled while its menu is open closes the menu. In a form, pass <code>disabled</code> to the row's <code>ListItem</code> too, which dims its label. An option's own <code>disabled</code> shows it dimmed in the menu, where it cannot be chosen.</p>
  <p>As the row's <code>ghost</code> field, in its <code>trailing</code> slot, the example offers neither <code>variant</code> nor <code>size</code>. Of the React page's phone settings, React Native's Select has <code>disabled</code> only: it has no <code>checkPosition</code> (the checkmark always leads the chosen row on iOS; Android marks it with its radio), no <code>clearable</code> None row, no <code>multiple</code> selection and no <code>loading</code> state.</p>

## Platforms

| | iOS 26 | Android |
| --- | --- | --- |
| Native component | Pop-up button (menu picker) | Single-choice dialog |
| Look | An up and down chevron; a glass menu at least 250pt wide, over the value in a row | The value in the accent in a row (a dropdown arrow on a field); a dialog of radio rows with Cancel |
