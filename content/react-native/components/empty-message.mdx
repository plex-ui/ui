<UsageBlock>{`import { EmptyMessage } from "@plexui/react-native"`}</UsageBlock>

The parts follow `@plexui/ui`'s EmptyMessage (`EmptyMessage.Icon`, `.Title`, `.Description`, `.ActionRow`); `EmptyState` is the same component under the pattern's name on the phone platforms. On iOS the phone layer's layout, as SwiftUI's ContentUnavailableView: a 48pt symbol 19pt over the title, the title 20/25 bold, the description 17/25 in the secondary label, actions 28pt under it. Material has no empty-state spec, so Android keeps the same layout in Material's type: the title in Title L, the description in Body M, the symbol and the description in `onSurfaceVariant`.

### Compact

`size="sm"` is for a panel, a card or an empty list: the symbol becomes a 32pt tinted tile with a 20pt symbol, and the description on iOS is 15/20.
