const [iconColor, setIconColor] = useState("secondary") // or "danger", "warning"
const [title, setTitle] = useState(true)
const [titleColor, setTitleColor] = useState("secondary") // or "danger", "warning"
const [description, setDescription] = useState(true) // a message needs a title or a description
const [actions, setActions] = useState("one") // or "two", "none"

const buttonSize = Platform.OS === "android" ? undefined : size === "sm" ? "md" : "sm"

// The space under the screen's top bar: a static or absolute message fills it
<View style={{ flex: 1 }}>
  <EmptyMessage fill={fill} size={size} align={align}>
    {icon && (
      <EmptyMessage.Icon color={iconColor} size={size === "md" ? iconSize : undefined}>

      </EmptyMessage.Icon>
    )}

          <Button color="primary" variant="ghost" size={buttonSize}>
            Browse templates
          </Button>

### Overview

<ComponentPreview details={<>
  <p>The parts follow <code>@plexui/ui</code>'s EmptyMessage (<code>EmptyMessage.Icon</code>, <code>.Title</code>, <code>.Description</code>, <code>.ActionRow</code>); <code>EmptyState</code> is the same component under the pattern's name on the phone platforms. On iOS the phone layer's layout, as SwiftUI's ContentUnavailableView: a 48pt symbol 19pt over the title, the title 20/25 bold, the description 17/25 in the secondary label, actions 28pt under it. On Android the view stands 46dp in from the sides: the symbol in gray 12dp over a Medium 20 title, the description 14sp in gray 8dp under it, and actions 16dp under that across the column, 74dp from the screen's edges; a Button that sets no size or width of its own there is the big 48dp pill, as wide as the column.</p>
  <p>An empty message is made of parts, each optional: an icon, a title, a description and an action row. It needs a title or a description, so this preview offers <code>description</code> with a title. <code>color</code> on <code>EmptyMessage.Icon</code> and on <code>EmptyMessage.Title</code> shows the intent of the message, such as <code>danger</code> on both for an error (a missing permission) or <code>warning</code> on the icon for a notice (a feature in beta); the description keeps its own color.</p>
  <p><code>fill</code> sizes the message to its parent: <code>static</code> grows to fill the space it is given and centers in it, <code>absolute</code> covers its parent and centers, and <code>none</code> hugs its content, for a container that sets the height (a list with no results). Use <code>size="sm"</code> for an empty panel, card section or list: the symbol becomes a 32pt tinted tile with a 20pt symbol and the description on iOS is 15/20; in a message of the default size the icon takes its own <code>size</code>. <code>align="start"</code> lines the message up at the start, for an empty state under a section heading.</p>

Its actions stand under the text, each at its own width, one under the other: a small capsule, then a plain button for a second action. On a screen with a bar, an action that adds (such as New project) can stand in the bar instead, as iOS apps put it. Android sets the same parts in its own sizes.</p>
  <p>The React page also offers a text link as the action, a <code>TextLink</code>; React Native has no text link, so this example does not offer it.</p>
