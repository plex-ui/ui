### Overview

<ComponentPreview details={<>
  <p>The props follow <code>@plexui/ui</code>'s Avatar. Both platforms draw the Plex avatar from the same tokens: the initial at half the size in semibold, a picture with a hairline border inside its edge, and the semantic colors of the soft and solid fills. React Native adds a third fill, <code>gradient</code>.</p>
  <p>An avatar shows one of four things. Without other props it shows the first letter of <code>name</code>. With <code>imageUrl</code>, an absolute URL, or <code>source</code>, an Image source such as a bundled <code>require()</code>d asset, it shows the picture over the initial, and the initial stays while it loads or if it fails. With <code>Icon</code>, an icon component such as <code>Robot</code> from <code>@plexui/react-native/icons</code>, it shows the symbol at 70% of the size, as the web's; <code>name</code> is not shown, and only names the avatar for screen readers. With <code>overflowCount</code> it shows the count, formatted (+1k) and scaled to fit.</p>
  <p><code>size</code> sets the width and height in points, and the initial, symbol and count scale with it; without it an avatar is 28. <code>color</code> and <code>variant</code> style every avatar except a loaded picture, which covers them. <code>onPress</code> makes the avatar a button, named by its <code>name</code>, that dims while pressed. iOS and Android draw the same avatar.</p>
  <p><code>variant="gradient"</code> draws the avatar as a circle with a top-to-bottom gradient in one of seven colors (red, orange, violet, green, cyan, blue, pink) and up to two white initials in Medium: the first letters of the first and the last word of <code>name</code>. A <code>secondary</code> avatar takes its gradient from the name, the same each time; the other colors take the nearest one (<code>danger</code> red, <code>discovery</code> violet, <code>success</code> green, <code>info</code> and <code>primary</code> blue). A count keeps the soft fill. It draws the same on both platforms.</p>
  <p>An avatar is always a circle, as avatars are on both platforms: the React page's <code>roundness</code> is a Tailwind class on the web avatar, and a React Native avatar has no such setting (a <code>style</code> radius would square the fill but not the picture), so this example does not offer it.</p>
</>} code={overviewCode} previewMinHeight={228}>
