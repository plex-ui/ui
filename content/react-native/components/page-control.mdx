<UsageBlock>{`import { PageControl } from "@plexui/react-native"`}</UsageBlock>

The props follow `@plexui/ui`'s PageControl. On iOS the page control of iOS 26: 8pt dots 8pt apart, the current one in the label color and the rest in the tertiary label, a 24pt capsule behind them while pressed and a 44pt touch target. Material has no page indicator of its own, so Android draws the same dots, the current one in `onSurface` and the rest in `outlineVariant`. A tap on either side of the current dot shows the previous or next page and a drag scrubs page by page. For screen readers the control is adjustable: swipe up or down for the next or previous page.

## Examples

### Overview

Control the page with `value` and `onChange`, and show that page's content.

<RNPreview demo="page-control/Overview" code={overviewCode} />

### Many pages

Up to six pages show every dot. From seven, a window of full-size dots holds the current page, with smaller dots past each side of it, as iOS does.

<RNPreview demo="page-control/ManyPages" code={manyPagesCode} />

### Background

`background` sets the capsule behind the dots: `automatic` shows it while a finger presses or scrubs, `prominent` always, `minimal` never, and a minimal control does not scrub.
