<UsageBlock>{`import { RadioGroup } from "@plexui/react-native"`}</UsageBlock>

The props follow `@plexui/ui`'s RadioGroup, with `RadioGroup.Item` for each option. iOS has no radio button: the chosen option shows the checkmark of a list row in a 22pt column, and the others leave the column empty, in 44pt rows. Android draws Material 3's 20dp radio button, a 2dp ring with a dot in the Plex primary, in a 48dp touch target with the press's state layer. A phone stacks the options in a column by default.

`orientation="right"` on an item puts its mark after the label.
