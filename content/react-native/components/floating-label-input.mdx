## Examples

### Overview

<ComponentPreview details={<>
  <p>iOS has no floating label: on iOS the field is a cell of a <code>List</code> on the grouped background, named by its placeholder (the label), as the web's phone view draws it with <code>Field row hideLabel</code>. The label stays the field's name for screen readers.</p>

### Text fields

Everything that is typed: more than one line, or a password. Values with a mask, such as an [SSN](/react-native/components/input#ssn-input) or a [birthday](/react-native/components/input#birthday-input), are on the Input page.

#### Password input

### Selects

React Native has no floating-label select: a `Select` alone in a label-hidden row is its cell, named by its placeholder.

## Platforms

| | iOS 26 | Android |
| --- | --- | --- |
| Native component | Text field in a form cell (no floating label) | Text field, outlined, with a floating label |
| Look | A cell named by its placeholder; the error inside it, the description in the footer | An 8dp outlined field; the label springs from 16 to 12sp onto the line; 14sp help under it |
