<UsageBlock>{`import { DatePicker } from "@plexui/react-native"`}</UsageBlock>

The value is a plain `Date` in the device's time zone; a day keeps its time when only the day changes, and the other way round.

## Platforms

| | iOS 27 | Android |
| --- | --- | --- |
| Native component | UIDatePicker (`.compact`, `.inline`, `.wheels`), SwiftUI DatePicker | DatePicker and TimePicker of Material 3 (DatePickerDialog, TimePicker dial); spinner mode |
| Compact | Capsules that open the calendar and the wheels in a popover | A row's value or an outlined field that opens the dialog; OK applies |
| Inline | The month's calendar in place, a Time row under it | Material's calendar in place |
| Wheels | Wheels with a 32 band | Spinners between two lines |
