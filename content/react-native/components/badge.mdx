export const removableCode = `const TAGS = ["Design", "Mobile", "Plex"]
const [tags, setTags] = useState(TAGS)

{tags.map((tag) => (
  <Badge
    key={tag}
    size="lg"
    pill
    onRemove={() => setTags((list) => list.filter((item) => item !== tag))}
    removeLabel={\`Remove \${tag}\`}
  >
    {tag}
  </Badge>
))}
{tags.length === 0 ? <Button size="sm" variant="soft" onPress={() => setTags(TAGS)}>Reset</Button> : null}`

<UsageBlock>{`import { Badge } from "@plexui/react-native"`}</UsageBlock>

The props follow `@plexui/ui`'s Badge. iOS has no badge control for text, and Material 3's badge is a dot or a count on an icon (TabBar draws that one), so both platforms draw the Plex badge from the same tokens: the size, gutter, radius and semibold type of each size, and the semantic colors of the fills.

### Sizes and pill

Four sizes, 20 to 36 points tall. `pill` rounds the ends into a capsule.

<RNPreview demo="badge/Sizes" code={sizesCode} />

### Icons

An icon beside the text takes the badge's color and the size's icon size.

<RNPreview demo="badge/Icons" code={iconsCode} />

### Removable

`onRemove` adds a cross at the end, a button named by `removeLabel`. Inside a control that takes the press itself, `removable` draws the cross as a plain mark.
