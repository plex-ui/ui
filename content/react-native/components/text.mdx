<UsageBlock>{`import { Heading, Text } from "@plexui/react-native"`}</UsageBlock>

`variant` takes the text styles of the platform under Apple's names: on iOS the sizes of the Human Interface Guidelines (Body 17/22, Headline 17/22 semibold, Large Title 34/41); on Android each name takes the nearest role of the Material 3 type scale (Body Large 16/24, Title Medium 16/24 medium, Headline Large 32/40). `size` and `Heading` give the Plex UI scale instead, the same on both platforms. The face is Inter on both, with the Plex tracking at each size, and the colors follow iOS's label roles or Material's `onSurface` and `onSurfaceVariant`.

### Plex UI sizes

`size` sets a size of the Plex UI text scale (`--font-text-*`, 8 to 18) in place of a platform style.
