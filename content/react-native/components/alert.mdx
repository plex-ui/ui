## Platforms

| | iOS 26 | Android |
| --- | --- | --- |
| Native component | None (a Plex view in the shape of a TipKit tip) | None (a Plex view drawn as a card) |
| Look | Gray rounded card, the icon in the alert's color, capsule actions | A card with 16dp corners, the icon in the alert's color, 40dp capsule actions |

Neither platform has an inline alert: iOS's Alert is the modal [Dialog](/react-native/components/dialog), so an inline message takes the tip's shape.
