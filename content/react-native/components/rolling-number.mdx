## Examples

### Overview

<ComponentPreview details={<>
  <p>A rolling number turns each changed digit to its new value, as the wheels of an odometer do, so a total or a count that changes in front of the reader shows the change. Use it where a number moves while it is watched, such as a total as items are added; a number that only loads once needs none.</p>
  <p>Pass the number as <code>value</code>; a new value rolls each digit that changes, and the digits that stay still do not move. <code>format</code> and <code>locales</code> write it as <code>Intl.NumberFormat</code> does: here as a currency, a percent or a plain number, with its grouping. It takes the props of <code>Text</code> for its size, weight and color, as the web's classes. Separators, signs and the currency stand still; tabular figures keep each digit as wide, so the number does not shift while it rolls. On iOS each digit is a reel of 0 to 9 that turns in 600ms, as on the web; on Android it is the Plex Android look's animated text, a changed character fading out and away while the new one comes in, up for a larger number, in 320ms. It is read out as the written number, and with reduced motion the digits change at once.</p>
  <p><code>animation="count"</code> counts the whole number to a new value instead, through the numbers between, as a result runs up beside its bar: in <code>duration</code> on <code>easing</code> after <code>delay</code>, from <code>from</code> when it first shows (a result running up from 0). Each number is written in the format, rounded to the format&apos;s own digits (a percent, a currency) or to the value&apos;s decimals. <code>onCountEnd</code> is called when it gets there, so what comes next (the next result, a button fading in) can start then; with reduced motion it stands at the value at once and calls it. A screen reader reads the value it counts to.</p>
</>} code={overviewCode} codeValues={{ animation: "roll" }} previewMinHeight={240}>

</ComponentPreview>
