`@plexui/react-native` is not released yet: these pages document the `feat/react-native` branch. Every example on them is live, drawn by react-native-web. The switch above the examples draws them as iOS or Android, light or dark.

## Setup

<UsageBlock>{`npm install @plexui/react-native react-native-svg react-native-safe-area-context
# optional: native glass on iOS 26, a blur elsewhere
npx expo install expo-glass-effect expo-blur`}</UsageBlock>

Wrap the app in `ThemeProvider` inside `SafeAreaProvider`, and put one `Toaster` in it for `toast()`:

```tsx
import { ThemeProvider, Toaster, interFonts } from "@plexui/react-native"
import { SafeAreaProvider } from "react-native-safe-area-context"

export default function App() {
  return (
    <SafeAreaProvider>
      <ThemeProvider fonts={interFonts}>
        <Screens />
        <Toaster />
      </ThemeProvider>
    </SafeAreaProvider>
  )
}
```

`ThemeProvider` follows the device: iOS draws the iOS 26 look, Android the look of Android 16 and Google's own apps (Material 3 Expressive), the web the iOS look. `platform` overrides it, `scheme` takes `"light"`, `"dark"` or `"system"`, and `brand` sets a product's colors, faces and radii over the Plex UI defaults.
