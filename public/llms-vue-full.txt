# PlexUI for Vue: full reference
> PlexUI for Vue 3: the same components, props, markup and styles as the React library.

Vue 3 components with the same names, props, defaults and markup as the React library. Quick overview: https://plexui.com/llms-vue.txt

Install: npm install @plexui/vue
Docs: https://plexui.com
Components: 40

## Setup

```css
@import "tailwindcss";
@import "@plexui/styles/css";
```

Wrap your app with <PlexUIProvider :link-component="RouterLink"> from "@plexui/vue/components/PlexUIProvider"

Size scale: 3xs, 2xs, xs, sm, md, lg, xl, 2xl, 3xl
Colors: primary, secondary, danger, success, warning, caution, discovery, info
Variants: solid, soft, outline, ghost

---

## Accordion
Vertically stacked panels that expand to reveal content, with one or several items open at a time and full keyboard navigation.
Import: import { Accordion, AccordionContent, AccordionItem, AccordionTrigger } from "@plexui/vue/components/Accordion"
Docs: https://plexui.com/vue/components/accordion

### Overview
```vue
<Accordion type="single" collapsible default-value="shipping" style="width: 100%; max-width: 384px">
  <AccordionItem value="shipping">
    <AccordionTrigger>What are your shipping options?</AccordionTrigger>
    <AccordionContent>
      We offer standard (5–7 business days), express (2–3 days), and
      overnight shipping. Free standard shipping on orders over $50.
    </AccordionContent>
  </AccordionItem>
  <AccordionItem value="returns">
    <AccordionTrigger>What is your return policy?</AccordionTrigger>
    <AccordionContent>
      Returns are accepted within 30 days of delivery. Items must be unused
      and in original packaging. Refunds are processed within 5–7 business
      days of receipt.
    </AccordionContent>
  </AccordionItem>
  <AccordionItem value="support">
    <AccordionTrigger>How can I contact customer support?</AccordionTrigger>
    <AccordionContent>
      Reach us by email, live chat, or phone Monday through Friday, 9am–6pm
      ET. Weekend tickets are handled within 24 hours.
    </AccordionContent>
  </AccordionItem>
</Accordion>
```

### Single
Default shape. type="single" + collapsible lets users close the currently open item; without collapsible, one item is always open.
```vue
<Accordion type="single" collapsible default-value="trial" style="width: 100%; max-width: 384px">
  <AccordionItem
    v-for="item in [
      {
        value: 'trial',
        trigger: 'How long is the free trial?',
        content: '14 days, no credit card required. At the end of the trial you can keep the free tier or upgrade to Pro; your projects stay in place either way.',
      },
      {
        value: 'plan',
        trigger: 'Can I change plans mid-cycle?',
        content: 'Yes. Upgrades are prorated immediately; downgrades take effect at the next billing date. Invoices always reflect the exact span each plan was active.',
      },
      {
        value: 'invoices',
        trigger: 'Where can I find past invoices?',
        content: 'Billing → Invoices in your workspace settings. Every PDF is archived for seven years and can be pulled via the Billing API.',
      },
    ]"
    :key="item.value"
    :value="item.value"
  >
    <AccordionTrigger>{{ item.trigger }}</AccordionTrigger>
    <AccordionContent>{{ item.content }}</AccordionContent>
  </AccordionItem>
</Accordion>
```

### Multiple
Use type="multiple" when readers can keep several sections open at once: settings pages, long FAQs, step-by-step references.
```vue
<Accordion type="multiple" :default-value="['notifications']" style="width: 100%; max-width: 384px">
  <AccordionItem
    v-for="item in [
      {
        value: 'notifications',
        trigger: 'Notification settings',
        content: 'Pick which events trigger email, push, or in-app alerts. Release-blocker incidents always page the on-call regardless of quiet hours.',
      },
      {
        value: 'privacy',
        trigger: 'Privacy & security',
        content: 'Turn on two-factor, review active sessions, and manage connected apps. Workspace admins can also enforce SSO and hardware-key policies org-wide.',
      },
      {
        value: 'billing',
        trigger: 'Billing & subscription',
        content: 'View your current plan, payment method, and upcoming renewal. Seat changes apply immediately; the next invoice will include a prorated adjustment.',
      },
    ]"
    :key="item.value"
    :value="item.value"
  >
    <AccordionTrigger>{{ item.trigger }}</AccordionTrigger>
    <AccordionContent>{{ item.content }}</AccordionContent>
  </AccordionItem>
</Accordion>
```

### Disabled
Pass disabled to an AccordionItem to make it read-only. The row stays visible so the reader understands the section exists; keyboard focus skips it.
```vue
<Accordion type="single" collapsible default-value="history" style="width: 100%; max-width: 384px">
  <AccordionItem value="history">
    <AccordionTrigger>Can I see my usage history?</AccordionTrigger>
    <AccordionContent>
      Yes, the Activity tab logs every API call, deploy, and admin action
      for the last 90 days. Longer retention requires the Enterprise plan.
    </AccordionContent>
  </AccordionItem>
  <AccordionItem value="audit" disabled>
    <AccordionTrigger>Audit log export (Enterprise only)</AccordionTrigger>
    <AccordionContent>
      Upgrade to Enterprise to stream audit events to S3, Splunk, or your
      SIEM of choice.
    </AccordionContent>
  </AccordionItem>
  <AccordionItem value="two-factor">
    <AccordionTrigger>How do I enable two-factor auth?</AccordionTrigger>
    <AccordionContent>
      Settings → Security → Two-factor. You can use an authenticator app or
      a FIDO2 hardware key. Recovery codes are issued once at enrollment.
    </AccordionContent>
  </AccordionItem>
</Accordion>
```

## Alert
Inline message for notices and warnings with semantic colors, variants, a title, a description, action slots, and a dismiss control.
Import: import { Alert } from "@plexui/vue/components/Alert"
Docs: https://plexui.com/vue/components/alert
Props:
  - title (string | slot) — Title displayed in the alert
  - description (string | slot) — Description text
  - actions (slot) — Actions (for example buttons)
  - actions-placement ("end" | "bottom") — Placement of actions; automatic from sizing when unset
  - actions-class-name (string) — Class applied to the actions container
  - color (SemanticColors) default: "primary" — Color scheme
  - variant ("solid" | "soft" | "outline") default: "outline" — Style variant
  - @dismiss (() => void) — Shows the dismiss button when set

### Overview
```vue
<Alert
  title="Scheduled maintenance"
  description="We'll be offline 2 - 4 AM UTC on July 14 while we upgrade our database."
>
  <template #actions>
    <Button color="primary" variant="soft" pill>Dismiss</Button>
  </template>
</Alert>
```

### Colors & variants
You can stylize the display of the alert using the color and variant props.
```vue
<div class="w-fit min-w-full max-w-[500px]">
  <div class="flex flex-col gap-6">
    <div
      v-for="color in ['primary', 'success', 'danger', 'warning', 'caution', 'info', 'discovery']"
      :key="color"
      class="flex items-center"
    >
      <div class="text-right text-sm mr-8 min-w-[4rem]" style="color: var(--color-text-tertiary)">{{ color }}</div>
      <div class="flex-1">
        <Alert :color="color" :variant="variant" title="Scheduled maintenance on Saturday, 2-4 AM PT">
          <template #description>
            Track status updates on <TextLink color="currentcolor" href="#">status page</TextLink>
          </template>
        </Alert>
      </div>
    </div>
  </div>
</div>
```

### Title
You can optionally include a title for your alert with the title prop (or the title slot).
```vue
<Alert title="Your current access level limits what you can view or modify" />
```

### Description
You can optionally include description text for your alert with the description prop, or the description slot for rich content.
```vue
<Alert>
  <template #description>
    We're working on centralizing SCIM and invite settings. For now, setup is handled within individual product settings. <TextLink href="#">Learn more</TextLink>
  </template>
</Alert>
```

### Actions
You can add actions to the alert with the actions slot. Combine with @dismiss to add a dismiss button.
```vue
<div class="flex flex-col items-center justify-center gap-6 w-full">
  <Alert
    variant="soft"
    color="warning"
    title="Password expires in 3 days"
    description="Update it now to avoid losing access to your account."
  >
    <template #actions>
      <Button color="primary" pill>Update password</Button>
    </template>
  </Alert>
  <Alert
    variant="soft"
    color="warning"
    title="Your API key will be rotated soon"
    description="Automatic key rotation is scheduled for March 10. Download the new key afterward to keep your integrations running."
    @dismiss="() => {}"
  >
    <template #actions>
      <Button color="warning" variant="soft" pill>Remind me later</Button>
    </template>
  </Alert>
</div>
```

### Action placement
Actions are automatically positioned in the alert by default. You can force a specific position with the actions-placement prop by passing either 'end' or 'bottom'.
```vue
<Alert
  title="Our terms of service has been updated"
  description="We've updated our terms to clarify how we handle data, billing, and user permissions. Please review and accept the latest terms to avoid impacting your service."
  actions-placement="bottom"
>
  <template #actions>
    <Button color="primary" variant="soft" pill>Set reminder</Button>
    <Button color="primary" variant="solid" pill>Review terms</Button>
  </template>
</Alert>
```

### Indicator
Alert provides an indicator icon by default. You can override it with the indicator slot, or pass :indicator="false" to hide it entirely.
```vue
<div class="flex flex-col items-center justify-center gap-6 w-full">
  <Alert>
    <template #indicator>
      <Lightbulb />
    </template>
    <template #description>
      We're working on centralizing SCIM and invite settings. For now, setup is handled within individual product settings. <TextLink href="#">Learn more</TextLink>
    </template>
  </Alert>
  <Alert
    :indicator="false"
    description="Version 2.18.5 rolls out behind-the-scenes tweaks to caching and background sync. You don't need to do anything."
  />
</div>
```

### Dismissible
The suggested approach for dismissible notices is to use labeled buttons in the actions slot. You can also listen to @dismiss to render a dismiss button in the alert chrome.
```vue
<div class="flex flex-col items-center justify-center gap-6 w-full">
  <Alert
    class="items-start"
    title="Try our new dashboard layout"
    description="We've introduced a streamlined layout that makes using the dashboard even easier. You can switch back any time."
  >
    <template #actions>
      <Button color="primary" variant="soft" pill>Dismiss</Button>
      <Button color="primary" variant="solid" pill>Try it</Button>
    </template>
  </Alert>
  <Alert
    title="Thank you!"
    description="Your application has been received. We will review your application and respond within the next 48 hours."
    @dismiss="() => {}"
  />
</div>
```

## Avatar
An avatar for user identities that shows an initial, a photo or an icon, with overflow counts, semantic colors and roundness options.
Import: import { Avatar } from "@plexui/vue/components/Avatar"
Docs: https://plexui.com/vue/components/avatar
Props:
  - name (string) — Display name; used for text initial when no image/icon
  - image-url (string) — Absolute URL for image avatar
  - Icon (Component) — Icon component for icon avatar, bound as :Icon
  - size (number) — Width and height in pixels
  - color ("primary" | "secondary" | "success" | "info" | "discovery" | "danger") default: "secondary" — Semantic color for text/icon avatar
  - variant ("soft" | "solid") default: "soft" — Style variant
  - overflow-count (number) — Show overflow count (e.g. +9)
  - class (string) — Applied to the avatar root
  - @click ((event: MouseEvent) => void) — Makes avatar interactive (renders a button)
  - @pointerdown ((event: PointerEvent) => void) — Makes avatar interactive (renders a button)

### Overview
A variety of avatar types: text, image, icon, and overflow.
```vue
<div class="flex gap-4">
  <Avatar name="Tyler" image-url="https://gravatar.com/avatar/9531b260b9693f3394bea8646c6ea141ce58fe5a138b7db7729d60a4c5dde552" :size="48" />
  <Avatar name="Will" :size="48" />
  <Avatar name="Tech support" :Icon="Robot" :size="48" color="primary" variant="solid" />
</div>
```

### Text
For text-based avatars, a single initial is displayed based on the name prop passed to the component.
```vue
<Avatar name="David" :size="48" />
```

### Image
To display an image avatar, provide an absolute URL to the image with image-url. Images will have a soft fade entrance once loaded, or fall back to a text display if the image fails to load.
```vue
<Avatar
  name="Tyler"
  image-url="https://gravatar.com/avatar/9531b260b9693f3394bea8646c6ea141ce58fe5a138b7db7729d60a4c5dde552"
  :size="48"
/>
```

### Icon
To display an icon avatar, pass an icon component to the Icon prop, for example Robot imported from @plexui/vue/components/Icon. The name prop is not used in this case, and can be omitted.
```vue
<Avatar
  :Icon="Robot"
  :size="48"
/>
```

### Overflow count
To display an overflow avatar, provide a number to the overflow-count prop. The number will be automatically formatted and scaled to fit.
```vue
<Avatar :overflow-count="overflowCount" :size="size" />
```

### Sizing
To size the avatar, pass a number to the size prop, which will set the width and height in pixels. Text and icon avatars will scale their sizes dynamically based on this value.
```vue
<Avatar name="David" :size="size" />
```

### Colors & variants
You can stylize the display of the avatar using the color and variant props.
```vue
<div
  class="grid items-center gap-x-8 gap-y-5"
  style="grid-template-columns: repeat(2, minmax(0, auto)) auto; justify-items: center"
>
  <div
    v-for="variant in ['soft', 'solid']"
    :key="variant"
    class="text-sm font-medium"
    style="color: var(--color-text-tertiary)"
  >{{ variant }}</div>
  <div />
  <template v-for="(color, idx) in ['primary', 'secondary', 'success', 'danger', 'info', 'discovery']" :key="color">
    <Avatar
      v-for="variant in ['soft', 'solid']"
      :key="variant"
      :name="String.fromCharCode(65 + idx)"
      :color="color"
      :variant="variant"
      :size="size"
    />
    <div class="text-sm font-medium justify-self-start" style="color: var(--color-text-tertiary)">{{ color }}</div>
  </template>
</div>
```

### Roundness
By default, avatars are fully rounded. You can override this by passing a Tailwind rounding class to class.
```vue
<Avatar
  name="Acme, co."
  color="primary"
  variant="solid"
  :size="size"
  :class="'rounded-' + roundness"
/>
```

### Interactive
Avatars can be used as interactive elements by listening to @click (or @pointerdown). The avatar then renders a button and applies semantic and visual interaction styles.
```vue
<div class="flex items-center gap-4">
  <Avatar name="Will" :size="48" @click="saySup" />
  <Avatar
    image-url="https://gravatar.com/avatar/9531b260b9693f3394bea8646c6ea141ce58fe5a138b7db7729d60a4c5dde552"
    name="Tyler"
    :size="48"
    @click="saySup"
  />
  <Avatar name="Tech support" :Icon="Robot" :size="48" color="info" @click="saySup" />
</div>
```

## Avatar Group
Stacks user avatars into a single overlapping cluster, with a configurable stacking direction and one size for the whole group.
Import: import { Avatar, AvatarGroup } from "@plexui/vue/components/Avatar"
Docs: https://plexui.com/vue/components/avatar-group
Props:
  - default slot (VNode[]) — The avatars of the group
  - size (number) — Size of all avatars in the group
  - stack ("start" | "end") default: "start" — Stacking direction
  - class (string) — Applied to the group container; other attributes are not forwarded

### Overview
```vue
<AvatarGroup :size="42">
  <Avatar name="Tyler" image-url="https://gravatar.com/avatar/9531b260b9693f3394bea8646c6ea141ce58fe5a138b7db7729d60a4c5dde552" />
  <Avatar name="Jane" color="primary" variant="solid" />
  <Avatar name="Tech support" :Icon="Robot" variant="solid" />
  <Avatar :overflow-count="5" />
</AvatarGroup>
```

### Stacking direction
You can control the stacking direction using the stack prop, as either "start" or "end".
```vue
<AvatarGroup :stack="stack" :size="42">
  <Avatar name="Tyler" image-url="https://gravatar.com/avatar/9531b260b9693f3394bea8646c6ea141ce58fe5a138b7db7729d60a4c5dde552" />
  <Avatar name="Will" />
  <Avatar name="Tech support" :Icon="Robot" variant="solid" />
  <Avatar :overflow-count="5" variant="soft" />
</AvatarGroup>
```

### Group sizing
You can control the size of all avatars in the group by passing size directly to the &lt;AvatarGroup&gt; component.
```vue
<AvatarGroup :size="size">
  <Avatar name="Tyler" color="info" />
  <Avatar name="Jane" color="discovery" />
  <Avatar name="Will" color="danger" />
  <Avatar :overflow-count="5" />
</AvatarGroup>
```

## Badge
Compact label for statuses and inline metadata, with semantic colors, three variants and sizes, icon support, and a loading state.
Import: import { Badge } from "@plexui/vue/components/Badge"
Docs: https://plexui.com/vue/components/badge
Props:
  - default slot (VNode[]) — Content inside the badge
  - color ("secondary" | "success" | "danger" | "warning" | "info" | "discovery" | "caution") default: "secondary" — Semantic color
  - variant ("solid" | "soft" | "outline") default: "soft" — Style variant
  - size ("sm" | "md" | "lg") default: "sm" — Badge size
  - pill (boolean) default: false — Fully rounded

### Overview
Status badges in different colors and compositions.
```vue
<div class="flex gap-4 flex-wrap">
  <Badge color="success" size="lg">Successful</Badge>
  <Badge size="lg" class="gap-1.5"><LoadingIndicator /> In progress</Badge>
  <Badge color="danger" size="lg">Failed</Badge>
  <Badge color="warning" size="lg" pill><Flask /> Beta</Badge>
  <Badge color="caution" size="lg">Caution</Badge>
</div>
```

### Colors & variants
You can stylize the display of the badge using the color and variant props.
```vue
<div class="w-full overflow-x-auto">
  <div class="pt-1 pb-6 px-8 w-fit min-w-full">
    <div class="grid gap-6 items-center justify-center" style="grid-template-columns: auto repeat(7, min-content)">
      <div />
      <div
        v-for="color in ['secondary', 'success', 'warning', 'danger', 'info', 'discovery', 'caution']"
        :key="color"
        class="text-center mb-1"
        style="color: var(--color-text-tertiary); font-size: 0.875rem"
      >{{ color }}</div>
      <template v-for="variant in ['soft', 'solid', 'outline']" :key="variant">
        <div class="text-right mr-3" style="color: var(--color-text-tertiary); font-size: 0.875rem">{{ variant }}</div>
        <div
          v-for="color in ['secondary', 'success', 'warning', 'danger', 'info', 'discovery', 'caution']"
          :key="color"
          class="text-center"
        >
          <Badge :color="color" :variant="variant">Sample</Badge>
        </div>
      </template>
    </div>
  </div>
</div>
```

### Size & roundness
You can control the size and roundness of the badge with size and pill props. When pill is set, extra horizontal gutter is dynamically applied to the badge.
```vue
<Badge color="info" :size="size" :pill="pill">New</Badge>
```

### Icon
Content within the badge can be composed, like showing icons. Color, sizing, and spacing adapt by default.
```vue
<Badge color="warning" size="lg"><Flask /> Beta</Badge>
```

### Loading
In this example, additional gap is added with a Tailwind gap-1.5 class to provide the appropriate visual spacing.
```vue
<Badge size="lg" color="secondary" class="gap-1.5">
  <LoadingIndicator /> In progress
</Badge>
```

## Button
Button with four variants (solid, soft, outline, ghost), eight semantic colors, icon slots, loading, and block layout.
Import: import { Button } from "@plexui/vue/components/Button"
Docs: https://plexui.com/vue/components/button
Props:
  - color ("primary" | "secondary" | "danger" | "success" | "info" | "discovery" | "caution" | "warning") default: "primary" — Visual color scheme
  - variant ("solid" | "soft" | "outline" | "ghost") default: "solid" — Button style variant
  - size ("3xs" | "2xs" | "xs" | "sm" | "md" | "lg" | "xl" | "2xl" | "3xl") default: "md" — Control height and default gutter/icon size
  - pill (boolean) default: false — Fully rounded corners
  - block (boolean) default: false — Full width
  - uniform (boolean) default: false — Square icon button (width equals height)
  - disabled (boolean) default: false — Visually and accessibly disabled; click is not emitted
  - disabled-tone ("relaxed") — Default cursor instead of not-allowed while disabled
  - loading (boolean) default: false — Shows loading indicator
  - inert (boolean) default: loading — Accessibly disabled without visual change
  - selected (boolean) default: false — Selected state styling
  - optically-align ("start" | "end") — Offset gutter for optical alignment
  - gutter-size ("3xs" | "2xs" | "xs" | "sm" | "md" | "lg" | "xl") — Horizontal padding size
  - icon-size ("sm" | "md" | "lg" | "xl" | "2xl") — Size of icons in the slot
  - type ("button" | "submit" | "reset") default: "button" — Native button type
  - @click ((event: MouseEvent) => void) — Emitted on click, unless disabled

### Overview
A showcase of Button's key styles: solid, soft, outline, ghost, and icon-only.
```vue
<div class="flex flex-wrap gap-3">
  <Button color="primary">Submit</Button>
  <Button variant="soft"><CompareArrows /> Compare</Button>
  <Button color="danger" gutter-size="sm" :pill="false"><Delete /></Button>
  <Button variant="outline">Next <ArrowRight /></Button>
  <Button variant="ghost" color="secondary" uniform><Clear /></Button>
</div>
```

### Colors & variants
You can stylize the display of the button using the color and variant props.
```vue
<div class="w-[calc(100%+48px)] -mx-6 overflow-x-auto [scrollbar-width:none] [-ms-overflow-style:none] [&::-webkit-scrollbar]:hidden">
  <div class="pt-1 pb-6 px-8 w-max mx-auto">
    <div class="grid gap-6 items-center justify-center" style="grid-template-columns: auto repeat(8, min-content)">
      <div />
      <div
        v-for="color in ['primary', 'secondary', 'danger', 'info', 'discovery', 'success', 'caution', 'warning']"
        :key="color"
        class="text-center text-sm mb-1"
        style="color: var(--color-text-tertiary)"
      >{{ color }}</div>
      <template v-for="variant in ['soft', 'solid', 'outline', 'ghost']" :key="variant">
        <div class="text-right text-sm mr-3" style="color: var(--color-text-tertiary)">{{ variant }}</div>
        <div
          v-for="color in ['primary', 'secondary', 'danger', 'info', 'discovery', 'success', 'caution', 'warning']"
          :key="color"
          class="text-center"
        >
          <Button :color="color" :variant="variant" size="md">Submit</Button>
        </div>
      </template>
    </div>
  </div>
</div>
```

### Sizing & roundness
Control height with size and horizontal padding with gutter-size. Use pill for fully rounded corners. Each size provides default values for gutter-size and icon-size, as well as font-size. Each of these values can be overridden independently.
```vue
<Button :color="color" :variant="variant" :size="size" :pill="pill"><Mail /> Button <ArrowRight /></Button>
<Button :color="color" :variant="variant" :size="size" :pill="pill">Button <ArrowRight /></Button>
<Button :color="color" :variant="variant" :size="size" :pill="pill"><Mail /> Button</Button>
<Button :color="color" :variant="variant" :size="size" :pill="pill">Button</Button>
```

### Icons
Add icons to the default slot. Sizing is automatic via the icon-size prop. For square icon buttons use uniform, which ignores gutter-size. Combine it with pill to make circular icons.
```vue
<Button
  :color="color"
  :size="size"
  :gutter-size="gutterSize === 'auto' ? undefined : gutterSize"
  :icon-size="iconSize === 'auto' ? undefined : iconSize"
  :uniform="uniform"
  :variant="variant"
>
  <PlusLg />
</Button>
```

### Block
Create full-width buttons with the block prop.
```vue
<div class="w-[290px] mx-auto text-center p-2 border border-dashed border-alpha/20 rounded-md">
  <Button color="primary" size="lg" :block="block">Continue</Button>
</div>
```

### Disabled
Use disabled to both visually and accessibly disable a button. Click events are not emitted.
```vue
<Button color="primary" :disabled="disabled">Submit</Button>
```

### Inert
Use inert to accessibly disable a button without any visual changes.
```vue
<Button color="primary" :inert="inert">Submit</Button>
```

### Loading
Use loading to display a loading indicator in the button, fading out the current content. Interactions are prevented during this state, because inert defaults to loading. Override it with inert, or use disabled to add visual disablement.
```vue
<Button loading size="xl" pill><ArrowUp /> Click to load</Button>
```

### Selected

## Button Link
A semantic anchor with full button styling, for internal and external links with icons and block layout.
Import: import { ButtonLink } from "@plexui/vue/components/Button"
Docs: https://plexui.com/vue/components/button-link
Props:
  - default slot (VNode[]) — Content inside the link button
  - color ("primary" | "secondary" | "danger" | "success" | "info" | "discovery" | "caution" | "warning") default: "primary" — Visual color
  - variant ("solid" | "soft" | "outline" | "ghost") default: "solid" — Style variant
  - size ("3xs" | "2xs" | "xs" | "sm" | "md" | "lg" | "xl" | "2xl" | "3xl") default: "md" — Control height and typography scale
  - gutter-size ("3xs" | "2xs" | "xs" | "sm" | "md" | "lg" | "xl") — Override horizontal padding
  - icon-size ("sm" | "md" | "lg" | "xl" | "2xl") — Override icon size
  - href (string) — Link URL
  - to (string | RouteLocationRaw) — Router link destination (internal)
  - as (Component) — Link component override (e.g. RouterLink, NuxtLink)
  - external (boolean) — Force external-link behavior
  - optically-align ("start" | "end") — Apply optical negative margin alignment
  - block (boolean) default: false — Full width
  - pill (boolean) default: false — Fully rounded
  - disabled (boolean) default: false — Disable link
  - disabled-tone ("relaxed") — Use relaxed visual tone for disabled state
  - @click ((event: MouseEvent) => void) — Emitted on click, unless disabled

### Overview
```vue
<ButtonLink color="primary" :pill="false" href="#">View API Keys <ArrowRight /></ButtonLink>
```

### Internal link
When a relative href or to is provided, ButtonLink uses the link component configured on PlexUIProvider, so your router handles navigation.
```vue
<ButtonLink href="/vue/components/button" color="primary">
  Internal link <ArrowRight />
</ButtonLink>
```

### External link
When linking to an external URL (or when external is set), &lt;a&gt; is used with target="_blank" and rel="noopener noreferrer" added automatically. If your link is not being automatically identified, you can force external link behavior with the external prop.
```vue
<ButtonLink href="#" color="primary">
  External link <ArrowUpRight />
</ButtonLink>
```

### Colors & variants
Stylize the link with color and variant props.
```vue
<div class="w-[calc(100%+48px)] -mx-6 overflow-x-auto [scrollbar-width:none] [&::-webkit-scrollbar]:hidden">
  <div class="pt-1 pb-6 px-8 w-fit min-w-full">
    <div class="grid gap-6 items-center justify-center" style="grid-template-columns: auto repeat(8, min-content)">
      <div />
      <div
        v-for="color in ['primary', 'secondary', 'danger', 'info', 'discovery', 'success', 'caution', 'warning']"
        :key="color"
        class="text-center text-sm mb-1 text-tertiary"
      >{{ color }}</div>
      <template v-for="variant in ['soft', 'solid', 'outline', 'ghost']" :key="variant">
        <div class="text-right text-sm mr-3 text-tertiary">{{ variant }}</div>
        <div
          v-for="color in ['primary', 'secondary', 'danger', 'info', 'discovery', 'success', 'caution', 'warning']"
          :key="color"
          class="text-center"
        >
          <ButtonLink href="#" size="lg" :color="color" :variant="variant" class="whitespace-nowrap">Button</ButtonLink>
        </div>
      </template>
    </div>
  </div>
</div>
```

### Sizing & roundness
Sizing of the link is controlled with size and gutter-size. size sets the control height, and gutter-size sets the horizontal padding. Create fully rounded links with the pill prop. When pill is set, extra horizontal gutter is dynamically applied to the link.
```vue
<div class="flex flex-col gap-2 justify-start items-start">
  <ButtonLink color="primary" :size="size" :pill="pill" href="#" class="whitespace-nowrap">
    View account <ArrowRight />
  </ButtonLink>
  <ButtonLink color="primary" :size="size" :pill="pill" href="#" class="whitespace-nowrap">
    View account
  </ButtonLink>
</div>
```

### Icons
Icon sizing is controlled by the icon-size prop, which makes it easy to add icons to the slot without additional props. size provides a default value for icon-size, but setting the prop forces the specified size.
```vue
<ButtonLink color="info" :size="size" :icon-size="iconSize" variant="soft" href="#" class="whitespace-nowrap">
  <Globe /> View website
</ButtonLink>
```

### Block
Create full-width links with the block prop.
```vue
<div class="w-[290px] text-center p-2 border border-dashed border-alpha/20 rounded-md">
  <ButtonLink :block="block" size="lg" href="#" class="whitespace-nowrap">Continue to dashboard</ButtonLink>
</div>
```

### Disabled
Use disabled to both visually and accessibly disable a link. The component renders as a span[role="link"], and click is not emitted.
```vue
<ButtonLink href="#" color="primary" :disabled="disabled" class="whitespace-nowrap">
  <Key /> View API Keys
</ButtonLink>
```

## Checkbox
Checkbox for binary on/off selection with solid, pill, and ghost variants, an indeterminate state, and rich labels with inline descriptions.
Import: import { Checkbox } from "@plexui/vue/components/Checkbox"
Docs: https://plexui.com/vue/components/checkbox
Props:
  - variant ("solid" | "ghost") default: "solid" — Visual style: solid (filled background) or ghost (checkmark only)
  - pill (boolean) default: false — Fully rounded indicator corners
  - checked / v-model:checked (boolean | "indeterminate") — Controlled state


### Variants
The checkbox supports three visual styles: solid (default) with a filled background and standard radius, solid pill with fully rounded corners, and ghost, which renders only the checkmark without a border or background fill.

### Sizing & roundness
Sizing of the input is controlled with the size and gutter-size props. size sets the input to a specific control height, and gutter-size sets the horizontal padding. Each size provides default values for gutter-size, as well as font-size. Each of these values can be overridden independently.

```vue
    placeholder="Search..."
    :size="size"
    :gutter-size="gutterSize === 'auto' ? undefined : gutterSize"
    :pill="pill"

      <Search class="fill-tertiary" />
    </template>

    v-model:value="username"
    placeholder="Username"
```

### Start adornment
You can add arbitrary content to the beginning of an input with the startAdornment slot, like a search icon. Ideally, the spacing will look pretty good by default. If you need to customize the spacing: gutter-size determines the amount of spacing on the edges of the container, which you can fine-tune as needed (if you need precise spacing not supported by gutter-size, use negative left margin on your adornment directly, e.g. -ml-2). The spacing between the adornment and the input is controlled with gap on the container, which you can customize as needed with Tailwind classes.
```vue
<div class="w-[320px]">
  <Input placeholder="Start adornment">
    <template #startAdornment>
      <Search class="fill-tertiary" />
    </template>
  </Input>
</div>
```

### Open on hover
Use show-on-hover to create popovers that appear on hover and focus events. This should be used sparingly and with clear intention.By default, hover popovers will not alter the focused element on the page, nor restore focus to the trigger on close.     <PopoverTrigger>

### Using the controller
The default slot of PopoverContent receives {"{ close, shake }"}. Components rendered inside it can get the same two methods from usePopoverController() in their setup(). They do exactly what you think they do.Attempting to submit an empty form calls the shake() methodAfter async submission occurs (submitPrompt() fakes a two-second request), the close() method is called to close the popup imperatively.
```vue
<Popover>
  <PopoverTrigger>
    <Button color="primary" :pill="false">Generate</Button>
  </PopoverTrigger>
  <PopoverContent side="right" v-slot="{ close, shake }">
    <form
      @submit.prevent="
        if (!prompt) return shake();
        submitting = true;
        submitPrompt().then(() => { submitting = false; prompt = ''; close(); });
      "
    >
      <textarea
        v-model="prompt"
        placeholder="Describe what you're using the model for, and we'll generate system instructions."
        style="width: 100%; height: 80px; background: none; padding: 12px 16px 8px; border: 0; font-size: 14px; line-height: 20px; resize: none; outline: 0"
      />
      <div class="px-3 pb-3 flex items-center justify-between">
        <div class="flex gap-1.5 items-center font-normal text-sm text-tertiary">
          <Sparkles :width="16" :height="16" />
          Free beta
        </div>
        <Button color="primary" size="xs" :pill="false" :loading="submitting" type="submit">
          Create
        </Button>
      </div>
    </form>
  </PopoverContent>
</Popover>
```

## Slider
Slider for fine-tuning numeric values with single or range thumbs, marks, an editable value input, and vertical orientation.
Import: import { Slider } from "@plexui/vue/components/Slider"
Docs: https://plexui.com/vue/components/slider
Props:
  - value (number | number[]) — Current value; an array when range is set. Bind with v-model:value
  - min (number) — Minimum value
  - max (number) — Maximum value
  - step (number) — Step increment
  - range (boolean) default: false — Enable multi-thumb range mode

  - reset-value (number) — Value for the reset option (single mode only)

  - unit (string) — Unit displayed after the value (e.g. ms, px)

## Tabs
Switch between grouped views with segmented or underline tabs, icon-only triggers, and badge counts on each tab.
Import: import { Tabs, TabsTab } from "@plexui/vue/components/Tabs"
Docs: https://plexui.com/vue/components/tabs
Props:
  - value (string) — Selected tab value. Bind with v-model:value; leave unset for an uncontrolled group
  - variant ("segmented" | "underline") default: "segmented" — Visual style: segmented (background highlight) or underline (line indicator)
  - orientation ("horizontal" | "vertical") default: "horizontal" — Layout direction of the tab group
  - size ("3xs" | "2xs" | "xs" | "sm" | "md" | "lg" | "xl" | "2xl" | "3xl") default: "md" — Control height (3xs through 3xl)
  - gutter-size ("2xs" | "xs" | "sm" | "md" | "lg" | "xl") — Horizontal padding of tabs
  - pill (boolean) default: true — Fully rounded control (segmented variant only)
  - flush (boolean) default: false — Text-width indicator, no border, gap spacing (underline variant only)
  - block (boolean) default: false — Full-width control with equal-width tabs
  - disabled (boolean) default: false — Disable all tabs
  - aria-label (string) — Accessible name (required)
  - class (string) — Extra classes on the group element

  - @change ((value: string) => void) — Emitted with update:value, named after the React onChange prop

  - badge (number | string | VNode | { content; color?; variant?; pill?; loading? }) — Badge/count or custom badge config
  - icon slot (VNode[]) — Icon before the label
  - badge slot (VNode[]) — Badge content; styling still comes from the badge object

### Suggestions
Combine TagInput with clickable buttons to let users add tags by clicking suggestions or typing manually. Suggestions disappear once selected.
```vue
<script setup lang="ts">
import { computed, ref } from "vue"
import { Button } from "@plexui/vue/components/Button"
import { TagInput, type Tag } from "@plexui/vue/components/TagInput"

const SUGGESTIONS = ["React", "TypeScript", "Next.js", "Tailwind CSS", "Node.js", "GraphQL", "PostgreSQL", "Redis", "Docker", "AWS"]

const tags = ref<Tag[]>([
  { value: "React", valid: true },
  { value: "TypeScript", valid: true },
])

const available = computed(() => {
  const selected = new Set(tags.value.map((t) => t.value))
  return SUGGESTIONS.filter((s) => !selected.has(s))
})
</script>

<template>
  <div class="flex flex-col gap-3">
    <TagInput v-model:value="tags" placeholder="Add a skill..." />
    <div v-if="available.length > 0" class="flex flex-wrap gap-1.5">
      <Button
        v-for="s in available"
        :key="s"
        size="xs"
        color="secondary"
        variant="soft"
        :pill="false"
        @click="tags = [...tags, { value: s, valid: true }]"
      >
        {{ s }}
      </Button>
    </div>
  </div>
</template>
```

### Compact
Spread compact ({`import { toast, compact } from "@plexui/vue/components/Toast"`}) into any toast(...) options for a centered-text layout. Toast width shrinks to content by default regardless; the compact helper only adds center alignment for short status messages.
```vue
<Button color="secondary" variant="outline" @click="toast.success('Inquiry ID copied', compact)">

```

### Persistent
Pass duration: Infinity for toasts that stay open until the user acts on them. There are no close (×) affordances: put a labelled action on the toast so dismissal is intentional and keyboard-accessible.
```vue
<Button
  color="secondary"
  variant="outline"
  @click="() => {
    const id = toast('Backup scheduled for 2:00 AM UTC', {
      description: 'This stays open until you dismiss it.',
      duration: Infinity,
      action: { label: 'Dismiss', onClick: () => toast.dismiss(id) },
    })
  }"
>
  Persistent toast
</Button>
```

## Tooltip
Brief informative text shown on hover or focus, for any trigger element, with conditional enabling and a compact variant.
Import: import { Tooltip, TooltipTriggerDecorator } from "@plexui/vue/components/Tooltip"
Docs: https://plexui.com/vue/components/tooltip
Props:
  - content (string | VNode | null) — Tooltip content, or the #content slot (null = no tooltip)
  - compact (boolean) default: false — Short 1–3 word tooltips, inverse styling
  - interactive (boolean) default: false — Content is interactive, stays open when hovered
  - openDelay (number) default: 150 — Delay before showing (ms)
  - side (string) default: "top" — Preferred side
  - sideOffset (number) default: 5 — Distance from trigger
  - align (string) default: "center" — Alignment
  - alignOffset (number) default: 0 — Alignment offset
  - gutterSize ("sm" | "md" | "lg") default: "md" — Content padding
  - contentClassName (string) — Class for tooltip content
  - forceOpen (boolean) — Force open or closed

### Base
```vue
<Tooltip content="This is additional context that appears when the trigger is hovered or focused">
  <TooltipTriggerDecorator>Simple text with tooltip</TooltipTriggerDecorator>
</Tooltip>
```

### Different triggers
Tooltip provides an optional component, TooltipTriggerDecorator, to help create accessible tooltip triggers. However, any component can be used as a trigger.
```vue
<div class="flex items-center gap-4">
  <Tooltip content="Tooltip on button">
    <Button color="primary" size="lg">Sample button</Button>
  </Tooltip>
  <Tooltip content="Tooltip on span">
    <span>Inaccessible trigger</span>
  </Tooltip>
</div>
```

### Conditionally enabled
Sometimes a tooltip should only be disabled under certain conditions, such as when a component is disabled, providing more context as to why that is. Below is an example of how to do this by conditionally passing in null content.
```vue
<Tooltip :content="disabled ? 'This action is disabled for reasons' : null">
  <Button color="primary" size="lg" :disabled="disabled">
    Sample button
  </Button>
</Tooltip>
```

### Compact tooltips
Compact tooltips are designed for short, 1-3 word tooltips with inverted styling. They feature minimal padding, a dark background with white text, and no box shadows. Use compact for brief status messages.
```vue
<Tooltip content="Copy to clipboard" compact>
  <Button color="secondary" variant="ghost" size="md"><Copy /></Button>
</Tooltip>
```
