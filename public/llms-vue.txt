# PlexUI for Vue
> PlexUI for Vue 3: the same components, props, markup and styles as the React library.

Vue 3 components with the same names, props, defaults and markup as the React library (https://plexui.com/llms.txt).
In Vue: `class` instead of `className`, slots instead of ReactNode props, `v-model:value` for controlled values, `@x` listeners for `onX` callbacks, flat named exports for compound parts (e.g. DialogTrigger), composables from @plexui/vue/composables/<name>.
Every example's code: https://plexui.com/llms-vue-full.txt

Install: npm install @plexui/vue @plexui/styles
Docs: https://plexui.com
Components: 50

## Setup

```css
@layer theme, base, components, utilities;
@import "tailwindcss";
@import "@plexui/styles/css";
@source "../node_modules/@plexui/vue";
```

Wrap your app with <PlexUIProvider :link-component="RouterLink"> from "@plexui/vue/components/PlexUIProvider"

Size scale: 3xs, 2xs, xs, sm, md, lg, xl, 2xl, 3xl
Colors: primary, secondary, danger, success, warning, caution, discovery, info
Variants: solid, soft, outline, ghost

Import: import { Accordion, AccordionContent, AccordionItem, AccordionTrigger } from "@plexui/vue/components/Accordion"

Props:
  - type ("single" | "multiple") — Required. Whether one item or many can be open at a time
